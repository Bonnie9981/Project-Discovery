# A071052: proof of a(2n) = a(n) + 2n

Chi Hsia, November 2026. Proof and Lean 4 formalization generated with an LLM (Claude) and machine-checked; see the AI-use note at the end.

## Statement

Let r_n be generation n of the elementary cellular automaton Rule 150, new(i) = old(i-1) XOR old(i) XOR old(i+1), started from a single ON cell at position 0. Row n of the triangle A071036 is r_n on the 2n+1 cells -n..n. A071053(n) is the number of 1's and A071052(n) the number of 0's in that row, so

A071052(n) = 2n + 1 - A071053(n).

**Theorem.** For every n >= 0, A071052(2n) = A071052(n) + 2n.

## Proof

Over GF(2), two Rule 150 steps give new(i) = old(i-2) XOR old(i) XOR old(i+2): in the double sum old(i-1) and old(i+1) appear twice and old(i) three times. (Equivalently (x^-1 + 1 + x)^2 = x^-2 + 1 + x^2 over GF(2).)

So if a configuration lives on the even cells only, two steps act on it exactly like one step of the configuration "squeezed" to every cell, and the odd cells stay 0. The seed lives on the even cells, hence by induction r_{2n}(2i) = r_n(i) and r_{2n}(2i+1) = 0. In polynomial language, (1+x+x^2)^(2n) = (1+x^2+x^4)^n mod 2.

Therefore row 2n has the same number of 1's as row n: A071053(2n) = A071053(n) (this identity is already in the FORMULA of A071053, Peter J. Taylor 2020). Row 2n is 2n cells longer than row n, so

A071052(2n) = (4n+1) - A071053(n) = (2n+1 - A071053(n)) + 2n = A071052(n) + 2n. QED
