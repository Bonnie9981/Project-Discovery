# Proofs of the conjectures in OEIS A218483

Chi Hsia, 2026. Written with an LLM (Claude); the first proof is checked in Lean 4 (core only).

**Conjecture 1 (M. Coman, 2012).** There are no Fermat pseudoprimes to base 2 of the form 40*n + 15.

**Proof.** If N == 15 (mod 40) then 5 | N, and 2^(N-1) == 1 (mod N) would give 2^(N-1) == 1 (mod 5). The order of 2 modulo 5 is 4, so 4 | N - 1. But N - 1 == 14 (mod 40), so N - 1 == 2 (mod 4). Hence no N == 15 (mod 40) at all (prime or not) satisfies 2^(N-1) == 1 (mod N). QED

**Conjectures 2 and 3.** For an odd N with prime factor p, "N = 8*p*k + p^2 for an integer k" is equivalent to N/p == p (mod 8), i.e. N == p^2 == 1 (mod 8) (because p^2 == 1 and p^(-1) == p (mod 8)). So the condition does not depend on p: it holds for one prime factor of N if and only if N == 1 (mod 8), and then it holds for every prime factor, with k = (N - p^2)/(8p). For Conjecture 3 (N = p1*p2): N = p1*(p1 + 8n) forces 8n = p2 - p1, and then 8*p2*(-n) + p2^2 = p2*(p2 - 8n) = p2*p1 = N, with the same n. Both statements are therefore true for every odd N (every N = p1*p2 in Conjecture 3), pseudoprime or not.
