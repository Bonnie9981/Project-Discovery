# Proof of Rotondo's conjecture in OEIS A058128

Chi Hsia, 2026. Written with an LLM (Claude); checked in Lean 4 (core only).

**Claim (D. Rotondo, 2024).** For even n, a(n) = (n^n - n)/(n-1)^2 is prime or a weak Fermat pseudoprime to base n, i.e. n^a(n) == n (mod a(n)).

**Proof.** Let n >= 2 be even and put T = 1 + n + ... + n^(n-2) = (n^(n-1) - 1)/(n-1).

1. Write n = 1 + m. Then n^i == 1 + i*m (mod m^2), so T == (n-1) + m*(n-2)(n-1)/2 (mod m^2). Since n is even, (n-2)/2 is an integer, so the second term is a multiple of m^2 and T == m (mod m^2). Hence S = T/(n-1) is an integer with S == 1 (mod n-1), and a(n) = n*S.
2. S divides n^(n-1) - 1, so gcd(S, n) = 1 and n^(n-1) == 1 (mod S).
3. n*S - 1 == S - 1 == 0 (mod n-1), say n*S - 1 = (n-1)*t. Then n^(nS-1) = (n^(n-1))^t == 1 (mod S), so n^(nS) == n (mod S).
4. Also n^(nS) == 0 == n (mod n). As gcd(n, S) = 1, n^a(n) == n (mod n*S = a(n)). QED

Remark. For odd n the same computation gives S == 1 + (n-1)/2 (mod n-1), and the property can fail (e.g. n = 3: a = 6, 3^6 == 3 (mod 6) holds, but n = 5: a = 195, 5^195 mod 195 = 125 != 5).
