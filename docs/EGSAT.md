# Erdős–Gyárfás 小範圍 SAT 重現（`discovery/egsat/`）

問題：最小度 ≥ 3 的圖是否一定有長度 4、8、16、… 的圈。這裡只做小 n 的重現加證書（DISC-0022），前沿已在 40 點（Ducoffe–Dumitru 2026）。

## 用法

```
python -m discovery.egsat.search 10 11 12 --out OUT   # 搜尋，UNSAT 時寫 CNF＋DRAT
python -m discovery.egsat.check OUT 10 11 12          # 獨立檢查
```

## 編碼（變數編號規格，`check.py` 會照這裡獨立重建）

- `e(a,b)`（a<b）：上三角按列優先排序的位置 + 1，共 E = n(n−1)/2 個。
- `d(i) = E + 1 + i`：只有單向「d(i) → deg(i) ≤ 3」。
- 字典序輔助變數從 E + n + 1 起，依 i = 0..n−2、比較位置依序編號。

子句家族：

| 家族 | 內容 | 為什麼不會漏掉反例 |
|---|---|---|
| DEG | 每點 v、任兩個其他點 T：v 到 T 以外的邊至少一條 | 就是 deg(v) ≥ 3 |
| C4 | 每個 4 圈不能四條邊全有 | 定義 |
| MIN | e(a,b) → d(a) ∨ d(b)；d(v) → v 的任四條邊不全有 | 反例一直刪邊到「再刪就有點度 < 3」仍是反例（刪邊不會產生新圈），點數不變；這時每條邊都有一端度數恰好 3 |
| LEX | 對每個相鄰對換 (i,i+1)：上三角向量 ≥lex 對換後的向量 | 取同構類裡上三角向量字典序最大的標號，它對所有置換都成立，對換只是其中一部分 |
| CYC | CEGAR 時找到的 8 圈、16 圈（n ≥ 16 才擋 16 圈） | 定義 |

MIN 與 LEX 同時成立：邊極小在重新標號下不變，所以可以先取邊極小、再取字典序最大的標號。

## 證書

UNSAT 時把「基本子句 ＋ 所有擋圈子句」寫成 CNF，用 CaDiCaL（PySAT `Cadical195`）重新求解並輸出 DRAT。`check.py` 不 import 搜尋程式：
1. 自己照上面規格重建基本子句，比對集合相等；其他子句必須是 K_n 裡真的 4、8、16 圈。
2. 自寫正向 RUP 檢查器（兩個監看字面），只接受 RUP 引理，必須推出空子句。刪除行只停用子句。
3. SAT 時直接暴力檢查圖。

沒用 drat-trim：這個容器不能下載外部程式來編譯，所以檢查器是自己寫的，`tests/test_egsat.py` 有竄改證書會被擋下的測試。
