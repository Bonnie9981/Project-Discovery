# 開定位支配集有幾個（高二版證明說明）

對應：OEIS 新序列草稿「環 C_n 的開定位支配集個數」「路徑 P_n 的開定位支配集個數」，以及 A001609 的編輯草稿。英文證明：`paper/open-locating-and-ladders.md` 第 1～3 節。

## 1. 問題是什麼

房間排成一圈（環 C_n）或一排（路徑 P_n），相鄰房間有門。在集合 S 的房間裝感應器，這次感應器**只偵測隔壁、不偵測自己的房間**。小偷在房間 v，響的是 v 的鄰居裡有裝的那些。要求：小偷在任何一間（包括有裝的房間），都至少有一個會響，而且不同房間響的組合都不一樣。這樣的 S 叫「開定位支配集」（open-locating-dominating set）。

小例子：5 個房間排一圈，裝 4 間（5 種裝法）或 5 間全裝都可以，裝 3 間以下都不行，所以有 6 種。4 個房間排一圈一種都沒有（個數是 0，公式對 n = 4 不適用）：對面兩間的鄰居完全一樣，永遠分不出來。

## 2. 關鍵觀察：鄰居一定在「另一個奇偶類」

在一圈或一排房間裡，房間 v 的鄰居是 v−1 和 v+1，奇偶性都和 v 相反。所以「奇數房有沒有裝」只影響「偶數房的小偷能不能被定位」，反過來也一樣。**問題拆成兩個互不相干的小問題，答案相乘。**

## 3. 每個小問題變成「0 之間至少隔 3 格」的字串

先看環、n 是奇數的情形。從房間 0 開始每次跳 2 格：0, 2, 4, …，n 是奇數，所以會走過全部 n 間再回到 0。按這個順序寫下每間裝不裝（1/0），得到一個繞一圈的字串 y。

- 小偷在 v 時，v 的兩個鄰居在新順序裡剛好相鄰 → 「至少一個響」= 相鄰兩格不能都是 0。
- 只有相隔 2 的兩間（v 和 v+2）鄰居有重疊（都含 v+1），要分得出來，就要 v−1 或 v+3 有裝；它們在新順序裡相隔 2 格 → 隔一格的兩個字母不能都是 0。

合起來：**任兩個 0 至少隔 3 格**。這種繞圈字串的個數，把每個 0 和它前面兩個 1 黏成一塊「110」，就變成用長 1 和長 3 的磚鋪一圈，方法數是 OEIS 的 A001609（1, 1, 4, 5, 6, 10, 15, 21, …，每項 = 前一項 + 前第三項）。

n 是偶數時，奇數房、偶數房各自跳 2 格繞成一個長 n/2 的圈，各自是同樣的問題，所以答案是 A001609(n/2) 的平方。

## 4. 一排房間（路徑）

一樣拆成奇數位置和偶數位置。每一類寫成直線字串，規則一樣是「任兩個 0 至少隔 3 格」，只多一件事：如果這一排最端點的那一間**不屬於**這一類，它只有一個鄰居，那個鄰居一定要裝；再加上端點和隔壁同類那間要分得出來，第二近的也一定要裝。所以靠那一端的兩個字母被強迫是 1。

直線上「0 至少隔 3 格」的字串數是 Narayana 牛數 A000930（1, 1, 1, 2, 3, 4, 6, 9, 13, …）：最後一個字母是 1，前面隨便；是 0，前面兩個一定是 1。於是

- n = 2k：兩類各 k 間，各有一端被強迫 → A000930(k)²；
- n = 2k+1：奇數類 k+1 間、兩端都沒被強迫 → A000930(k+3)；偶數類 k 間、兩端都被強迫 → A000930(k−2)；相乘。

## 5. 哪些是證明、哪些是電腦

第 2～4 節是完整證明，不靠電腦。電腦做的是檢查：照定義試所有裝法（n ≤ 20）和公式完全一樣，另一套程式（critic 的獨立程式）把環算到 n = 40、路徑算到 n = 60 也一樣。網路和 OEIS 都沒找到有人數過，但不等於一定是新的。

## 6. 超出高二的地方

- 「鋪一圈的方法數 = Σ 磚長 × 鋪直線的方法數」是乘法原理，高二就夠；寫成生成函數是大學內容，可以不管。

## 7. 自己寫 OEIS 留言時要講的重點

- 定義：每個點的「鄰居（不含自己）」與 S 的交集非空且互不相同（Seo、Slater）。
- 關鍵：鄰居在另一個奇偶類 → 拆成兩半；每半是「任兩個 0 至少隔 3 格」的字串。
- 公式：環 = A001609(n)（奇）或 A001609(n/2)²（偶，n ≥ 6）；路徑 = A000930 的乘積。
- 說明 AI 協助、你自己讀過證明；不說「新發現」。
