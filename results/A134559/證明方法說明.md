# A134559 證明方法說明（高二版）

> 依據：英文說明 `paper/a134559-counterexample.md`、Lean 檔 `lean/Discovery/A134559Counter.lean`、紀錄 `records/DISC-0021/`。

## 一句話結論

Ratajczak（2019）在 A134559 留言猜：滿足某個 gcd 條件 (*) 的 n，**剛好就是** A005383 的成員（質數 p 且 (p+1)/2 也是質數），除了 3 和 5。

我們證明了一半、推翻了另一半：

- **對的那半：** 滿足 (*) 的 n 一定在 A005383 裡（紙筆證明）。
- **錯的那半：** A005383 的成員不一定滿足 (*)。最小反例是 **p = 4933**。

## 第一步：定義和小例子

**b_n(k)。** 對 1 ≤ u ≤ n，看 n 除以 u 的餘數。把「餘數剛好是 k」的那些 u 加起來，就是 b_n(k)。k 從 0 到 ⌈n/2⌉ − 1。

例：n = 13。

- k = 0：13 除以 u 餘 0 的 u 是 1、13，和是 14。
- k = 1：13 除以 u 餘 1 的 u 是 2、3、4、6、12，和是 27。
- 依此類推，b_13 = 14, 27, 11, 15, 9, 8, 7。

（另一種看法：n 除以 u 餘 k ⇔ u 整除 n − k 而且 u > k。所以 b_n(k) = 「n − k 的因數中大於 k 的那些加起來」。）

**P(n)** = 所有 b_n(k) 乘起來。

**條件 (*)：** gcd(P(n), n) = 1，而且 gcd(P(n+1), n+1) = 2。

例：n = 13。P(13) = 14 × 27 × 11 × 15 × 9 × 8 × 7 = 31434480，和 13 的最大公因數是 1。P(14) 和 14 的最大公因數是 2。所以 13 滿足 (*)。而 13 是質數、(13+1)/2 = 7 也是質數，13 在 A005383 裡 ✓。

200 以下滿足 (*) 的 n：13, 37, 61, 73, 157, 193，全部在 A005383 裡。

## 第二步：反例 p = 4933

4933 是質數，(4933 + 1)/2 = 2467 也是質數，所以 4933 在 A005383 裡。

但看 n + 1 = 4934 = 2 × 2467：

- b_4934(134) = 4934 − 134 = 4800 的因數中大於 134 的總和 = 150 + 160 + 192 + 200 + 240 + 300 + 320 + 400 + 480 + 600 + 800 + 960 + 1200 + 1600 + 2400 + 4800 = 14802 = 6 × 2467。
- b_4934(0) = 4934 所有因數的和 = 1 + 2 + 2467 + 4934 = 7404，是偶數。

所以 P(4934) 同時是 2 和 2467 的倍數，也就是 4934 的倍數。gcd(P(4934), 4934) = 4934，不是 2。4933 不滿足 (*)，猜想錯。

而且 4933 是最小的這種反例。1.5 × 10^5 以內的反例有 4933, 6997, 11113, 48673, 50341, 54217, 92941。其中 54217 是在另一邊失敗（gcd(P(54217), 54217) = 54217），這正是原留言自己提到「猜想可能會這樣失敗」的方式。

## 第三步：對的那一半

**引理。** 如果 N/2 < m ≤ 2N/3，令 k = N − m，那 b_N(k) = m。

為什麼：u 要滿足「u 整除 m、u > k」。u = m 符合（m > N/2 > k）。m 的其他因數最大是 m/2，而 m ≤ 2N/3 推得 m/2 ≤ N − m = k，所以都不符合。只剩 m 自己。

**推論。** 如果 d ≥ 2 整除 N，而且 d ≤ N/6，那 d 也整除 gcd(P(N), N)。

為什麼：區間 (N/2, 2N/3] 長度是 N/6 ≥ d，裡面一定有 d 的倍數 m。由引理，m = b_N(N − m) 是 P(N) 的一個因數，所以 d 整除 P(N)。

**定理：** 滿足 (*) 的 n 一定在 A005383 裡，而且不是 3、5。

- n < 36：直接檢查。
- n ≥ 36，n 不是質數的話：最小質因數 q ≤ √n ≤ n/6，由推論 q 整除 gcd(P(n), n)，和「gcd = 1」矛盾。所以 n 是質數。
- N = n + 1 是偶數。如果 4 整除 N：4 ≤ N/6，所以 4 整除 gcd，gcd 不會是 2。所以 N = 2M，M 是奇數。
- 如果 M 不是質數：M 的最小質因數 q ≤ √M ≤ N/6，q 和 2 都整除 gcd，gcd 不會是 2。所以 M = (n+1)/2 是質數。

這部分只用到因數、最大公因數、√n 的估計，都在高中範圍。

## 編輯可能問、你可以這樣答

- **問：反例怎麼看出來？** 答：4934 − 134 = 4800 的大於 134 的因數和是 14802 = 6·2467，而 σ(4934) = 7404 是偶數，所以 4934 整除 P(4934)，gcd 不是 2。
- **問：另一半？** 答：只要 n 有 ≤ n/6 的因數 d，(n/2, 2n/3] 裡 d 的倍數 m 會等於 b_n(n−m)，所以 d 整除 gcd。由此推出 n 和 (n+1)/2 都是質數。
