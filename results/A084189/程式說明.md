# A084189、A084352 程式說明（高二版）

## 這些程式在算什麼

| 檔案 | 語言 | 做什麼 |
|---|---|---|
| `code/check_pal.py` | Python | 列出 10^9 以下所有「回文數又是兩個質數相乘」的數，算出兩條序列，和 OEIS 資料比對，檢查最大值 ≤ 3 |
| `code/palprime_pairs.c` | C | 把「數字全 ≥ 4 的回文質數」兩兩相乘，乘積到 10^22，看有沒有回文（A084189） |
| `code/digit_pairs.c` | C | 把「數字全 ≥ 4 的質數」（不限回文）兩兩相乘，乘積到 10^14，看哪些是回文、位數是否相同（A084352） |

（都在 `results/A084189/` 底下。）

## 最簡單的一支：check_pal.py（你自己可以跑）

只要 Python 3：

```
python results\A084189\code\check_pal.py
```

預設檢查到 10^8，約一分鐘。我們跑到 10^9（加參數 `1e9`，要幾分鐘）的結果：

```
limit 1000000000: A046376 terms 707, max min-digit 3; palindromic brilliant 930, max min-digit 3
DATA lines match; conjectures hold below the limit
```

注意：範圍太小（例如 `1e6`）會出現 `AssertionError: A084189 DATA mismatch`，那不是錯，是因為 10^6 以下的項數比 OEIS 上的資料少，對不完整。用預設值或更大就好。

**程式逐段說明：**

- `palindromes(limit)`：直接「造」出所有回文數，不用一個一個檢查。做法是取前半段（例如 12），把它倒過來接上去：偶數位得 1221、奇數位得 121。
- `semiprime_split(n)`：用試除法找 n 的最小因數 d（從 2 開始試到 √n），再檢查 n/d 是不是質數。是的話 n 就是兩個質數相乘，回傳 (p, q)。
- `ispal(n)`：`str(n) == str(n)[::-1]`，字串和它的倒轉一樣就是回文。`[::-1]` 是 Python 倒轉字串的寫法。
- `main()`：
  - 對每個回文數，拆成 p × q；
  - 算 p、q 所有數字的最小值；
  - p、q 都是回文 → 屬於 A084189；p、q 位數一樣 → 屬於 A084352；
  - 和程式開頭從 OEIS 抄來的資料（103 項、87 項）比對，並檢查最大值 ≤ 3。

## 兩支 C 程式（需要 C 編譯器，可以只看說明）

**palprime_pairs.c（A084189）：** 先造出所有數字只用 4～9 的回文質數（最多 11 位，共 2082 個），兩兩相乘（2168403 對，乘積 < 10^22），檢查乘積是不是回文。結果：一個都沒有。0.3 秒跑完。

**digit_pairs.c（A084352）：** 造出所有數字只用 4～9 的質數（最多 7 位，18482 個），兩兩相乘（乘積 < 10^14）。結果：有 126 個乘積是回文，但**全部**是兩個因數位數不同的情況，最小的是 33433 = 67 × 499。位數相同的一個都沒有，和證明一致。這也說明「位數相同」這個條件是必要的。

跑法（Linux / Mac）：

```
gcc -O2 -o ppal palprime_pairs.c && ./ppal 11 1e22
gcc -O2 -o pal digit_pairs.c && ./pal 7 100000000000000
```

## 不用程式也能自己驗證

- 偶數位回文是 11 的倍數：試 4554 ÷ 11 = 414、123321 ÷ 11 = 11211。
- 33433 = 67 × 499：用計算機乘乘看，再看 33433 是不是回文（是）。它是 5 位（奇數位），所以 11 的論證管不到它。
