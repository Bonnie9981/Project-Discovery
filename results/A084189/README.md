# OEIS A084189、A084352：「兩因數最小數字永遠不大於 3」的證明

紀錄 [DISC-0024](../../records/DISC-0024/)，Lean `lean/Discovery/PalDigits.lean`（`a084189`、`a084352`）。兩條放同一個資料夾。

| 檔案 | 內容 |
|---|---|
| `a084189_a084352_oeis_edit_draft.md` | 兩條的 OEIS 編輯草稿（分開送），使用者自己送出 |
| `code/check_pal.py` | Python：列出 10^9 以下的回文半質數，對 DATA，檢查最大值 ≤ 3 |
| `code/palprime_pairs.c` | C：數字全 ≥ 4 的回文質數兩兩相乘，窮舉到 10^22，沒有回文 |
| `code/digit_pairs.c` | C：數字全 ≥ 4 的任意質數兩兩相乘（10^14 內）；同位數的那些沒有回文 |

註：不限回文、位數不同時，數字全 ≥ 4 的質數乘積可以是回文（最小 33433 = 67·499），所以兩條猜想的條件都用到了。
