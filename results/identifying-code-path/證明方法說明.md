# 路徑上的「識別碼」有幾個（高二版證明說明）

對應：OEIS 新序列草稿「Number of identifying codes in the path graph P_n」。英文證明：`paper/locating-dominating-paths.md` 第 3 節。

## 1. 問題

同樣 n 個房間排一排，在集合 C 的房間裝感應器。這次感應器**也會偵測自己的房間**：小偷在房間 v，響的是 v 自己和它鄰居中有裝的。要求每個房間響的組合都不是空的、而且互不相同（不論小偷在有裝或沒裝的房間都能定位）。這樣的 C 叫「識別碼」。b(n) = 裝法數。

n = 2 沒有任何裝法：兩間房的「自己加鄰居」都是 {1,2}，永遠分不出來，b(2) = 0。n = 3 有 {1,3}、{1,2,3} 兩種。

## 2. 化成字串規則（引理 3，n ≥ 3）

寫成 0/1 字串 w₁…wₙ。

- **非空**：不能連續三個 0；開頭兩格至少一個 1；結尾兩格至少一個 1。
- **相隔 3 格以上的兩間**：它們的「自己加鄰居」沒有重疊，又都非空，自動不同。
- **相鄰兩間 i、i+1**：兩者的差別只在 i−1 和 i+2 兩個房間，所以 w_{i−1}、w_{i+2} 至少一個是 1。換個寫法：**隔 3 格的兩個位置不能都是 0**；最左邊那對（1、2 號）的差別只剩 3 號，所以 **w₃ = 1**，同理倒數第 3 個也要是 1。
- **隔一間的 i、i+2**：差別是 i−1、i、i+2、i+3，裡面已經包含上一條保證有 1 的位置，自動滿足。

## 3. 數字串：轉移矩陣

所有規則只看連續 4 個字母。所以從左往右寫的時候，只要記得**最後 3 個字母**（2³ = 8 種狀態），就知道下一個字母能不能放。把「狀態 p 後面可以接成狀態 q」做成 8×8 的表（矩陣 M），長度 n 的字串數就是 M 的 n−3 次方再加總開頭、結尾允許的狀態。

線性代數裡的 Cayley–Hamilton 定理說：矩陣會滿足自己的特徵多項式。電腦精確算出這個 M 的特徵多項式是 x·(x⁷ − x⁶ − x⁵ + x⁴ − x³ − x² + 1)，所以

b(n) = b(n−1) + b(n−2) − b(n−3) + b(n−4) + b(n−5) − b(n−7)。

（這個定理高二還沒教，可以把它當成「矩陣次方的數列一定滿足一條固定的遞迴，遞迴係數由矩陣決定」。）前 20 項用暴力算確認，所以公式對每個 n 都對。

## 4. 哪些是證明、哪些是電腦

第 2 節的規則是證明；第 3 節的推理是證明，其中「特徵多項式」這個數是電腦精確算的（整數運算，沒有近似）。暴力、字串規則、矩陣、遞迴四種算法在 n ≤ 20 都一樣。不宣稱是新的，只是 OEIS 和網路粗查都沒找到。

## 5. 超出高二的地方

- 第 3 節的 Cayley–Hamilton 定理和特徵多項式是大學線性代數；特徵多項式由電腦用整數精確算出。

## 6. 自己寫 OEIS 留言時要講的重點

- 識別碼的定義：每個點「自己加鄰居」與 C 的交集非空且互不相同。
- 字串規則三條：隔 3 格不能都是 0、第 3 和倒數第 3 個是 1、不能連三個 0 且頭尾兩格各有 1。
- 規則只看連續 4 格 → 8 狀態轉移矩陣 → 7 階遞迴（n ≥ 8）。
- AI 協助、你自己讀過證明；不說「新發現」。
