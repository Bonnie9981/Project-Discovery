# A058128 證明方法說明（高二版）

> 依據：英文證明 `paper/a058128-proof.md`、Lean 檔 `lean/Discovery/CxBatch1.lean`（定理 `a058128_weak_psp`）。

## 一句話結論

A058128(n) = (n^n − n) / (n−1)²。Rotondo（2024）猜：n 是偶數時，a(n) 是質數，或是「以 n 為底的弱偽質數」。我們證明它對。也順便說明 n 是奇數時可能不成立（例如 n = 5）。

## 第一步：名詞和小例子

**弱偽質數。** 說 a 是「以 n 為底的弱偽質數」，意思是 n^a 除以 a 的餘數等於 n 除以 a 的餘數（寫成 n^a ≡ n (mod a)），但 a 不是質數。質數本來就滿足這個式子（費馬小定理），所以猜想就是說：

> n 是偶數時，n^a(n) ≡ n (mod a(n))。

**小例子：n = 4。** a(4) = (256 − 4) / 9 = 28 = 4 × 7。4^28 除以 28 餘多少？

- 除以 7：4³ = 64 = 9 × 7 + 1，餘 1。28 = 3 × 9 + 1，所以 4^28 = (4³)⁹ × 4，餘 1 × 4 = 4。
- 除以 4：4^28 和 4 都是 4 的倍數，都餘 0。
- 除以 7 餘 4、除以 4 餘 0，而 4 本身也是這樣，所以 4^28 ≡ 4 (mod 28) ✓。

n = 6：a(6) = 1866 = 6 × 311，程式算出 6^1866 除以 1866 餘 6 ✓。

## 第二步：證明（n 是偶數，n ≥ 2）

令 T = 1 + n + n² + … + n^(n−2)（等比級數，共 n−1 項），等比級數公式給 T = (n^(n−1) − 1)/(n−1)。

注意 n^n − n = n·(n^(n−1) − 1) = n·(n−1)·T，所以 a(n) = n·T/(n−1)。

**1. T 是 n−1 的倍數，而且 S = T/(n−1) 除以 n−1 餘 1。**

令 m = n − 1，所以 n = 1 + m。用二項式定理：n^i = (1+m)^i = 1 + i·m + （m² 的倍數）。所以除以 m² 時，

> n^i ≡ 1 + i·m (mod m²)

把 i = 0 到 n−2 加起來：

> T ≡ (n−1) + m·[0 + 1 + … + (n−2)] = m + m·(n−2)(n−1)/2 = m + m²·(n−2)/2 (mod m²)

**n 是偶數**，所以 (n−2)/2 是整數，第二項是 m² 的倍數。於是 T ≡ m (mod m²)，也就是 T = m + （m² 的倍數）。除以 m 得 S = T/m = 1 + （m 的倍數）：S 是整數，而且 S 除以 n−1 餘 1。

所以 a(n) = n·S。

**2. S 和 n 互質，而且 n^(n−1) 除以 S 餘 1。** 因為 S 整除 T，T 整除 n^(n−1) − 1（T·(n−1) = n^(n−1) − 1），所以 S 整除 n^(n−1) − 1。一個整除 n^(n−1) − 1 的數，不可能和 n 有公因數（否則公因數會整除 1）。

**3. n^(nS) ≡ n (mod S)。** 因為 S ≡ 1 (mod n−1)、n ≡ 1 (mod n−1)，所以 nS − 1 ≡ 1·1 − 1 = 0 (mod n−1)，寫成 nS − 1 = (n−1)·t。那

> n^(nS−1) = (n^(n−1))^t ≡ 1^t = 1 (mod S)

兩邊乘 n：n^(nS) ≡ n (mod S)。

**4. 合起來。** 除以 n：n^(nS) 和 n 都是 n 的倍數，都餘 0。除以 S：第 3 步說餘數相同。n 和 S 互質，所以除以 n·S = a(n) 也餘數相同（這就是「中國剩餘定理」的簡單情形：除以兩個互質的數都同餘，除以乘積也同餘）。證畢。

## 第三步：n 是奇數時為什麼會失敗

同樣的計算，n 奇數時 (n−2)/2 不是整數，最後得到 S ≡ 1 + (n−1)/2 (mod n−1)，第 3 步就不成立了。實際例子：n = 5，a(5) = (3125 − 5)/16 = 195，5^195 除以 195 餘 125，不等於 5。（n = 3 剛好還成立：3^6 ≡ 3 (mod 6)。）

## 用到的高中以外的東西

- **同餘（mod）**：「a ≡ b (mod m)」就是 a 和 b 除以 m 的餘數相同。高中有教餘數，只是記號不同。
- **中國剩餘定理**：第 4 步用到它最簡單的情形，上面已經用白話說明。
- 其他（等比級數、二項式定理、數學歸納法）都是高中範圍。

## 怎麼確定沒錯

- **Lean 4**：`a058128_weak_psp` 對所有偶數 n 證明。
- **程式**：對 n ≤ 300 的所有偶數直接算 n^a(n) mod a(n)，全部成立（見程式說明）。

## 編輯可能問、你可以這樣答

- **問：證明大意？** 答：n 偶數時 a(n) = n·S，S = (n^(n−1)−1)/(n−1)² 和 n 互質、S ≡ 1 (mod n−1)，所以 n−1 整除 nS−1，於是 n^(nS) ≡ n (mod S)；除以 n 也同餘，合起來就得 n^a(n) ≡ n (mod a(n))。
- **問：奇數 n 呢？** 答：可能失敗，例如 n = 5：5^195 ≡ 125 (mod 195)。
