# 程式說明（高二版）：梯子圖

## 執行

在 repo 根目錄（要有 `discovery/` 資料夾，因為會用到 repo 的程式）：

```
python results\ladder-locating\code\check_ladder.py
```

約 20 秒，最後一行 `all checks passed`。

## 三種算法互相核對

1. **暴力（n ≤ 9）**：`ladder(n)` 列出鄰居，`is_ld`、`is_id` 照定義判斷，試遍 2^(2n) 種裝法。
2. **窗口 DP（n ≤ 15）**：`discovery/newseq/transfer.py`，把房間排成一列，只記最後 10 個房間的狀態。
3. **逐欄轉移矩陣（n ≤ 50 多）**：`discovery/newseq/strip.py`，一次加一整欄，並做「向量恆等式」檢查（`certify`）。

`series` 把生成函數展開成數列；主程式要求三種算法的數都和它一樣，而且 `certify` 找到的遞迴係數要剛好等於生成函數分母，才印 `all checks passed`。
