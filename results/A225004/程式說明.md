# A225004、A340896 程式說明（高二版）

## 程式在算什麼

只有一支：`results/A225004/code/check225004.py`。對 n = 1 到 150：

1. **最笨的方法**：把 n 的倍數 k·n 一路試到 k = n²（也就是倍數到 n³，遠超過證明說的「只要看到 n²」），找出因數個數少於 2·d(n) 的最大那個。
2. **公式**：只看 n 的因數 m，找 d(n·m) < 2·d(n) 的最大 m，答案是 n·m。
3. 兩種一樣、而且整除 n²，就代表證明說的對（至少在這範圍內，倍數再大也不會跑出更大的）。
4. 和 OEIS 前 21 項比對。
5. A340896：檢查「d(n²) < 2·d(n)」⇔「n 的不同質因數個數 ≤ 1」（也就是 n 是 1 或質數次方）。

## 怎麼自己跑

只要 Python 3：

```
python results\A225004\code\check225004.py
```

預設 n ≤ 150，需要算到 150³ ≈ 340 萬的因數個數，大約一兩分鐘、會用掉一些記憶體。想快一點可以加小一點的數字，例如 `check225004.py 60`。輸出：

```
n <= 60: brute force (multiples up to n^3) = formula, a(n) | n^2, DATA matches; A340896 n^2-in-row-n <=> prime power
```

## 程式逐段說明

- **算因數個數（篩法）**：
  ```python
  for i in range(1, M + 1):
      for j in range(i, M + 1, i):
          d[j] += 1
  ```
  對每個 i，把 i 的所有倍數 j 的計數加 1。跑完之後 d[j] 就是 j 的因數個數。這比對每個數分別找因數快很多。
- **最笨的方法**：`max(k * n for k in range(1, n*n + 1) if d[k*n] < 2*d[n])`，在所有 n 的倍數裡找符合條件的最大值。
- **公式**：`n * max(m for m in range(1, n+1) if n % m == 0 and d[n*m] < 2*d[n])`，只在 n 的因數 m 裡找。
- `assert best == formula`、`assert (n*n) % best == 0`：兩個方法一樣、而且整除 n²。
- **A340896**：`npf` 數 n 有幾個不同的質因數（逐一試 p，p 整除 n 且 p 是質數就算一個），檢查 `(d[n*n] < 2*d[n]) == (npf <= 1)`。

## 不用程式也能自己驗證

- n = 6：列出 6, 12, 18, 24, 30, 36 的因數個數（4, 6, 6, 8, 8, 9），因數個數 < 8 的最大倍數是 18。（再往後的 42, 48, 54, … 也都 ≥ 8，證明保證不用再看。）
- n = 10：d(10) = 4，10 的因數 m = 1, 2, 5, 10，d(10) = 4、d(20) = 6、d(50) = 6、d(100) = 9，最大的是 50。OEIS 第 10 項正是 50。
- A340896：n = 8 = 2³，d(64)/d(8) = 7/4 < 2，64 在第 8 列；n = 10，d(100)/d(10) = 9/4 > 2，100 不在第 10 列。
