# A225004、A340896 證明方法說明（高二版）

> 依據：紀錄 `records/DISC-0024/`、Lean 檔 `lean/Discovery/DivisorExp.lean`（定理 `exponents_le`，只形式化了關鍵的乘積不等式）、草稿 `a225004_a340896_oeis_edit_draft.md`。兩條分開送。

## 一句話結論

J. Lowell 的兩個猜想都**對**：

- **A225004**（2013）：a(n) 一定整除 n²。
- **A340896**（2021）：第 n 列含有 n² ⇔ n 是質數的次方（包括 1）。

## 第一步：定義和小例子

**d(n)：n 的正因數個數。** 例：d(12) = 6（1, 2, 3, 4, 6, 12）。

**因數個數公式（高中排列組合會學）：** 如果 n = p₁^a₁ × p₂^a₂ × …，那 d(n) = (a₁+1)(a₂+1)…。因為每個因數就是從每個質數選一個次方 0, 1, …, aᵢ。例：12 = 2² × 3，d = 3 × 2 = 6 ✓。

**A340896 的第 n 列：** n 的倍數中，因數個數**少於 2·d(n)** 的那些。**A225004(n)** 是第 n 列最大的那個（每列的最後一項）。

例：n = 6，d(6) = 4，要找 6 的倍數 k 使 d(k) < 8。

- 6：d = 4 ✓；12：d = 6 ✓；18：d = 6 ✓；24：d = 8 ✗；30：d = 8 ✗；36：d = 9 ✗；…

最大的是 18，所以 a(6) = 18。18 整除 36 = 6² ✓。而 36 = 6² 不在第 6 列（d(36) = 9 ≥ 8），6 也不是質數次方 ✓。

OEIS 前幾項：1, 4, 9, 16, 25, 18, 49, 64, 81, 50, …

## 第二步：A225004 的證明

設 k = n × m 是 n 的倍數。對每個質數 p，令 a = n 裡 p 的次方、x = m 裡 p 的次方。那

> d(nm) / d(n) = 每個質數的 (a + x + 1)/(a + 1) 乘起來

每一項都 ≥ 1（x ≥ 0）。如果某個質數 x ≥ a + 1（m 裡 p 的次方比 n 裡多，包括 n 沒有、m 有的新質數，那時 a = 0、x ≥ 1），那一項

> (a + x + 1)/(a + 1) ≥ (2a + 2)/(a + 1) = 2

整個比值就 ≥ 2，d(nm) ≥ 2d(n)，不在這一列。

所以在這一列裡的倍數，每個質數都 x ≤ a，也就是 m 整除 n。那 k = nm 整除 n × n = n²。最大的那個 a(n) 當然也整除 n²。

## 第三步：A340896 的證明

看 k = n²，比值是

> d(n²) / d(n) = 每個質數的 (2a + 1)/(a + 1) 乘起來

- **n = 1 或 n 是質數次方 p^a：** 只有一項，(2a+1)/(a+1) = 2 − 1/(a+1) < 2。所以 d(n²) < 2d(n)，n² 在第 n 列。（n = 1 時比值是 1。）
- **n 至少有兩個不同質因數：** 每一項 (2a+1)/(a+1) 在 a ≥ 1 時 ≥ 3/2（a = 1 時剛好 3/2，a 越大越接近 2）。兩項以上乘起來 ≥ 3/2 × 3/2 = 9/4 > 2。所以 n² 不在第 n 列。

例：n = 6 = 2 × 3，比值 = 3/2 × 3/2 = 9/4，d(36) = 9 = 9/4 × 4 ✓。

這兩個證明只用到因數個數公式和分數大小比較，完全在高中範圍。

## 第四步：怎麼確定沒錯

- **程式**：對 n ≤ 150，把 n 的倍數一路掃到 n³（遠超過證明說的範圍），找出真正最大的那個，和公式比對、和 OEIS 資料比對；A340896 的「n² 在第 n 列 ⇔ 質數次方」也逐一檢查（見程式說明）。

## 編輯可能問、你可以這樣答

- **問：A225004 證明大意？** 答：d(nm)/d(n) 是每個質數 (a+x+1)/(a+1) 的乘積，每項 ≥ 1，只要有一個質數 x > a 那項就 ≥ 2。所以 d(nm) < 2d(n) 逼得 m | n，nm | n²。
- **問：A340896？** 答：d(n²)/d(n) = Π(2a+1)/(a+1)；一個質因數時 < 2，兩個以上時每項 ≥ 3/2，乘起來 ≥ 9/4 > 2。
