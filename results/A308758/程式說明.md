# A308758 程式說明（高二版）

> 依據：`results/A308758/code/check_a308758.py`、`records/DISC-0028/experiment.md`、草稿裡的 PARI 指令。下面的輸出都實際跑過。

## 程式在算什麼

`check_a308758.py` 用四種方法檢查同一件事：

1. **暴力數（`parts4`、`tri`）**：用三層迴圈把 n 的所有 4 部分分拆 a ≥ b ≥ c ≥ d 列出來，分別把 a、b、c、d 加總；同樣把周長 m 的三角形 x ≤ y ≤ z、x + y > z 列出來加總。然後檢查四條差分式，n 從 1 到 200。
2. **對應本身（`check_bijection`）**：對每個 n，把所有 (a,a,c,d) 用 (c, a, a+d−1) 變過去，看結果的集合是不是剛好等於「周長 n−1 的所有三角形」，個數也相同。
3. **生成函數（`check_gf_exact`）**：把我們推出來的分式和 Barker 的分式交叉相乘，用整數多項式逐項比，要求完全一樣（8 條條目都比）。另外 `check_gf` 用前 120 項當額外的檢查。
4. **OEIS 資料（`check_oeis`）**：如果有下載離線 OEIS，就把 9 條條目存的所有項拿來和暴力結果比。

## 怎麼跑

在 repo 根目錄：

```
python results/A308758/code/check_a308758.py 200
```

大約 7 秒，輸出：

```
identities and bijection: n <= 200 OK; g.f.s of A308733/58/59/60/75 equal Barker's (exact polynomial identities); triangle g.f.s A307686/A308096/A307966 too; OEIS terms: A308760:49 A308759:51 A308758:53 A308733:55 A026810:58 A307686:59 A308096:56 A307966:56 A005044:74
```

最後那串是「每條條目比了幾項」。沒下載 OEIS 時會顯示 skipped。數字 200 可以改小（更快）或改大。

## 怎麼自己驗（不靠我們的程式）

在 PARI/GP（OEIS 常用的計算軟體，免費）裡分兩行輸入：

```
s(n)=my(t=0);forpart(p=n,t+=p[2],,[4,4]);t
u(m)=my(t=0);for(x=1,m\3,for(y=x,(m-x)\2,if(x+y>m-x-y,t+=x)));t
```

`s(n)` 是 A308758(n)：`forpart` 列出 n 恰好分 4 份的分拆，由小排到大，所以 `p[2]` 是第三大。`u(m)` 是 A307686(m)：x 是最短邊，y 是中間邊，z = m − x − y。接著：

```
vector(40,n,s(n+1)-s(n)-u(n))
```

應該得到 40 個 0（我們在 PARI 2.15.4 跑過，結果全是 0）。也可以手算小的例子：s(7) = 4、s(6) = 2、u(6) = 2。

## 程式驗不到的

程式只驗到 n = 200；對所有 n 成立靠的是「證明方法說明」裡的一一對應。生成函數那部分是完整證明（多項式恆等），不是取樣。
