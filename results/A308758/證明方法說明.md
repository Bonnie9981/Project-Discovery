# A308758 證明方法說明（高二版）

> 依據：證明頁 `paper/a308758-four-parts.md`、紀錄 `records/DISC-0027/`（proof.md、experiment.md、critic.md）、草稿 `a308758_oeis_edit_draft.md`。沒有 Lean，是紙上證明加程式驗算。

## 一句話結論

「把 n 拆成 4 個正整數（不計順序）時，第三大那個數的總和」每往上加一步多出來的量，剛好等於「周長 n−1 的整數邊三角形，最短邊的總和」：

> A308758(n) − A308758(n−1) = A307686(n−1)（n ≥ 2）

同一個方法還給出另外三條同類式子，並證明了 Colin Barker 2019 年在 8 條條目上留下的「猜想生成函數」全部正確。

## 第一步：兩種東西

**4 部分分拆。** 把 n 寫成 a + b + c + d，四個都是正整數，排成 a ≥ b ≥ c ≥ d。例：n = 7 有三種：(4,1,1,1)、(3,2,1,1)、(2,2,2,1)。第三大的數 c 分別是 1、1、2，加起來 4，所以 A308758(7) = 4。

**整數邊三角形。** 三邊 x ≤ y ≤ z 都是正整數，而且要能圍成三角形：**兩短邊之和大於最長邊**，x + y > z。例：周長 6 只有 (2,2,2)（(1,2,3) 不行，因為 1 + 2 = 3 不大於 3）。最短邊總和 A307686(6) = 2。

驗算一下：A308758(7) − A308758(6)。n = 6 的分拆是 (3,1,1,1)、(2,2,1,1)，c 都是 1，總和 2。所以差是 4 − 2 = 2，正好等於 A307686(6) = 2。✓

## 第二步：把 n−1 的分拆「搬」到 n

把 n−1 的每個分拆，最大的 a 加 1：(a,b,c,d) → (a+1,b,c,d)。
- 結果還是 n 的 4 部分分拆，而且一定 a+1 > b。
- 不同的分拆搬過去還是不同（只要把 a 減 1 就搬回來了）。
- 反過來，n 的分拆只要 a > b，把 a 減 1 就是 n−1 的分拆。

所以 n 的分拆分成兩堆：**a > b 的那堆**，和 n−1 的分拆一個對一個，而且 c 沒變；**a = b 的那堆**，形狀是 (a, a, c, d)。

因此「n 的 c 總和 − (n−1) 的 c 總和」= 「a = b 那堆的 c 總和」。

## 第三步：關鍵對應

把 (a, a, c, d) 對應到三角形 (x, y, z) = (c, a, a + d − 1)。檢查：
- 周長：c + a + (a + d − 1) = (2a + c + d) − 1 = n − 1。✓
- 排序：c ≤ a（因為 a ≥ c）；a ≤ a + d − 1（因為 d ≥ 1）。✓
- 能圍成三角形：x + y > z 就是 c + a > a + d − 1，也就是 c > d − 1，即 c ≥ d，本來就成立。✓

反過來，三角形 (x, y, z) 對應回 (y, y, x, z − y + 1)，一樣每項都檢查得過。兩個方向互相抵消，所以是一對一。

這個對應下 c 正好是最短邊 x，所以「a = b 那堆的 c 總和」=「周長 n−1 三角形的最短邊總和」，證完。

用同一個對應：a 對到中間邊 y、d 對到 z − y + 1，就得到另外三條：
- A308759(n) − A308759(n−1) = A308096(n−1)（第二大 ↔ 中間邊）
- A308733(n) − A308733(n−1) = A307966(n−1) − A308096(n−1) + A005044(n−1)（最小部分）
- A308760(n) − A308760(n−1) = A026810(n−1) + A308096(n−1)（最大部分；搬的時候 a 加了 1，所以多一個「n−1 的分拆個數」）

注意：只數「個數」的版本（A026810 的差分是 A005044）OEIS 早就有了，我們的是「加權」版本。

## 第四步：生成函數（超出高二，簡述）

**生成函數**是把一列數 a(0), a(1), a(2), … 寫成 a(0) + a(1)x + a(2)x² + …，用代數式子表示。這是大學組合數學的工具。

做法：令 d = y4、c = y4 + y3、b = y4 + y3 + y2、a = 全部加起來，就有 n = y1 + 2y2 + 3y3 + 4y4。這樣每個分拆對應一組 (y1, y2, y3, y4)，可以把「c 的總和」直接寫成分式。把我們的分式和 Barker 寫的分式交叉相乘，兩邊是完全相同的多項式（程式逐項算，兩個不同的程式都算過），所以他的猜想成立。三角形那三條再用上面的差分式推出來。

## 自己寫 OEIS 留言時要講的重點

1. n−1 的分拆最大部分加 1，就得到 n 裡 a > b 的全部分拆，c 不變。
2. 剩下的 (a,a,c,d) 和周長 n−1 的三角形 (c, a, a+d−1) 一一對應；三角不等式正好是 c ≥ d。
3. 所以差分等於三角形最短邊的總和。
4. Barker 的 g.f.：用 y1+2y2+3y3+4y4 寫出生成函數，交叉相乘是恆等式。
5. 一次只送 A308758 一條，其他七條等編輯回覆再說；用自己的話寫，不要照抄草稿。
