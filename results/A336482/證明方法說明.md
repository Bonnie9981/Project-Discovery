# A336482、A119706 證明方法說明（高二版）

> 依據：證明頁 `paper/a336482-records.md`、紀錄 `records/DISC-0029/`、草稿 `a336482_a119706_oeis_edit_draft.md`。沒有 Lean，是紙上證明加程式驗算。

## 一句話結論

1. 把 n 的所有「組合」的「破紀錄次數」加起來（A336482），等於「最大部分的總和」（A102712）從 n−1 到 n 增加的量。
2. Mathar 2025 年在 A119706 留的猜想「長度 n 的 0/1 字串，最長連續 1 的總長 = A102712(n+1) − 2^n」是對的。

## 第一步：名詞

**組合（composition）。** 把 n 寫成正整數的和，**順序有差**。例：3 = 3 = 2+1 = 1+2 = 1+1+1，共 4 種。一般 n 有 2^(n−1) 種（n−1 個空隙，每個空隙切或不切）。

**最大部分。** 3 的四種組合最大部分是 3、2、2、1，總和 8 = A102712(3)。

**破紀錄（左到右極大值）。** 從左讀到右，比前面所有數都大的就算一次破紀錄，第一個數一定算。例：1+2 有兩次（1、2），2+1 只有一次。3 的四種：3（1 次）、2+1（1 次）、1+2（2 次）、1+1+1（1 次），共 5 = A336482(3)。

驗算：A102712(3) − A102712(2) = 8 − 3 = 5。✓（2 的組合 2、1+1，最大部分和 2+1 = 3。）

## 第二步：拆成「每個 j 各自成立」

- 最大部分 = 「有幾個 j 滿足 最大部分 ≥ j」。例如最大是 3，就是 j = 1、2、3 三個。所以 A102712(n) = Σ_j A_j(n)，A_j(n) 是「最大部分 ≥ j 的組合個數」。
- 一個組合「在 j 破紀錄」，等於說「第一個 ≥ j 的數剛好是 j」（前面都比 j 小，j 第一次出現就破紀錄）。所以 A336482(n) = Σ_j B_j(n)，B_j(n) 是「第一個 ≥ j 的數剛好等於 j」的組合個數。

只要證明每個 j 都有 **B_j(n) = A_j(n) − A_j(n−1)**，加起來就是結論。

小例子 j = 2、n = 3：B_2(3) 數的是 2+1、1+2，共 2 個；A_2(3) = 3（3、2+1、1+2），A_2(2) = 1（2），3 − 1 = 2。✓

## 第三步：用生成函數證每個 j（超出高二，簡述）

生成函數把一列數寫成 a(0) + a(1)x + a(2)x² + …，像無窮等比級數那樣做代數（大學組合數學內容）。

- 「每個數都 < j」的組合，生成函數 N_j = 1/(1 − x − x² − … − x^(j−1))。
- B_j 的組合長成「前段（每個數都 < j）＋ j ＋ 後段（隨便）」，所以生成函數是三段相乘。
- A_j =「全部組合」減「每個數都 < j 的組合」。
- 「n 減 n−1」在生成函數上就是乘 (1 − x)。

把式子展開，只用到 (1 − 2x + x^j)·N_j = 1 − x 這個等式（就是等比級數求和），兩邊就相等。細節在證明頁。

## 第四步：Mathar 的猜想（高二看得懂的一一對應）

長度 n 的 0/1 字串，對應到 n+1 的組合：把 n+1 個 1 排成一排，第 i 位是 1 就把第 i 和第 i+1 個 1 黏在一起。

例：n = 3、字串 110 → 1 1 1 1 中，前兩個空隙黏、第三個不黏 → 3+1。字串裡一段（左右都碰到 0 或邊界的）連續 k 個 1，就變成一個 k+1 的數；所以「最大部分 = 最長連續 1 的長度 + 1」。

把 2^n 個字串加起來：A102712(n+1) = A119706(n) + 2^n，就是猜想。

## 判定與限制

- 狀態：兩條都是 `SUPPORTED_KNOWN`（審查指出：A336482 那條可由 A382312 的生成函數微分得到；A119706 那條可由兩個既有生成函數相減得到；只是 OEIS 上沒人寫出來）。紙上證明加程式，**沒有 Lean**。
- 新穎性：只查了 OEIS 離線全庫（2026-11-27 的快照 091a90f51479）和 A119706 引用的一篇 arXiv 論文的前 36 頁。兩條在這個範圍內都沒人寫成定理（第二條還標「Conjecture」），但都能由條目裡已有的生成函數一步推出，所以算**已知**。兩條都不難，**不宣稱新**。

## 自己寫 OEIS 留言時要講的重點

1. A119706：0/1 字串和 n+1 的組合一一對應，連續 k 個 1 ↔ 一個 k+1，所以最大部分 = 最長連續 1 + 1。
2. A336482：在 j 破紀錄 ⇔ 第一個 ≥ j 的數是 j；最大部分 = 有幾個 j ≤ 最大部分；每個 j 用生成函數證 B_j(n) = A_j(n) − A_j(n−1)。
3. 兩條分開送，先送 A119706；用自己的話寫。
