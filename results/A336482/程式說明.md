# A336482、A119706 程式說明（高二版）

> 依據：`results/A336482/code/check_a336482.py`、`records/DISC-0029/experiment.md`、草稿裡的 PARI 指令。輸出都實際跑過。

## 程式在算什麼

1. **暴力（`compositions`）**：n 的組合用 n−1 個「切或不切」的位元表示，全部列出來，算每個組合的最大部分（加起來是 A102712）和破紀錄次數（加起來是 A336482）。再列出所有長度 n 的 0/1 字串，算最長連續 1（加起來是 A119706）。n ≤ 18 時檢查兩條結論，以及每個 j 的細分式 B_j(n) = A_j(n) − A_j(n−1)。
2. **另一種算法（`fast`）**：不列組合，用證明裡的分解式做遞推（所以不算完全獨立；真正獨立的檢查是和 OEIS 存的項比），算到 n = 79，先確認和暴力在 n ≤ 18 一致，再檢查差分關係。
3. **OEIS 資料**：三條條目存的所有項（32～34 項）都拿來比。

## 自己驗（PARI/GP）

照草稿把 `L(n)`、`R(n)` 兩行分開輸入，再跑 `vector(15,n,R(n+1)-L(n+1)+L(n))`，應得 15 個 0（PARI 2.15.4 跑過）。`vector(8,n,L(n))` 是 1, 3, 8, 19, 43, 94, 202, 428；`vector(8,n,R(n))` 是 1, 2, 5, 11, 24, 51, 108, 226。也可以手算：3 的四種組合破紀錄共 5 次。
