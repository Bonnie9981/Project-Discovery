# A334504 證明方法說明（高二版）

> 這份是給送出者本人看的中文導讀，內容依據英文證明 `paper/a334504.pdf`（原始檔 `results/A334504/a334504.tex`）。正式內容以英文證明和 Lean 檔為準。

## 一句話結論

OEIS A334504 在問：「一圈 w 個格子、只有一格亮著，照『規則 26』一直更新，最後會以多長的週期重複？」條目上有人在 2024 年猜了兩個公式，我們證明兩個都對：

- **w 是奇數（w ≥ 3）**：週期 = w × 2^⌊log₂ w⌋。例：w = 5，⌊log₂ 5⌋ = 2，週期 = 5 × 4 = 20。
- **w 是偶數（w = 2n+2，n ≥ 1）**：週期 = A268754(n)，也就是「規則 90 在一條 n 格、兩端外面都是空格的線上」的週期。

## 第一步：先搞懂定義

**格子和狀態。** 把 w 個格子排成一個圓圈，編號 0, 1, …, w−1。每格只有兩種狀態：亮（1）或暗（0）。因為是圓圈，格子 w−1 的右邊是格子 0。

**規則 26 怎麼更新。** 每一步，所有格子「同時」更新。每格看自己和左右鄰居共三格（左、中、右），照下表決定下一步亮不亮：

| 左中右 | 111 | 110 | 101 | 100 | 011 | 010 | 001 | 000 |
|---|---|---|---|---|---|---|---|---|
| 下一步 | 0 | 0 | 0 | 1 | 1 | 0 | 1 | 0 |

把下一排讀成二進位 00011010，正好是十進位 26，所以叫「規則 26」（這是 Wolfram 的命名法）。

**小例子：w = 5。** 一開始只有格子 0 亮（■ 亮、□ 暗）：

```
t=0  ■□□□□
t=1  □■□□■
t=2  □□■■□
t=3  □■■□■
t=4  □■□□□
...
```

一直算下去，第 20 步才第一次回到 ■□□□□，之後每 20 步重複一次。所以 a(5) = 20，和公式 5 × 2² = 20 一樣。w = 3 時是 3 × 2 = 6，也可以自己手算 6 步驗證（3 格很快）。

**週期的意思。** 狀態只有有限多種（2^w 種），所以一直算下去一定會重複。「最後的週期」是指重複之後，每隔幾步就回到同一個狀態的最小步數。前面還沒進入循環的那段叫「暫態」。

## 第二步：證明的大方向

### 奇數寬度：「巴斯卡三角形在圓圈上滑動」

關鍵觀察：在一條無限長的線上，規則 26 從一格亮出發，畫出來的圖案和另一個簡單的規則「規則 90」一模一樣。規則 90 的意思是「下一步 = 左鄰 XOR 右鄰」（XOR：兩個一樣得 0，不一樣得 1，也就是「相加後除以 2 的餘數」）。

規則 90 畫出來的就是**巴斯卡三角形每個數除以 2 的餘數**（奇數亮、偶數暗），也就是有名的謝爾賓斯基三角形。原因：巴斯卡三角形的規則是「下面的數 = 左上 + 右上」，取 mod 2 就變成 XOR。

為什麼規則 26 和規則 90 一樣？比對兩個表，只有「110」這種情況不同（規則 26 給 0，規則 90 給 1）。而巴斯卡三角形 mod 2 的每一排都不會有兩格相鄰都亮，所以「110」根本不會出現。

在圓圈上，圖案繞一圈後會撞到自己，所以要另外處理。證明寫出了**每一步每一格的精確公式**（引理「closed form」）：

> 第 t 步，格子 i 亮 ⇔ s = (i + t) 除以 w 的餘數是偶數，而且 C(t, s/2) 是奇數。

這裡 C(t, j) 就是高中學的組合數「t 取 j」。白話：這是一個「巴斯卡三角形 mod 2 的第 t 排」被放進一個寬 w 的窗口，而且窗口每步往左滑一格。

**這個公式怎麼證明？** 用數學歸納法：t = 0 時對（只有格子 0 亮，因為 C(0,0) = 1）。假設第 t 步對，檢查第 t+1 步。把每格的三個鄰居代進規則 26 的表，分成四種情況：

1. s 是 ≥ 2 的偶數：中間那格是暗的，規則 26 在「中間暗」時就是「左 XOR 右」，剛好是巴斯卡的「左上 + 右上 mod 2」。
2. s 是 ≥ 3 的奇數：左右兩格都是暗的（奇數位置一律暗），結果是 0。對。
3. s = 1：這是圖案繞一圈後撞到自己的地方。三格是「? 1 0」，查表得 0。這裡規則 26 和規則 90 不一樣，剛好把繞回來的部分切掉。
4. s = 0：因為 w 是奇數，w−2 是奇數，左邊那格一定暗；右邊是 C(t,0) = 1 亮。查表「0 ? 1」得 1。對。

**奇數**這個條件只在第 4 種情況用到：它讓窗口兩端都落在「偶數位置」，圖案的左邊緣才能一直保持住。

**什麼時候回到起點？** 回到起點（只有格子 0 亮）需要兩件事同時成立：

- 窗口滑回原位：t 是 w 的倍數。
- 巴斯卡第 t 排在窗口內除了最左邊都是偶數：證明裡用「Lucas 定理（p = 2 的情形）」得到，這等於 t 是 2^k 的倍數，k = ⌊log₂ w⌋。

w 是奇數，和 2^k 沒有公因數，所以「兩個都整除 t」等於「w × 2^k 整除 t」。最小的這種 t 就是 w × 2^k，也就是週期。

> **超出高二的部分：Lucas 定理。** 這個定理說 C(t, j) 是奇數 ⇔ 把 t 和 j 寫成二進位後，j 的每個 1 都出現在 t 也是 1 的位置。證明只用到它的兩個推論，而且用一個高中可以理解的式子推出：在「mod 2」的世界裡 (1+x)² = 1 + 2x + x² = 1 + x²（因為 2x 是偶數，mod 2 等於 0）。所以 (1+x)^(2a) = (1+x²)^a，比較係數就得到 C(2a, 2c) 和 C(a, c) 同奇偶、C(2a, 奇數) 是偶數。直觀上可以自己驗證：巴斯卡三角形第 4 排 1 4 6 4 1，中間全是偶數；第 8 排 1 8 28 56 70 56 28 8 1，中間也全是偶數。2 的次方那排中間全偶，就是這個道理。

### 偶數寬度：「對折成一條線」

w = 2m 是偶數時，從第 1 步開始，圓圈上的圖案永遠**左右對稱**，而且格子 0 和格子 m（正對面）永遠是暗的。所以只要看半圈（格子 1 到 m−1，共 n = m−1 格）就夠了，另外半圈是鏡像。

證明分幾步：

1. **奇偶分開**：在那條 n 格的線上，第 t 步亮的格子位置都和 t 同奇偶。因為每格的新值只看左右兩格，而左右兩格位置同奇偶。
2. **不會出現「110」**：因為亮的格子都是同奇偶，不會有兩格相鄰都亮，所以規則 26 在這些狀態上就是規則 90。
3. **一步一步對上**：檢查「圓圈走一步」等於「把半圈那條線用規則 90（兩端外面當作暗）走一步再鏡像貼回去」。格子 0 左右看到的是同一個值（鏡像），XOR 起來是 0，所以一直暗；格子 m 同理。
4. **第 1 步**：從格子 0 亮出發，第 1 步亮的是格子 1 和 w−1，正好是「線的左端一格亮」的鏡像。
5. **週期一樣**：這個「貼回圓圈」的對應是一對一的，所以圓圈的狀態重複 ⇔ 線的狀態重複，週期相同；只是圓圈多了第 0 步，暫態多 1。

而 OEIS A268754 的程式算的正是「n 格的線、規則 90、兩端外面是暗格、從左端一格亮出發」的週期，所以 a(2n+2) = A268754(n)。

小例子：w = 6（n = 2）。

```
t=0  ■□□□□□
t=1  □■□□□■
t=2  □□■□■□
t=3  □■□□□■
```

格子 0 和格子 3 一直暗，格子 1、2 和格子 5、4 互為鏡像，週期 2 = A268754(2)。

- **數值檢查**：兩支獨立寫的模擬程式，對奇數 w ≤ 129、偶數對應 n ≤ 40 都和公式一致（見程式說明）。
- **沒被形式化的地方**（英文證明裡有誠實寫出來）：Lean 裡的 b_t(j) 是用巴斯卡規則定義的，沒有另外證明它等於 C(t,j) mod 2（但主定理沒用到這件事）；Lean 的定義和 OEIS 的定義是用人工比對加數值對照確認的（`spec_audit.md`）。

## 編輯可能問、你可以這樣答

- **問：奇數寬度的證明大意？** 答：每一步的狀態都可以明確寫出來，是巴斯卡三角形 mod 2 的一排放在一個繞著圓圈滑動的窗口裡；回到起點要窗口轉回原位（w 整除 t），而且那排中間全偶（2^k 整除 t）。
- **問：偶數寬度的證明大意？** 答：從第 1 步起狀態左右對稱、格子 0 和 m 永遠暗，所以等於規則 90 在 n = m−1 格兩端為空的線上跑，那正是 A268754 算的東西。
- **問：為什麼 w = 1 不算？** 答：只有一格時它左右鄰居都是自己（111），第一步就全暗，暫態是 1，不符合「從頭就循環」的說法；公式也是從 n ≥ 1 開始。
