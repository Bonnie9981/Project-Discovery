# A215461、A215462 程式說明（高二版）

## 程式在算什麼

檢查程式和 A231897 共用一支：`results/A231897/code/verify.py`。它對 A215461、A215462 做：

1. 用兩種完全不同的寫法算出每一項，n < 600 都要一樣。
2. 和 OEIS 的資料比對（A215461 前 74 項、A215462 前 80 項）。
3. 找出所有 a(n) = 0 的 n，掃到 n < 200,000。
4. 檢查 Lean 證明裡用的「拆法」（證人）真的對，到 n < 500,000。

## 怎麼自己跑

1. 裝 Python 3（python.org，安裝時勾「Add Python to PATH」）。
2. 到 https://github.com/Bonnie9981/Project-Discovery 按「Code」→「Download ZIP」，解壓縮（也可以只把這一支檔案存下來，它不需要其他檔案）。

## 每一段在做什麼

- **`sieve`（埃拉托斯特尼篩法）**：先列出 2 到 N 的所有數，從 2 開始把每個質數的倍數劃掉，剩下的就是質數。很快就能知道 N 以內每個數是不是質數。
- **寫法 1 `impl1`：照條目 FORMULA 的公式。** 條目把「2i+1 是不是質數」記成 p(i)（是就 1）和 c(i) = 1 − p(i)，然後做「卷積」：對所有 i + j = n − 1 加總 p(i)·c(j) + c(i)·p(j)（A215461）或 c(i)·c(j)（A215462）。白話：2n = (2i+1) + (2j+1) 的每一種拆法，看兩個數是不是質數，符合就算 1。
- **寫法 2 `impl2`：直接列出所有拆法。** x 從 1 開始每次加 2（只取奇數），y = 2n − x，用「試除法」（從 2 開始試到 √x，看有沒有人整除它）判斷質數，數符合條件的拆法。這和寫法 1 用的質數判斷方法、計數方式都不同。
- **`zeros_fast`**：找 a(n) = 0 的 n。對每個 n 只要找到一個拆法就停下來（不用全部數完），所以可以掃到 200,000。
- **證人檢查**：Lean 證明時給出具體的拆法（A215461 用 3、5、7 其中一個；A215462 用 9、25、35 其中一個）。程式對 n < 500,000 檢查這些拆法真的是「質數 + 非質數」或「非質數 + 非質數」。

## 不用程式也能自己驗證

- 拿 2n = 50（50 ÷ 6 餘 2）：50 = 35 + 15，35 = 5×7、15 = 3×5，兩個都不是質數 ✓。
- 2n = 40（餘 4）：40 = 25 + 15 ✓。2n = 42（餘 0）：42 = 9 + 33 ✓。
- 2n = 38：自己列出所有拆法，確認每一組都有質數（證明說明裡有列）。
