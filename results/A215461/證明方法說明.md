# A215461、A215462 證明方法說明（高二版）

> 依據：紀錄 `records/DISC-0018/`、Lean 檔 `lean/Discovery/NeverEasy.lean`（定理 `a215461_pos`、`a215462_pos`）、草稿 `a215461_a215462_oeis_edit_draft.md`。兩條序列分開送出，但證明很像，放在一起說明。

## 一句話結論

- **A215461(n)**：把 2n 拆成「一個奇質數 + 一個奇數非質數」的方法數。條目猜：n > 5 時 a(n) > 0。**對**。
- **A215462(n)**：把 2n 拆成「兩個奇數非質數」的方法數。條目猜：n > 19 時 a(n) > 0。**對**，而且這就是 AIME 1984 第 14 題（「38 是最大的、不能寫成兩個奇合數相加的偶數」）。

兩個都是習題程度，不宣稱新。

## 第一步：定義和小例子

這兩條序列都只用奇數拆，並且把 1 算成「非質數」（條目的例子 36 = 1 + 35 就是這樣算）。a + b 和 b + a 算兩種。

**A215461，n = 5（2n = 10）：** 奇數拆法有 1+9、3+7、5+5、7+3、9+1。

- 1+9：兩個都不是質數 ✗
- 3+7、5+5、7+3：兩個都是質數 ✗

沒有「一個質數一個非質數」的拆法，所以 a(5) = 0。

**A215461，n = 6（2n = 12）：** 3 + 9（3 是質數、9 = 3×3 不是）✓，所以 a(6) > 0。

**A215462，n = 19（2n = 38）：** 38 = 1+37、3+35、5+33、7+31、9+29、11+27、13+25、15+23、17+21、19+19（再加左右對調）。每一組都至少有一個質數（37、3、5、7、29、11、13、23、17、19），所以 a(19) = 0。

## 第二步：A215461 的證明（n ≥ 6）

看三個數 2n−3、2n−5、2n−7。它們是三個連續的奇數（每次差 2），除以 3 的餘數各不相同（差 2 和差 4 除以 3 分別餘 2 和 1），所以**其中一個一定是 3 的倍數**。

n ≥ 6 時，最小的 2n−7 ≥ 5，所以那個 3 的倍數至少是 9（奇數的 3 倍數有 3, 9, 15, …，而它 ≥ 5，所以不是 3），因此**不是質數**。

把它和對應的 3、5 或 7（都是奇質數）配對：

> 2n = 3 + (2n−3) 或 5 + (2n−5) 或 7 + (2n−7)

就是一種「奇質數 + 奇非質數」的拆法，所以 a(n) > 0。

例：2n = 20 → 20−3 = 17、20−5 = 15、20−7 = 13，15 是 3 的倍數，20 = 5 + 15 ✓。

## 第三步：A215462 的證明（n ≥ 20，也就是 2n ≥ 40）

看 2n 除以 6 的餘數（2n 是偶數，只可能餘 0、2、4）：

| 2n 除以 6 餘 | 拆法 | 為什麼兩個都不是質數 |
|---|---|---|
| 0 | 9 + (2n − 9) | 9 = 3×3；2n − 9 是奇數、是 3 的倍數、≥ 31，所以 ≥ 33 不是質數 |
| 4 | 25 + (2n − 25) | 25 = 5×5；2n − 25 是奇數、是 3 的倍數（4 − 25 = −21 是 3 的倍數）、≥ 15 |
| 2 | 35 + (2n − 35) | 35 = 5×7；2n − 35 是奇數、是 3 的倍數（2 − 35 = −33）、2n ≥ 44 所以 ≥ 9 |

三種情況第二個數都是「≥ 9 的奇數 3 倍數」，不是質數。所以 2n ≥ 40 都拆得出來，a(n) > 0。

## 第四步：邊界（哪些 n 會是 0）

證明只說「n 夠大時不是 0」。比較小的 n 是用程式直接算的（不在 Lean 裡）：

- A215461 只有 n = 0, 1, 5 是 0。
- A215462 只有 n = 0, 2, 3, 4, 6, 7, 10, 16, 19 是 0。

程式掃到 n < 200,000（審查員另外掃到 2,000,000）都一樣。其實有了上面的證明，大的 n 一定不是 0，掃描只是多一層確認。

## 第五步：怎麼確定沒錯

- **Lean 4**：`a215461_pos`、`a215462_pos` 對所有夠大的 n 證明，而且明確給出拆法（「證人」）。程式也把 Lean 用的證人對 n < 500,000 數值檢查過。
- **程式**：兩種獨立寫法對 n < 600 每一項都一樣，也和 OEIS 資料（74 項、80 項）一致。

## 編輯可能問、你可以這樣答

- **問：A215461 的證明？** 答：2n−3、2n−5、2n−7 其中一個是 3 的倍數，n ≥ 6 時它 ≥ 9，所以是奇非質數，配上 3、5 或 7。
