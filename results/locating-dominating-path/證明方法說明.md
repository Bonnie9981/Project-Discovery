# 路徑和環上的「定位支配集」有幾個（高二版證明說明）

對應：OEIS 新序列草稿「Number of locating-dominating sets in the path graph P_n」和 A001642 的編輯草稿。英文完整證明：`paper/locating-dominating-paths.md`。

## 1. 問題是什麼

想像一條走廊有 n 個房間排成一排，編號 1 到 n，相鄰房間有門相通（這就是「路徑圖 P_n」）。我們要在一些房間裝感應器，裝了感應器的房間集合叫 S。

小偷躲在**沒裝感應器**的某個房間時，隔壁裝了感應器的房間會響。我們要求：

1. **每個沒裝的房間都至少有一個隔壁有裝**（不然小偷躲那裡就沒人知道，這叫「支配」）；
2. **兩個不同的沒裝房間，響起來的感應器組合不能一樣**（不然分不出小偷在哪一間，這叫「定位」）。

同時滿足這兩點的 S 叫「定位支配集」。問題：n 個房間時，有幾種裝法？答案記成 a(n)。

n = 3 時：裝 {1,2}、{2,3}、{1,3}、{1,2,3} 都可以；只裝 {2} 不行，因為小偷在 1 號或 3 號，響的都只有 2 號，分不出來。所以 a(3) = 4。

## 2. 把裝法寫成 0 和 1 的字串

第 i 個房間有裝寫 1、沒裝寫 0。例如 n = 7 的 1001011 表示裝在 1、4、6、7 號。

看每兩個相鄰的 1 之間夾了幾個 0，叫「空隙」；最左邊 1 的左邊、最右邊 1 的右邊的 0 也算空隙（叫「兩端空隙」）。

## 3. 關鍵觀察（引理 1）

**條件 1（每個 0 都碰得到 1）** 等於：中間的空隙最多 2 個 0，兩端的空隙最多 1 個 0。
理由：中間如果有 000，中間那個 0 左右都是 0；開頭如果是 00，第 1 間只有第 2 間一個鄰居，也是 0。

**條件 2（分得出來）**：在一條路上，每個房間最多兩個鄰居。如果兩個 0 號房間響的感應器一樣，它們一定共用一個裝了感應器的鄰居 p，也就是 p 的左右兩邊 p−1、p+1，而且它們都**沒有別的**有裝的鄰居。這等於：p 左邊再過去一格（p−2）不是 1 或根本不存在，右邊（p+2）也一樣。

我們把「中間的 2 個 0」或「兩端的 1 個 0」叫做**長空隙**。上面那句話就是：p 的左右兩邊都是長空隙。所以：

> **裝法合格 ⇔ 中間空隙 ≤ 2、兩端空隙 ≤ 1，而且沒有一個 1 被兩個長空隙夾住。**

## 4. 數一數：只要記一件事

從左往右寫字串，一次寫「一個 1 加上它後面的空隙」。要知道下一步能不能放長空隙，只要記得**上一個空隙長不長**（兩種狀態）。把每種寫法依長度記帳，整理出

a(n) = a(n−1) + a(n−2) + a(n−4) + a(n−5)（n ≥ 6），開頭是 1, 3, 4, 9, 15。

（數學上把「長度 n 的寫法數」放進 x^n 的係數，就得到生成函數 x(1+2x+2x³+x⁴)/(1−x−x²−x⁴−x⁵)，兩狀態的計算是 2×2 矩陣的反矩陣，高中矩陣就夠。）

為什麼是 1、2、4、5 往回看？看下面環的情形最清楚。

## 5. 環的情形：鋪磚

如果房間排成一圈（環 C_n），就沒有兩端。n ≥ 5 時，同樣的推理得到：每個空隙 ≤ 2，而且不能連續兩個空隙都是 2。

把每個 1 和它後面的 0 黏成一塊：「1」「10」「100」。規則說「100」後面不能再接「100」，所以把每個「100」跟後面那塊黏起來，變成「1001」或「10010」。於是每個合格裝法剛好對應一種**用長度 1、2、4、5 的磚鋪滿一圈**的方法（反過來也一樣）。

鋪一圈的方法數：看蓋住 1 號房間的是哪一塊磚、1 號房間在這塊磚的第幾格（長度 l 的磚有 l 種），剩下的就是鋪一條直線。所以

圈的方法數 = 1·(長 n−1 的直線) + 2·(長 n−2) + 4·(長 n−4) + 5·(長 n−5)。

這正好是 OEIS A001642（Fielder 1968 的數列，條目只寫「A Fielder sequence」，沒有留言）的生成函數。它原本已知是某個多項式的根的 n 次方和（和週期軌道有關），我們補上一個新的解釋：**n ≥ 5 時，A001642(n) 就是 n 個房間排成一圈的定位支配集個數**。n = 4 不成立（9 ≠ 11），因為 4 個房間的圈裡，p−2 和 p+2 是同一間，推理第 3 步失效。

## 6. 哪些是證明、哪些是電腦檢查

- 第 3～5 節是完整的證明，不靠電腦。
- 電腦做的是「檢查」：三種不同的程式（照定義暴力試所有裝法、照字串規則數、照公式算）在 n ≤ 20 全部一樣。電腦檢查不能代替證明，但能抓出證明寫錯的地方。
- 我們在 OEIS 離線全庫和網路上都沒找到有人數過這個個數，但「沒找到」不等於「一定是新的」。

## 7. 超出高二的地方

- 第 4 節的生成函數用到 2×2 矩陣的反矩陣和「形式冪級數」（把數列放進 x^n 的係數），高二只學到矩陣乘法；可以只記遞迴那一行。
- 第 5 節「鋪環 = Σ 磚長 × 鋪直線」是排列組合的乘法原理，高二就夠。

## 8. 自己寫 OEIS 留言時要講的重點

- 定位支配集的定義（Slater）：S 外每點有 S 裡的鄰居，而且 S 外不同點看到的 S 鄰居不一樣。
- 證明關鍵一句：寫成 0/1 字串，1 之間的空隙最多 2、兩端最多 1，而且沒有一個 1 兩邊都是長空隙。
- 公式：生成函數和遞迴 a(n) = a(n−1) + a(n−2) + a(n−4) + a(n−5)。
- 環的版本是 A001642（n ≥ 5），n = 4 不成立的原因。
- 說明是 AI 協助找到和證明、你自己讀過證明；不要說「新發現」。
