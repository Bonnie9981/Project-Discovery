# 程式說明（高二版）：路徑和環的定位支配集、識別碼

## 你自己可以跑的那一支：check_paths.py

位置：`results/locating-dominating-path/code/check_paths.py`。只要 Python 3，不用裝任何東西：

```
python results\locating-dominating-path\code\check_paths.py
```

約 15 秒，最後一行印 `all checks passed; LD(C_n) = A001642(n) for 3 <= n <= 20 except n = 4`。

## 程式分三段，是三種互相獨立的算法

**A. 照定義硬算（brute force）**
- `path(n)`、`cycle(n)`：列出每個房間的鄰居。
- `is_ld(adj, S)`：對每個沒裝的房間 v，算「鄰居裡有裝的」集合；如果是空的（沒人響）或跟之前某間一樣（分不出來），就不合格。
- `is_id(adj, S)`：識別碼版本，每個房間（包含有裝的）都算「自己加鄰居裡有裝的」集合，要全部非空且互不相同。
- `brute`：n 個房間共有 2^n 種裝法，用二進位數 m 的每一位代表一間裝不裝，全部試一遍。

**B. 照證明裡的字串規則算**
- `ld_word_path(w)`：把字串切成空隙，檢查「中間 ≤ 2、兩端 ≤ 1、沒有兩個相鄰的長空隙」。
- `id_word_path(w)`：檢查識別碼的三條規則 (a)(b)(c)。
- `id_transfer(n)`：不列出所有字串，只記「最後三個字母」的 8 種狀態，每加一個字母更新每種狀態有幾種寫法（這就是轉移矩陣乘法）。

**C. 照公式算**
- `rec(init, coef, N)`：從開頭幾項用遞迴往後推。

主程式對 n = 1..20 要求 A、B、C 三個數字完全一樣，不一樣就 `assert` 報錯停下來；n = 21..39 再比 B 的矩陣和 C 的遞迴。

## 為什麼要三種算法

只用一種程式，程式寫錯了也看不出來。三種想法完全不同的算法給出一樣的數，寫錯的機會就很小。但這仍然只是檢查有限多個 n；對**所有** n 成立要靠證明（見「證明方法說明」）。
