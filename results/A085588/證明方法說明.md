# A085588 證明方法說明（高二版）

> 依據：英文證明 `paper/a085588-period.md`、Lean 檔 `lean/Discovery/A085588Period.lean`。

## 一句話結論

A085588(n) 是「規則 150 在一圈 n 格上、從一格亮出發」的最終週期。條目上 2024 年 8 月的一則留言說「2^D·(2^s − 1) 整除 a(n)」，**方向寫反了**。真正成立的是：

> a(n) 整除 2^D·(2^s − 1)

其中 n = 2^D·m（m 是奇數，D 是 n 能被 2 整除幾次，也就是 A007814(n)），s = A309786(n) 是讓 2^s 除以 m 餘 1 或餘 m−1（也就是 2^s ≡ ±1 mod m）的最小正整數。

反例：a(4) = 2，但 2² × (2¹ − 1) = 4，4 不整除 2。a(13) = 21，但 2⁶ − 1 = 63，63 不整除 21（反過來 21 整除 63 才對）。

## 第一步：定義和小例子

**規則 150。** 每格同時更新：新值 = 左鄰 XOR 自己 XOR 右鄰（XOR：三格中奇數個亮就亮）。在圓圈上，格子 n−1 和格子 0 相鄰。

**n = 5：**

```
t=0  ■□□□□
t=1  ■■□□■
t=2  ■□■■□
t=3  ■□□□□   ← 回到起點
```

a(5) = 3。算公式：5 = 2⁰ × 5，D = 0、m = 5；2¹ = 2、2² = 4 ≡ −1 (mod 5)，所以 s = 2。2⁰ × (2² − 1) = 3。a(5) = 3 整除 3 ✓。

**n = 4：** ■□□□ → ■■□■ → ■□□□，a(4) = 2。D = 2、m = 1、s = 1，公式值 4 × 1 = 4。2 整除 4 ✓，但 4 不整除 2，所以原留言的方向錯。

**n = 13：** a(13) = 21；m = 13，2⁶ = 64 = 65 − 1 ≡ −1 (mod 13)，s = 6，公式值 63。21 × 3 = 63 ✓。

## 第二步：證明

定一個記號：G_a 是「每格 = 往左 a 格 XOR 自己 XOR 往右 a 格」。規則 150 就是 G_1。

### 1. 走 2 步 = 「隔 2 格」的規則；走 2^j 步 = 「隔 2^j 格」的規則

G_a 做兩次：第二次時每格加起來的三項，各自又是三項的和，展開後 x(i−a) 和 x(i+a) 各出現 2 次、x(i) 出現 3 次、x(i−2a) 和 x(i+2a) 各 1 次。mod 2 時偶數次消掉、3 次等於 1 次，剩下 x(i−2a) + x(i) + x(i+2a)，也就是 G_{2a}。

所以走 2 步 = G_2，走 4 步 = G_4，……，走 2^j 步 = G_{2^j}（數學歸納法）。

（多項式說法：mod 2 時 (x⁻¹ + 1 + x)² = x⁻² + 1 + x²，因為交叉項都出現兩次。這個「平方時交叉項消失」在大學叫 Frobenius 性質，高中可以直接把平方展開驗證。）

### 2. 走 2^(D+s) 步 = 走 2^D 步

在圓圈上，「往右 a 格」只跟 a 除以 n 的餘數有關，而且 G_a 和 G_{−a} 一樣（左右對稱）。

s 的定義說 2^s = 1 + c·m 或 2^s = c·m − 1（某個整數 c）。兩邊乘 2^D：

- 2^(D+s) = 2^D + c·n，或
- 2^(D+s) = −2^D + c·n。

不管哪種，2^(D+s) 除以 n 的餘數是 ±2^D，所以 G_{2^(D+s)} = G_{2^D}，也就是**走 2^(D+s) 步和走 2^D 步結果一樣**。

而 2^(D+s) = 2^D + 2^D·(2^s − 1)。令 P = 2^D·(2^s − 1)，上面這句話就是：

> 任何狀態，走 2^D + P 步 = 走 2^D 步。

意思是：從第 2^D 步開始，每 P 步一定重複。

### 3. 最小週期一定整除 P

設真正的最小週期是 p。P 也是「一個會重複的步數」。把 P 除以 p：P = q·p + r，0 ≤ r < p。從某時刻起每 p 步重複，也每 P 步重複，所以每 r = P − q·p 步也重複。但 p 是最小的正週期，r 又比 p 小，只能 r = 0。所以 p 整除 P。證畢。

（這是高中「除法原理」的應用，和「兩個週期的最大公因數也是週期」同一個道理。）

## 編輯可能問、你可以這樣答

- **問：為什麼是整除 P 而不是 P 整除 a(n)？** 答：走 2^j 步等於隔 2^j 格的規則 150（mod 2 平方時交叉項消掉），而 2^(D+s) ≡ ±2^D (mod n)，所以走 2^D + P 步等於走 2^D 步，P 是一個週期，最小週期必整除它。反例 a(4) = 2、a(13) = 21 說明反方向不成立。
