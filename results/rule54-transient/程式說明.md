## 最簡單的：草稿裡的 Python 程式（你自己一定可以跑）

把下面這段存成 `rule54.py`，用 `python rule54.py` 執行：

```python
def a(n):
    x, seen, t = (1,) + (0,)*(n-1), {}, 0
    while x not in seen:
        seen[x] = t
        x = tuple(x[i] ^ (x[i-1] | x[(i+1) % n]) for i in range(n))
        t += 1
    return seen[x]
print([a(n) for n in range(1, 41)])
```

應該印出 `[1, 2, 2, 0, 5, 0, 0, 2, 6, 2, 2, 4, 10, ...]`，和草稿的 DATA 一樣。

**逐行說明：**

- `x = (1,) + (0,)*(n-1)`：起始狀態，第 0 格亮、其他暗。用 tuple（不能改的串列），才能當字典的鑰匙。
- `seen = {}`：字典，記住「這個狀態第一次出現在第幾步」。
- `while x not in seen`：還沒看過這個狀態就繼續走。
- `x[i] ^ (x[i-1] | x[(i+1) % n])`：規則 54。`|` 是 OR（左右至少一個亮），`^` 是 XOR（翻面）。`x[i-1]` 在 i = 0 時是 `x[-1]`，Python 會拿最後一格，剛好就是圓圈的左鄰；`% n` 讓最後一格的右鄰繞回第 0 格。
- 第一次遇到看過的狀態 x，它第一次出現的時刻 `seen[x]` 就是暫態長度。

## critic_c_mod1.py：審查員的攻擊式檢查

需要 numpy（`pip install numpy`）。審查員沒看我們的程式，自己從文字描述重寫：

- 整圈用 numpy 陣列，一步是 `x ^ (roll(x, 1) | roll(x, -1))`（`roll` 是整串轉一格，拿到鄰居的值）。
- 不找循環，而是直接驗證：第 w−4 步和第 w 步不同（暫態不比 w−3 短）、第 w−3 步和第 w+1 步相同、第 w−3+p 步（p = 1, 2, 3）和第 w−3 步不同（週期剛好 4）。
- **故意試錯的描述**：把缺陷的位置改錯，確認程式會抓到不一致。這是在檢查「檢查本身有沒有用」。
