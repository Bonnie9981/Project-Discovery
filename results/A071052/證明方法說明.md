# A071052 證明方法說明（高二版）

> 依據：英文證明 `paper/a071052-even.md`、Lean 檔 `lean/Discovery/A071052Even.lean`。

## 一句話結論

條目上 Ralf Stephan 在 2004 年猜：a(2n) = a(n) + 2n。我們證明它對所有 n ≥ 0 都成立。

## 第一步：定義和小例子

**規則 150。** 一排格子，每格亮（1）或暗（0）。每一步所有格子同時更新：

> 新的值 = 左鄰 XOR 自己 XOR 右鄰

XOR 就是「加起來除以 2 的餘數」：三格中有奇數個亮，新值就亮。

從正中間一格亮開始，第 n 步的圖案寬 2n+1 格（每步往兩邊各長一格）。A071052(n) 是第 n 列裡**暗格（0）的個數**。

前幾列（■ 亮、□ 暗，右邊數字是暗格數）：

```
n=0          ■           0
n=1         ■■■          0
n=2        ■□■□■         2
n=3       ■■□■□■■        2
n=4      ■□□□■□□□■       6
n=5     ■■■□■■■□■■■      2
n=6    ■□■□□□■□□□■□■     8
```

所以 a(0..6) = 0, 0, 2, 2, 6, 2, 8，和 OEIS 一致。檢查公式：a(6) = a(3) + 6 = 2 + 6 = 8，對；a(4) = a(2) + 4 = 6，對。

**仔細看第 6 列和第 3 列：** 第 6 列只看第 1、3、5、…、13 個字（偶數位置），是 ■■□■□■■，正好是第 3 列！奇數位置全是 □。這就是整個證明的核心。

## 第二步：為什麼「走兩步 = 隔一格走一步」

設某格位置 i。走一步後，位置 i 的值是 old(i−1) + old(i) + old(i+1)（mod 2）。再走一步，位置 i 的值是「走一步後」的 i−1、i、i+1 三格相加：

- 走一步後的 i−1 = old(i−2) + old(i−1) + old(i)
- 走一步後的 i  = old(i−1) + old(i) + old(i+1)
- 走一步後的 i+1 = old(i) + old(i+1) + old(i+2)

全部加起來：old(i−1) 出現 2 次、old(i+1) 出現 2 次、old(i) 出現 3 次、old(i−2) 和 old(i+2) 各 1 次。mod 2 時出現偶數次的會消掉，出現 3 次等於 1 次，所以

> 走兩步後 = old(i−2) + old(i) + old(i+2)（mod 2）

這就是「隔一格的規則 150」。

**用多項式看同一件事（高二學過多項式乘法）。** 規則 150 走 n 步的圖案，等於把 (1 + x + x²)^n 展開後，每個係數除以 2 的餘數（係數奇數就亮）。而在 mod 2 的世界裡

> (1 + x + x²)² = 1 + 2x + 3x² + 2x³ + x⁴ ≡ 1 + x² + x⁴

所以 (1 + x + x²)^(2n) ≡ (1 + x² + x⁴)^n，就是把 (1 + x + x²)^n 裡的 x 全換成 x²：第 2n 列 = 第 n 列每兩格中間插一個 0。

## 第三步：數暗格

- 第 2n 列亮格（1）的個數 = 第 n 列亮格的個數（插進去的全是 0）。這個事實其實早就寫在 A071053（亮格個數那條序列）的 FORMULA 裡（Peter J. Taylor，2020），我們只是把它接到 A071052。
- 第 2n 列長 4n+1 格，第 n 列長 2n+1 格，多了 2n 格。
- 暗格 = 長度 − 亮格，所以暗格也剛好多 2n 個：

> a(2n) = (4n+1) − 亮格數 = (2n+1 − 亮格數) + 2n = a(n) + 2n。證畢。

這個證明完全在高中範圍：只用到 mod 2 加法、多項式乘法和數學歸納法（「第 2n 列 = 第 n 列攤開」要對每個 n 成立，是用歸納法一步一步推過去）。

## 第四步：怎麼確定沒錯

## 編輯可能問、你可以這樣答

- **問：證明大意？** 答：規則 150 走兩步在 mod 2 下剛好等於隔兩格走一步（(1+x+x²)² ≡ 1+x²+x⁴），所以第 2n 列就是第 n 列每格中間插一個 0。1 的個數不變，列長多 2n，所以 0 多 2n 個。
