## 和 A265225 有關的程式碼

- `tot`：第 0 到 n 列亮格數的累加，就是 a(n)。
- 公式逐行用 `assert` 檢查，例如 Barker 的 `4 * tot[n] == (n + 1) * (2 * n - (-1) ** n + 5)`（兩邊都乘 4，避免除法出現小數）、Hurt 的 `tot[n] == n + 1 + (n + 1) * ((n + 1) // 2)`（`//` 是整數除法，等於下取整）。
- 生成函數：把 a(0), a(1), … 當多項式係數，乘上 (1−x)³(1+x)² 展開後的 1 − x − 2x² + 2x³ + x⁴ − x⁵，結果應該只剩 1 + 3x。
- Ianakiev：`combinations(range(1, 2n+1), n)` 列出從 1..2n 選 n 個的所有方法，找總和被 n 整除的最小值，要等於 `tot[n-1]` 而且不等於 `tot[n]`。
- critic 的動態規劃：一個一個數字考慮「選或不選」，記錄「已選幾個、和除以 n 的餘數」對應的最小和。選法有 C(2n, n) 種，n = 40 時有 10^23 種，列舉不完；動態規劃只需要 2n × n × n 個格子，很快。

## 不用程式也能自己驗證

- 數亮格：證明說明裡的表，1, 3, 2, 6, 3, 9, 4 累加得 1, 4, 6, 12, 15, 24, 28。
- 公式：a(5) 用 Barker 公式 (6)(10 + 1 + 5)/4 = 6 × 16 / 4 = 24 ✓；用 Hurt 公式 6 + 6 × 3 = 24 ✓。
- Ianakiev：n = 3，從 {1,…,6} 選 3 個、和是 3 的倍數，最小是 1+2+3 = 6 = a(2)，不是 a(3) = 12。
