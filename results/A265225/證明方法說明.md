# A265225 證明方法說明（高二版）

> 依據：英文證明 `paper/rule54-rows.md`（和 A118109 共用）、Lean 檔 `lean/Discovery/Rule54Rows.lean`。

## 一句話結論

A265225(n) = 規則 54 從一格亮出發，第 0 列到第 n 列**亮格總數**。條目上有五個猜想公式，我們全部證明；另外發現 Ianakiev 的一則註解差了一個索引（他說等於 a(n)，其實是 a(n−1)），並給出證明。

核心事實只有一句：**第 2k 列有 k+1 個亮格，第 2k+1 列有 3k+3 個亮格。**

## 第一步：規則 54 和小例子

規則 54：每格看左、中、右，

> 新的值 = 自己 XOR（左 OR 右）

白話：左右至少有一個亮，自己就翻面；否則不變。（逐一檢查 8 種組合，和規則 54 的表 00110110 一致。）

```
n   第 n 列            亮格數   累計 a(n)
0        ■               1        1
1       ■■■              3        4
2      ■□□□■             2        6
3     ■■■□■■■            6       12
4    ■□□□■□□□■           3       15
5   ■■■□■■■□■■■          9       24
6  ■□□□■□□□■□□□■         4       28
```

OEIS 前幾項正是 1, 4, 6, 12, 15, 24, 28。

## 第二步：每一列的形狀

偶數列是「1 後面接 k 個 0001」，奇數列是「111 後面接 k 個 0111」。用數學歸納法證明（詳細過程見 A118109 的證明方法說明第三步，同一個引理）：

- 偶數列的亮格彼此隔 4 格。下一步，每個亮格兩邊的暗格因為有亮鄰居而翻亮，亮格本身不翻，變成一段段 111。
- 奇數列下一步，111 的三格都翻暗、段與段之間的那格翻亮，又回到隔 4 格一個亮。

所以第 2k 列有 1 + k 個亮格（1 再加 k 個 0001），第 2k+1 列有 3 + 3k 個（111 再加 k 個 0111）。

## 第三步：加總（等差數列求和，高一學過）

a(2k) = 第 0 到 2k 列的和 = 偶數列（j = 0..k）的 (j+1) 加奇數列（j = 0..k−1）的 (3j+3)：

> a(2k) = [1 + 2 + … + (k+1)] + 3·[1 + 2 + … + k] = (k+1)(k+2)/2 + 3k(k+1)/2 = (k+1)(2k+1)

> a(2k+1) = a(2k) + (3k+3) = (k+1)(2k+1) + 3(k+1) = (2k+2)(k+2)

檢查：a(4)（k = 2）= 3 × 5 = 15 ✓；a(5) = 6 × 4 = 24 ✓。

## 第四步：五個猜想公式

每個公式都只要分「n 偶數」和「n 奇數」代進去，看是不是等於上面兩個式子。

1. **Barker：a(n) = (n+1)(2n − (−1)^n + 5)/4。** n = 2k：(2k+1)(4k − 1 + 5)/4 = (2k+1)(k+1) ✓。n = 2k+1：(2k+2)(4k+2 + 1 + 5)/4 = (2k+2)(k+2) ✓。
2. **Hurt：a(n) = n + 1 + (n+1)·⌊(n+1)/2⌋ = (n+1)(1 + ⌊(n+1)/2⌋)。** n = 2k：⌊(2k+1)/2⌋ = k，得 (2k+1)(k+1) ✓。n = 2k+1：⌊(2k+2)/2⌋ = k+1，得 (2k+2)(k+2) ✓。
3. **Veselovac：a(n) = A093353(n) + n + 1。** A093353(n) 的定義（它在 OEIS 的名稱）是 (n + (n mod 2))(n+1)/2。n = 2k：k(2k+1) + 2k + 1 = (2k+1)(k+1) ✓。n = 2k+1：(k+1)(2k+2) + 2k+2 = (2k+2)(k+2) ✓。
4. **Barker 的遞迴：a(n) = a(n−1) + 2a(n−2) − 2a(n−3) − a(n−4) + a(n−5)（n > 4）。** 偶數項和奇數項各自是 k 的二次多項式。可以直接代入兩種奇偶情況驗算（Lean 定理 `a265225_rec` 就是這樣做的）。直觀：這個遞迴的「特徵多項式」是 (1−x)³(1+x)²，(1−x)³ 對應「二次多項式」，(1+x)² 對應「奇偶交替」，剛好吻合。
5. **Barker 的生成函數：(1+3x)/((1−x)³(1+x)²)。** 分母乘開是 1 − x − 2x² + 2x³ + x⁴ − x⁵，就是第 4 點遞迴的係數，再用前 5 項 1, 4, 6, 12, 15 決定分子。

> **超出高二的部分：** 「特徵多項式」和「生成函數」是大學離散數學的工具。可以理解成：生成函數是一種把整條數列打包成一個分式的記法，「生成函數是這個分式」等價於「數列滿足分母對應的遞迴，而且前幾項對得上」。所以第 5 點不需要另外的證明。

## 第五步：Ianakiev 的註解差一個索引

原句：「從 1 到 2n 選 n 個不同的數，總和要被 n 整除，且越小越好，最小和似乎等於 a(n)。」

**反例：** n = 1，從 {1, 2} 選 1 個，最小是 1。但 a(1) = 4，a(0) = 1。所以應該是 a(n−1)。n = 2，從 {1,2,3,4} 選 2 個、和是偶數，最小是 1+3 = 4 = a(1)，不是 a(2) = 6。

**證明最小和是 a(n−1)：**

1. 選 n 個數，最小的和是 1+2+…+n = n(n+1)/2，最大是 (n+1)+…+2n = n(3n+1)/2。中間每個整數都做得到：從最小的選法開始，每次把某個數加 1（換成還沒選的下一個數），和就加 1，可以一路走到最大。
2. **n 奇數**：(n+1)/2 是整數，所以 n(n+1)/2 本身就是 n 的倍數，最小和就是 n(n+1)/2。令 n = 2k+1，這等於 (2k+1)(k+1) = a(2k) = a(n−1) ✓。
3. **n 偶數**：n(n+1)/2 = n·(n/2) + n/2，除以 n 餘 n/2，所以要再加 n/2 才是倍數，最小和是 n(n+2)/2。令 n = 2k+2，這等於 (k+1)(2k+4) = (2k+2)(k+2) = a(2k+1) = a(n−1) ✓。

換句話說：「從 1 到 2n+2 選 n+1 個數」才剛好是 a(n)。草稿裡**不改別人的原句**，只在後面加一行說明，讓編輯決定。這部分只有紙筆證明，程式暴力檢查 n ≤ 11 一致，審查員的另一支程式用不同方法檢查到 n ≤ 40 也一致，而且從來不等於 a(n)。

## 編輯可能問、你可以這樣答

- **問：證明大意？** 答：第 2k 列有 k+1 個亮格、第 2k+1 列有 3k+3 個，相加得 a(2k) = (2k+1)(k+1)、a(2k+1) = (2k+2)(k+2)，每個猜想公式分奇偶代入就成立。
- **問：Ianakiev 那句為什麼差一個？** 答：n 個數的和可以取到 n(n+1)/2 到 n(3n+1)/2 之間每個整數，最小的 n 倍數是 n(n+1)/2（n 奇）或 n(n+2)/2（n 偶），正好是 a(n−1)。n = 1 就是反例：最小和 1 = a(0)。
