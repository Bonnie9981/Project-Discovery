# A276674 證明方法說明（高二版）

> 依據：紀錄 `records/DISC-0024/`、草稿 `a276674_oeis_edit_draft.md`。**這是紙筆證明，沒有 Lean 檔**；程式只做數值檢查。

## 一句話結論

Ordowski（2016）猜：如果 x − λ(x) = 2m > 0（正偶數），那 x ≤ 4m。我們證明它**對**。核心是：這種 x 一定滿足 λ(x) ≤ x/2。

## 第一步：要先懂的名詞（超出高二，但可以用例子理解）

**φ(x)（歐拉函數）：** 1 到 x 之間和 x 互質（最大公因數是 1）的數有幾個。例：φ(12) = 4（1, 5, 7, 11）；質數 p 的 φ(p) = p − 1。

**λ(x)（Carmichael 函數）：** 最小的正整數 e，讓「每一個和 x 互質的 a」都滿足 a^e 除以 x 餘 1。

例：x = 12，和 12 互質的是 1, 5, 7, 11。5² = 25 餘 1、7² = 49 餘 1、11² = 121 餘 1，所以 λ(12) = 2。

兩個要用的性質（數論課本的標準結果）：

1. λ(x) 一定整除 φ(x)，所以 λ(x) ≤ φ(x)。
2. x = p₁^e₁ × p₂^e₂ × … 時，λ(x) 是各個 λ(pᵢ^eᵢ) 的**最小公倍數**；而 φ(x) 是各個 φ(pᵢ^eᵢ) 的**乘積**。奇質數 p 時 λ(p^e) = φ(p^e) = p^(e−1)(p−1)，是偶數。

**A276674** 列的是「不能寫成 x − λ(x) 的正整數」：21, 28, 45, 46, 51, …（這個猜想寫在條目留言裡）。

## 第二步：先排除不可能的 x

如果 x − λ(x) 是正偶數，x 不可能是：

- x = 1：λ(1) = 1，差是 0，不是正數。
- x = 2：λ(2) = 1，差是 1，奇數。
- x 是奇質數次方 p^k：λ = p^(k−1)(p−1)，差是 p^k − p^k + p^(k−1) = p^(k−1)，是奇數。

所以 x 只剩兩種：**x 是偶數（≥ 4）**，或 **x 是奇數、有至少兩個不同的質因數**。

## 第三步：兩種情況都有 λ(x) ≤ x/2

- **x 是偶數：** 1 到 x 裡一半是偶數，偶數和 x 不互質，所以 φ(x) ≤ x/2。再由性質 1，λ(x) ≤ φ(x) ≤ x/2。
- **x 是奇數、至少兩個不同質因數：** λ(x) 是至少兩個偶數的最小公倍數，φ(x) 是它們的乘積。兩個偶數 u、v 的最小公倍數 = uv / gcd(u, v)，而 gcd 至少是 2，所以最小公倍數 ≤ uv/2（多個數時一樣）。所以 λ(x) ≤ φ(x)/2 < x/2。

## 第四步：結論

λ(x) ≤ x/2，所以 x − λ(x) ≥ x/2，也就是

> x ≤ 2(x − λ(x)) = 2 × 2m = 4m。證畢。

例：x = 12，λ = 2，x − λ = 10 = 2 × 5，m = 5，12 ≤ 20 ✓。

## 編輯可能問、你可以這樣答

- **問：證明大意？** 答：差是正偶數時，x 不是 1、2 或奇質數次方。x 偶數時 λ ≤ φ ≤ x/2；x 奇數且至少兩個質因數時，λ 是幾個偶數的最小公倍數、φ 是它們的乘積，所以 λ ≤ φ/2 < x/2。於是 x ≤ 2(x − λ) = 4m。
