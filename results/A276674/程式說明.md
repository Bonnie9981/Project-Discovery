# A276674 程式說明（高二版）

## 程式在算什麼

只有一支：`results/A276674/code/check276674.py`。

1. 對每個 x ≤ 10^6 算出 λ(x)（Carmichael 函數）。
2. 檢查：只要 x − λ(x) 是正偶數 2m，就有 x ≤ 4m（程式寫成 `x <= 2 * n`，n = x − λ(x)）。
3. 重算 A276674 前 20 項（「不能寫成 x − λ(x) 的數」），和 OEIS 比對。

這是數值檢查，不是證明；證明是紙筆的（見證明方法說明）。

## 怎麼自己跑

只要 Python 3：

```
python results\A276674\code\check276674.py
```

預設 x ≤ 10^6，大約十幾秒到一分鐘。輸出：

```
x <= 1000000: x - lambda(x) = 2m > 0 always has x <= 4m; DATA matches
```

## 程式逐段說明

- **最小質因數篩（spf）**：`spf[j]` 存 j 的最小質因數。做法類似埃拉托斯特尼篩法：對每個質數 i，把 i² 以後的倍數中還沒標記的，標上 i。之後要分解 x，只要一直除以 `spf[x]` 就好，很快。
- **算 λ(x)**：把 x 分解成質數次方 p^e，每個算出 λ(p^e)，再取最小公倍數：
  - 奇質數 p：λ(p^e) = (p − 1) × p^(e−1)。
  - p = 2：λ(2) = 1、λ(4) = 2、e ≥ 3 時 λ(2^e) = 2^(e−2)（2 的次方比較特別，這是數論的標準結果）。
  - 最小公倍數用 `l * lp // gcd(l, lp)`（兩數相乘除以最大公因數）。
- **檢查猜想**：對每個 x，n = x − λ(x)，如果 n > 0 且是偶數，就 `assert x <= 2 * n`。
- **重算前 20 項**：收集所有 x ≤ 40000 的 x − λ(x) 值，找出 1 到 199 之間沒出現過的數，前 20 個要等於 OEIS 的 21, 28, 45, 46, 51, …。（為什麼看到 x ≤ 40000 就夠：除了奇質數次方，x − λ(x) 都至少 x/2，x 超過 400 就大於 199；奇質數次方 p^k 的 x − λ(x) = p^(k−1)，小於 200 的值在 40000 以內都已經出現過，例如 p² ≤ 199² < 40000。）

## 不用程式也能自己驗證

手算幾個 λ：

| x | 和 x 互質的數 | λ(x) | x − λ(x) | 偶數？ | x ≤ 4m？ |
|---|---|---|---|---|---|
| 12 | 1, 5, 7, 11（平方都餘 1） | 2 | 10 | 是，m = 5 | 12 ≤ 20 ✓ |
| 15 | λ = lcm(λ(3), λ(5)) = lcm(2, 4) | 4 | 11 | 否 | 不用檢查 |
| 9 | 奇質數次方 3² | 6 | 3 | 否（奇質數次方一定是奇數） | 不用檢查 |
| 4 | 1, 3 | 2 | 2 | 是，m = 1 | 4 ≤ 4 ✓（剛好等號） |
