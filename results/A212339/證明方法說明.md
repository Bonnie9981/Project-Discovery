# A212339、A212341 證明方法說明（高二版）

> 依據：證明頁 `paper/a212339-marked-mesh.md`、紀錄 `records/DISC-0031/`、草稿 `a212339_oeis_edit_draft.md`。沒有 Lean，是紙上證明加程式驗算。

## 一句話結論

Colin Barker 在 A212339、A212341 留的「Empirical g.f.」（看數字猜的生成函數）和 Harvey Dale 在 A212339 留的遞迴猜想都是對的。A212344、A212345 的公式則是條目引用的論文（Kitaev、Remmel、Tiefenbruck，以下簡稱 KRT）Theorem 13 早就證過的，我們只補出處。

## 第一步：名詞

**排列。** 1～n 每個數用一次排成一列，例如 n = 3 有 123、132、213、231、312、321。

**避開 132。** 排列裡找不到三個位置 i < j < k，數字大小像「小、大、中」。例如 132 本身不行；2 4 1 3 也不行（2、4、3 是小、大、中）。避開 132 的排列個數是卡特蘭數 C_n：1, 1, 2, 5, 14, 42, …（n = 3 有 5 個，只少了 132）。

**左下方的點。** 把排列 σ 畫成平面上的點 (i, σ_i)。某個數左下方的點，就是「在它前面而且比它小」的數。例：2 3 1 4 裡，4 的左下方有 2、3、1 三個點；3 的左下方只有 2。

**統計量。** 固定 k，數一個排列裡「左下方至少 k 個點」的數有幾個，叫 mmp(σ)。A212339 是 k = 3 時，所有 n 個數的 132-避免排列中，**mmp 剛好等於 1** 的排列有幾個。例：n = 4 時，要 mmp = 1，就要有一個數前面有 3 個比它小的數，只能是最後一個數是 4，前面是 1、2、3 的 132-避免排列（5 個），所以 A212339(4) = 5。

## 第二步：關鍵拆法

132-避免排列裡，把最大的數 n 找出來，寫成 σ = α n β（α 是 n 左邊那段，β 是右邊那段）。

**α 裡每個數都比 β 裡每個數大。** 如果 α 裡有 x、β 裡有 y 而 x < y，那 x、n、y 就是「小、大、中」，違反 132。

所以 α、β 本身各是一個 132-避免排列（α 用比較大的那些數，β 用比較小的那些數），反過來任意挑 α、β 也拼得回去。

**左下方的點各自在自己那段：**
- α 裡的數：前面的數都在 α 裡，所以點數跟只看 α 一樣。
- n：前面 α 的 |α| 個數全部比它小，所以 n 左下方有 |α| 個點。
- β 裡的數：前面有 α 和 n，但它們都比 β 的數大，不算；所以只看 β。

因此 mmp(σ) = mmp(α) + (|α| ≥ k 時加 1) + mmp(β)。

小例子（k = 3）：σ = 2 3 4 5 1（n = 5，α = 2 3 4、β = 1）。α 長度 3 ≥ 3，所以 n 加 1；α 裡最多的 4 左下方只有 2 個點，不算；β 只有一個數，不算。所以 mmp = 1。直接數：5 左下方有 2、3、4 三個點，其他數都不到 3 個。✓

## 第三步：生成函數（超出高二，簡述）

**生成函數**把一列數 a(0), a(1), a(2), … 寫成 a(0) + a(1)t + a(2)t² + …，用代數式子處理（大學組合數學）。這裡多一個變數 x 記錄 mmp：Q = Σ（所有 132-避免排列）t^(長度) x^(mmp)。

第二步的拆法變成一條方程式：

  Q = 1 + t·(P + x·(Q − P))·Q，P = 1 + t + 2t²（長度 0、1、2 的排列個數 1、1、2，k = 3）。

意思是：先放 n（乘 t），左邊 α 長度 < 3 時不加 x（這部分就是 P），長度 ≥ 3 時乘一個 x，右邊 β 隨便（乘 Q）。

把 Q 依 x 的次方拆開：Q = F + x·G + …（F 是 mmp = 0 的，G 是 mmp = 1 的，G 就是 A212339 的生成函數）。
- 只看沒有 x 的項：F = 1 + tPF，所以 F = 1/(1 − tP)。
- 只看 x 一次的項：G = tPG + t(F − P)F，解出 G = tF²(F − P)。

再化簡 F − P，就得到 G = t(1 − P + tP²)/(1 − tP)³。代 P = 1 + t + 2t²：分子變成 t⁴(5 + 4t + 4t²)，分母 1 − t − t² − 2t³ = (1 − 2t)(1 + t + t²)，正好是 Barker 的式子。分母三次方展開後的係數就是 Dale 猜的遞迴係數 (3, 0, 1, −12, −3, 1, 18, 12, 8)。

k = 4（A212341）一樣做，只是 P = 1 + t + 2t² + 5t³，結果也和 Barker 的式子完全一樣（程式逐項比對多項式）。

## A212344、A212345 是怎麼回事

它們數的是另一個方向（左上方：前面而且比它大），KRT 論文 Theorem 13 已經證明：最高次的係數是 C_k·C_{n−k}，次高是 a_k·C_{n−k}。k = 3 時就是 5·C(n−3) 和 9·C(n−3)。這兩條**不是我們的證明**，只是補上「論文第幾個定理」。

## 判定與限制

- 狀態：四條都是 `SUPPORTED_KNOWN`（審查判定）。原因：Barker 的 g.f. 本來就寫在 OEIS 上，KRT 論文的閉式解（OEIS 條目的 Mathematica 程式也有）對 x 微分一次就得到，所以我們是補上證明，不是新公式。
- 新穎性：查了 OEIS 離線全庫、KRT 第 I 篇（逐字讀了第 4、5 節）、第 II、III 篇（前半逐字、後半只有摘要）、Borie 2013。KRT 寫了方程式但說「找不到簡單公式」；從方程式取 x 一次項只是一步，屬於習題程度，**不宣稱新**。
- 紙上證明加程式，**沒有 Lean**。
