# A212339、A212341 程式說明（高二版）

> 依據：`results/A212339/code/check_a212339.py`、`records/DISC-0031/experiment.md`、草稿裡的 PARI 指令。輸出都實際跑過。

## 程式在算什麼

1. **暴力（`av132`、`brute`）**：把 n ≤ 11 所有避開 132 的排列一個個列出來（先檢查個數等於卡特蘭數），對每個數直接數「前面比它小的有幾個」「前面比它大的有幾個」，算出 k = 2、3、4 的統計量分布。
2. **遞推（`dp_x1_full`）**：用證明裡的拆法 σ = α n β 算出完整多項式到 n = 59。這用了證明的拆法，所以不算完全獨立；先和暴力在 n ≤ 11 對上。
3. **公式展開（`gf_x1`）**：把 t(1 − P + tP²)/(1 − tP)³ 展開成數列，和前兩種比。
4. **精確多項式比對（`check_exact`）**：我們的分式和 A212338（Mathar）、A212339、A212341（Barker）的分式交叉相乘，要求兩邊是完全相同的整數多項式；也檢查 (1 − t − t² − 2t³)³ 的係數就是 Dale 的遞迴。
5. **KRT Theorem 13 抽查**：暴力數左上方版本 (0,3,0,0)，檢查最高兩個係數是 5·C(n−3)、9·C(n−3)。
6. **OEIS 資料**：五條條目存的所有項（26～33 項）都拿來比。

## 怎麼跑

在 repo 根目錄：

```
python results/A212339/code/check_a212339.py 11
```

約 5 秒，輸出：

```
brute n <= 11, DP n < 60, exact g.f. identities (A212338/39/41, Dale signature) OK; OEIS terms: A212338:33 A212339:29 A212341:26 A212344:27 A212345:26
```

最後那串是每條條目比了幾項。數字 11 可以改小（更快）。

## 自己驗（PARI/GP）

照草稿每行分開輸入：`av(p)` 判斷有沒有避開 132，`m(p,k)` 數左下方至少 k 個點的數有幾個，`b(n,k)` 數 mmp = 1 的排列。`vector(6,n,b(n+3,3))` 應得 [5, 19, 61, 188, 523, 1387]；最後一行（我們的 g.f. 減 Barker 的）應得 0。PARI 2.15.4 跑過，結果相同。也可以手算：n = 4 時只有「1、2、3 的 5 種 132-避免排列後面接 4」符合，A212339(4) = 5。

## 程式驗不到的

暴力只到 n = 11、遞推到 n = 59；對所有 n 成立靠證明。g.f. 相等那部分是精確多項式恆等，不是取樣。
