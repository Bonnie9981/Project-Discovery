## 最簡單的一支：brute.py（你自己一定可以跑）

只要 Python 3，不需要其他東西：

```
python results\A362070\code\brute.py 4 1715 1716
```

輸出（每行是 n、a(n)、K(n)）：

```
4 9 4
1715 91 21
1716 91 13
```

**程式逐段說明：**

- `rf(t, k)`：一塊 t(t+1)…(t+k−1)，用 `prod(range(t, t+k))` 把 t 到 t+k−1 乘起來。
- `mmin(n, k)`：P 從 1 開始，m = 1, 2, 3, … 每次乘上一塊，第一次 `P % n == 0`（被 n 整除）就回傳 m。這完全照定義，沒有任何數學捷徑。
- `kempner(n)`：f 從 1 開始一直乘 1, 2, 3, …，第一次被 n 整除就回傳。
- `a(n)`：把 r = 1 到 K(n) 的 mmin 加起來。

想看 1715 的 21 個 m_min，可以在 Python 裡：

```python
exec(open(r"results\A362070\code\brute.py").read().split("import sys")[0])
[mmin(1715, r) for r in range(1, 22)]
```

## factored.py：不乘出來的方法

大整數相乘很慢。factored.py 改成只數質因數：n = p₁^e₁ × p₂^e₂ × …，對每個質數冪 p^e，找最小的 m 使 P(m) 裡因數 p 至少 e 個，再取所有質數裡最大的那個 m。

- `vp_fact(x, p)`：x! 裡因數 p 的個數，用 Legendre 公式 ⌊x/p⌋ + ⌊x/p²⌋ + …（程式裡是 `x //= p` 一直除，累加）。
- 一塊 t…(t+r−1) 裡因數 p 的個數 = (t+r−1)! 裡的 − (t−1)! 裡的。
- 跑 `python results\A362070\code\factored.py` 會印出前 57 項，可以和 OEIS 對照。（要先 `pip install sympy`。）

## scan.c：掃到 10^10

C 語言、需要編譯器（Windows 上較麻煩，可以只看說明）。做法和 factored.py 同一個想法，再加上幾個加速：

- 用分段篩法把每個 n 分解質因數。
- 只出現一次的質因數（e = 1），只有最大的那個 P 有影響：m_min = max(1, P − r + 1)，所以那部分可以直接用公式加總（就是 a(1716) 的那種算法）。
- e ≥ 2 的質數冪，先把 m_min 表算好存起來。
- a(n) 可能很大，用 128 位元整數存。

結果：n ≤ 10^10 只有 n = 1715 滿足 a(n) = a(n+1)。10^10 分四段平行跑，每段銜接處都有檢查到，沒有漏掉相鄰的一對。

## 條目自己的 Maxima 程式

Maxima 是免費的數學軟體。`entry_program.mac` 前兩行（定義 K 和 a）是從 OEIS 條目抄下來的程式，後面兩行 print 用來印出結果，其中 `print(a(1714),a(1715),a(1716),a(1717));` 印出 367653 91 91 5151。

這是最有說服力的檢查：用**原作者自己的程式**算，也得到 a(1715) = a(1716)。

## 不用程式也能自己驗證

- a(4) = 9（證明說明裡有手算）。
- a(1716) = 1 + 2 + … + 13 = 91（理由見證明說明第二步）。
- r = 2 時 m_min(1715, 2) = 13：數 13! 和 14! 裡的因數 7（1 個、2 個），共 3 個。
