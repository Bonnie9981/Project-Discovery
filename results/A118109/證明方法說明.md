# A118109 證明方法說明（高二版）

> 依據：英文證明 `paper/rule54-rows.md`（和 A265225 共用）、Lean 檔 `lean/Discovery/Rule54Rows.lean`。

## 一句話結論

A118109 是「規則 54 從一格亮出發，第 n 列寫成 0 和 1 的數字，當成十進位數來讀」。條目上有三個猜想公式（Colin Barker 2015、2019；Karl V. Keller, Jr. 2021），我們全部證明：

1. 遞迴：a(n) = 10001·a(n−2) − 10000·a(n−4)（n > 3）
2. 生成函數：(1+111x) / ((1−x)(1+x)(1−100x)(1+100x))
3. 下取整公式：a(n) = ⌊(10000 + 1100·(n mod 2))·100^n / 9999⌋

我們不宣稱新發現：這個圖案在 Wolfram 的書《A New Kind of Science》第 55 頁就看得到，A118108 也有。我們只是把條目上還標「猜想」的公式證完。

## 第一步：規則 54 是什麼

一排格子，每格亮（1）或暗（0），每一步同時更新，看（左、中、右）三格：

| 左中右 | 111 | 110 | 101 | 100 | 011 | 010 | 001 | 000 |
|---|---|---|---|---|---|---|---|---|
| 下一步 | 0 | 0 | 1 | 1 | 0 | 1 | 1 | 0 |

下一排 00110110 是二進位的 54。逐一檢查八種情況可以發現，這個表等於

> 新的值 = 自己 XOR（左 OR 右）

OR 是「至少一個亮就是 1」，XOR 是「不一樣才是 1」。白話：如果左右至少有一個亮，自己就翻面（亮變暗、暗變亮）；否則維持原樣。

## 第二步：小例子

從一格亮開始（■ 亮、□ 暗，右邊是當十進位數讀的值）：

```
n=0        ■                1
n=1       ■■■               111
n=2      ■□□□■              10001
n=3     ■■■□■■■             1110111
n=4    ■□□□■□□□■            100010001
n=5   ■■■□■■■□■■■           11101110111
n=6  ■□□□■□□□■□□□■          1000100010001
```

規律很明顯：偶數列是「1 後面接 k 個 0001」，奇數列是「111 後面接 k 個 0111」。

## 第三步：證明每一列的形狀（引理）

**引理。** 第 t 列（位置 x 從 −t 到 t），格子 x 亮 ⇔

- t 偶數：x 除以 4 的餘數和 t 一樣（x ≡ t mod 4）；
- t 奇數：x 除以 4 的餘數**不等於** t+1 的餘數。

**證明（數學歸納法）。** t = 0 對。假設第 t 列對，看第 t+1 列：

- t 偶數時，亮格彼此隔 4 格、互不相鄰。規則「左右有亮就翻面」：亮格本身左右都暗，不翻，仍亮；它旁邊的暗格有一個亮鄰居，翻成亮。結果每個亮格變成一段「111」，段和段之間剩一格暗。剛好是奇數列的樣子。
- t 奇數時，是「111 中間隔一個 0」。一段 111 的中間那格兩邊都亮，翻成暗；兩端那格有亮鄰居，也翻成暗；夾在段之間的那個 0 兩邊都亮，翻成亮；最外面多長出來的那格也翻成亮。整理後只剩 x ≡ t+1 (mod 4) 亮，剛好是偶數列的樣子。

每一格新值只跟「x 除以 4 的餘數」和「是不是在邊界」有關，所以只要檢查有限種情況（Lean 裡用 `omega` 這個自動工具逐一檢查完）。

## 第四步：從形狀推出公式

**每次跳兩列。** 比較第 t+2 列和第 t 列：第 t+2 列的前面部分就是第 t 列，最後多了四格：t 偶數時是 0001、t 奇數時是 0111。

當十進位數讀：往後接四位數，等於原數乘 10000 再加上那四位：

> a(t+2) = 10000·a(t) + e(t)，其中 e = 1（t 偶數）或 111（t 奇數）。

例：a(2) = 10000·1 + 1 = 10001；a(3) = 10000·111 + 111 = 1110111。

**公式 1（遞迴）。** 同樣的式子對 n−2 也成立：a(n−2) = 10000·a(n−4) + e。n 和 n−2 奇偶相同，所以 e 一樣。兩式相減：

> a(n) − a(n−2) = 10000·(a(n−2) − a(n−4))，移項得 a(n) = 10001·a(n−2) − 10000·a(n−4)。

**公式 3（下取整）。** 用數學歸納法可以證明 9999·a(n) + e(n) = (10000 + 1100·(n mod 2))·100^n。所以

> a(n) = (10000 + 1100·(n mod 2))·100^n / 9999 − e(n)/9999

而 0 < e(n) ≤ 111 < 9999，減掉的那一點點小於 1，所以取下取整剛好是 a(n)。

直觀理解（循環小數，高中學過）：10000 / 9999 = 1.000100010001…，乘上 100^n 後，小數點左邊就是「1 0001 0001 …」那一串，也就是偶數列；奇數列的 11100/9999 = 1.11011101110111… 同理。

**公式 2（生成函數）。** 分母乘開是 1 − 10001x² + 10000x⁴，正好就是公式 1 的遞迴係數，加上前四項 a(0..3) = 1, 111, 10001, 1110111 決定分子 1 + 111x。

> **超出高二的部分：生成函數。** 生成函數是把整條數列 a(0), a(1), a(2), … 當成一個「無窮多項」的係數：a(0) + a(1)x + a(2)x² + …。說「生成函數是某個分式」，等價於「數列滿足分母對應的遞迴，而且前幾項對得上」。所以它不需要另外證明，從公式 1 和前幾項就推得出來。Lean 沒有直接寫生成函數，但程式有把級數乘上分母檢查過。

## 編輯可能問、你可以這樣答

- **問：證明大意？** 答：規則 54 從一格出發，第 n+2 列就是第 n 列後面多接 0001（n 偶數）或 0111（n 奇數），所以 a(n+2) = 10000·a(n) + 1 或 + 111，三個公式都由此推出。
