# 程式說明（高二版）：開定位支配集

## 你自己可以跑的：check_old.py

位置 `results/open-locating-cycle/code/check_old.py`，只要 Python 3：

```
python results\open-locating-cycle\code\check_old.py
```

約 5 秒，最後一行 `all checks passed`。

## 程式在做什麼

- `path(n)`、`cycle(n)`：列出每個房間的鄰居。
- `is_old(adj, S)`：對每個房間 v 算「鄰居裡有裝的」集合，空的或和前面某間一樣就不合格。
- `brute(graph, n)`：n 間房有 2^n 種裝法，用二進位數 m 的每一位代表一間裝不裝，全部試。
- `A000930(k)`、`A001609(n)`：照 OEIS 的遞迴（每項 = 前一項 + 前第三項）自己算，不用上網。
- `old_cycle(n)`、`old_path(n)`：證明得到的公式。
- 主程式：n = 1..20 每個都要求「暴力數出來的」=「公式算出來的」，不一樣就停下來報錯。

## 怎麼自己驗證

把 `NMAX = 20` 改小（例如 8）就很快；也可以自己在紙上數 n = 5 的環（應該是 6 種）再和程式比。電腦只檢查到 20，對所有 n 成立要靠「證明方法說明」。
