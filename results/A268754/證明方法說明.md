# A268754 證明方法說明（高二版）

> 依據：英文證明 `paper/a268754-odd.md`、Lean 檔 `lean/Discovery/A268754Odd.lean`。這條序列有兩個結果：(1) 偶數項 a(n) = A334504(2n+2)，證明在 A334504 那份（見 A334504 的證明方法說明「偶數寬度」）；(2) 奇數項公式，就是這份要講的。

## 一句話結論

條目上寫著（沒有證明）：「a(2n+1) = 2·a(n)，但 n 是 2^k − 1 的形式時 a(n) = 1」。我們證明了它，而且說清楚例外到底是什麼：

1. 這條線最後會「全滅」（所有格子變暗）⇔ n+1 是 2 的次方。
2. n+1 不是 2 的次方時，a(2n+1) = 2·a(n)。
3. n+1 是 2 的次方時，a(n) = a(2n+1) = 1。

## 第一步：定義和小例子

**這條序列在算什麼。** 一條 n 格的線（不是圓圈），兩端外面都當作暗格。一開始只有最左邊那格亮。每一步所有格子同時更新：

> 新的值 = 左鄰 XOR 右鄰

XOR 的意思：兩個一樣得 0，不一樣得 1（等於「相加除以 2 的餘數」）。這叫「規則 90、零邊界」。a(n) 是這個過程最後重複的週期。

**n = 5 的例子**（■ 亮、□ 暗）：

```
t=0  ■□□□□
t=1  □■□□□
t=2  ■□■□□
t=3  □□□■□
t=4  □□■□■
t=5  □■□□□   ← 和 t=1 一樣
```

從 t=1 開始每 4 步重複，所以 a(5) = 4。n = 2 時是 ■□ → □■ → ■□，a(2) = 2。公式說 a(5) = a(2·2+1) = 2·a(2) = 4，對。

**全滅的例子：n = 3。** ■□□ → □■□ → ■□■ → □□□。全暗之後永遠全暗，週期算 1。n+1 = 4 是 2 的次方，符合結論 1。

## 第二步：證明的四個零件

### 零件 1：奇偶性

第 t 步亮的格子，位置（從 0 開始數）都和 t 同奇偶。

為什麼：t = 0 時只有位置 0 亮，對。每格的新值只看左右兩格，左右兩格位置和自己差 1，所以「下一步亮的位置」和「這一步亮的位置」奇偶相反。就像西洋棋盤，每走一步顏色換一次。

### 零件 2：「攤開」——長線走兩步 = 短線走一步

把 n 格的短線，放到 2n+1 格長線的第 2、4、6、…、2n 格（從 1 開始數），其他格放暗。叫這個動作 S（攤開）。

**長線走兩步，等於短線走一步再攤開。** 計算：短線上相鄰三格的值是 y(i−1)、y(i)、y(i+1)。長線走一步後，夾在中間的格子變成 y(i−1)+y(i) 和 y(i)+y(i+1)；再走一步，原位置變成

> (y(i−1) + y(i)) + (y(i) + y(i+1)) = y(i−1) + 2·y(i) + y(i+1)

除以 2 取餘數時 2·y(i) 消失，剩 y(i−1) + y(i+1)，剛好就是短線走一步的規則。兩端的邊界也對得上。

而長線從左端一格亮出發，走一步正好亮第 2 格，就是 S(短線起點)。所以用數學歸納法：

> 長線第 2t+1 步 = S(短線第 t 步)

上面 n = 2 → 長線 5 格可以驗證：長線第 1 步亮第 2 格（= S(■□)），第 3 步亮第 4 格（= S(□■)）。

S 是一對一的（看長線偶數格就讀得回短線），所以短線狀態相同 ⇔ 長線對應時刻的狀態相同。

### 零件 3：週期加倍

假設短線不會全滅。長線的週期如果是奇數 p，那在某個很大的奇數時刻 s，狀態 s 和狀態 s+p 相同；但由零件 1，時刻 s 的亮格在奇數位置、時刻 s+p 的亮格在偶數位置，兩者相同只能是全暗，而時刻 s 是 S(短線某狀態)、短線不會全暗，矛盾。所以長線週期一定是偶數，寫成 2q。

又由零件 2，長線每兩步對應短線一步，「長線每 2q 步重複」⇔「短線每 q 步重複」。最小的週期也對應，所以 a(2n+1) = 2·a(n)。

### 零件 4：什麼時候會全滅

- **n 是偶數**：更新規則可以「倒推」，也就是從下一步的狀態可以唯一算回上一步（像一個可逆的函數）。如果某步全暗，往回推上一步也全暗……一直推回起點也全暗，但起點有一格亮，矛盾。所以 n 偶數時永遠不會全滅。

  怎麼倒推：如果下一步全暗，最左那格 = 0 XOR y(1) = 0，所以 y(1) = 0；再往右推，奇數位置都是 0；從右端往左推，偶數位置也都是 0。（n 是偶數時兩邊剛好能推完；n 是奇數時推不完，例如 n = 3 的 ■□■ 下一步就全暗。）

- **n = 1**：一格的線，下一步看到兩邊都是暗，直接全滅。n+1 = 2，是 2 的次方。
- **n 是奇數 2r+1（r ≥ 1）**：由零件 2，長度 2r+1 的線全滅 ⇔ 長度 r 的線全滅。

把這三點合起來用「強歸納法」（假設比 n 小的都對，證 n 也對）：n 一直除以 2（取 (n−1)/2），直到變成偶數或 1。最後落在 1 ⇔ n 的二進位全是 1 ⇔ n+1 是 2 的次方。這就是結論 1。

結論 2、3 就從零件 3 和結論 1 得到（全滅的軌道週期是 1）。

> **用到的高中以外概念：** 「最小最終週期一定存在」用的是鴿籠原理（狀態只有 2^n 種，一直走必定重複），這是高中可以理解的，但 Lean 裡沒有把這件事形式化（英文證明有寫明）。XOR / 模 2 運算就是「奇偶相加」，高中範圍。

## 編輯可能問、你可以這樣答

- **問：證明大意？** 答：把 n 格的線放在 2n+1 格線的偶數格上，長線走兩步剛好等於短線走一步（中間那項出現兩次，模 2 消掉），所以週期加倍；奇偶性保證長線週期不會是奇數。
- **問：例外怎麼來的？** 答：n 偶數時更新可逆、不會全滅；n 奇數時全滅與否和 (n−1)/2 一樣；一路除下去，只有 n = 2^k − 1 會落到 1 而全滅。
