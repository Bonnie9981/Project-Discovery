## 最簡單的一支：check372430.py（你自己一定可以跑）

只要 Python 3，不需要其他東西（也可以只把這一個檔存下來跑）：

```
python results\A372430\code\check372430.py
```

幾秒鐘，輸出：

```
brute force k <= 10^6: [4100]
<= 4 one-bits, k < 2^120: [4100, 154742504911235484315811840]
2^87 + 2^49 = 154742504911235484315811840 binary indices {50, 88}, prime(50) = 229, prime(88) = 457: OK
```

**程式逐段說明：**

- `primes(n)`：列出前 n 個質數。從 2 開始一個個試，用已經找到的質數試除（只試到 √x）。
- `good(k, P)`：檢查 k 符不符合條件。j 從 1 開始，`(k >> (j-1)) & 1` 是「k 的第 j 位是不是 1」（`>>` 把二進位往右移 j−1 格，`& 1` 取最右邊一位）。如果是 1，就檢查第 j 個質數 `P[j-1]` 能不能整除 k（`k % P[j-1]` 是 0 才行）。只要有一位不行就回傳 False。
- 主程式第 1 部分：k = 1 到 10^6 每個都用 `good` 檢查，只找到 4100（和條目說的「驗到 10^7 只有 4100」一致）。
- 第 2 部分：用 `itertools.combinations` 選出 1 到 4 個位置當 1 位元，組出 k，檢查每個 1 位元對應的質數都整除 k。範圍到 2^120，找到 4100 和反例。
- 第 3 部分：直接驗證反例，而且確認第 50 個質數是 229、第 88 個是 457。

## a372430_dfs.c：剪枝窮舉（需要 C 編譯器，可以只看說明）

想法見證明方法說明第三步。程式重點：

- `P[j]` 是第 j 個質數。
- `dfs(r, v, M)`：已經決定了高位（存在 v 裡），還剩 r 個低位沒決定，M 是「必須整除 k 的質數乘積」。
  - 往下有兩條路：下一位放 0（M 不變），或放 1（M 乘上那一位對應的質數）。
  - 當區間長度 2^r 除以 M 小於 8，就直接列出區間裡 M 的倍數，用 `full_ok` 完整檢查。
- 用 128 位元整數（`unsigned __int128`），因為 k 可以到 2^120，一般的 64 位元放不下。
- 對每個位數 L = 1 到 120 分別跑一次（最高位固定是 1）。

跑法（Linux / Mac）：`gcc -O2 -o dfs a372430_dfs.c && ./dfs 120`，約 3 分鐘（`./dfs 100` 約 8 秒）。結果只印出 4100 和 154742504911235484315811840，總共約 67 億個節點。

## 不用程式也能自己驗證（只要 Python 或計算機）

```python
k = 2**87 + 2**49
bin(k).count("1")          # 2 → 只有兩個 1 位元
k % 229, k % 457           # (0, 0) → 都整除
5 * 229 * 457 * 525313     # 274877906945 = 2**38 + 1
2**12 + 2**2               # 4100；4100 % 5 == 0、4100 % 41 == 0
```

確認 229 是第 50 個質數，可以在 Python 裡跑 `[p for p in range(2, 460) if all(p % d for d in range(2, p))]`，看第 50 個和第 88 個。
