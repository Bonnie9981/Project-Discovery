只有一支：`results/A231897/code/verify.py`。它同時檢查 A231897 和 A215461、A215462（三條同一批做的）。這份只講 A231897 的部分；另外兩條見 A215461 的程式說明。

## 怎麼自己跑

1. 裝 Python 3（python.org，安裝時勾「Add Python to PATH」）。
2. 到 https://github.com/Bonnie9981/Project-Discovery 按「Code」→「Download ZIP」，解壓縮。（這支程式不需要 repo 其他檔案，你也可以只把它單獨存下來跑。）
3. 在終端機輸入：

```
python results\A231897\code\verify.py
```

第一行應該印出：

```
A231897: wt((2^a-1)^2) = a for a <= 3000; first 25 terms match
```

（後面幾行是 A215461、A215462 的檢查，大約要跑半分鐘到一分鐘。）

## 和 A231897 有關的程式碼

```python
def wt(x):
    return bin(x).count("1")
```

`bin(x)` 把數字寫成二進位字串（例如 `bin(13)` 是 `'0b1101'`），`.count("1")` 數裡面有幾個 1。

`check_a231897()` 做兩件事：

1. **檢查證明的關鍵式子**：對 a = 0 到 3000，算 m = 2^a − 1，檢查 wt(m × m) == a。Python 的整數沒有大小上限，2^3000 這麼大的數也能精確計算。
2. **用定義重算前 25 項**：對每個 n，m 從 0 開始一個一個加 1，直到 wt(m²) = n 為止，這個 m 就是 a(n)；要等於程式開頭從 OEIS 抄來的 `A231897` 前 25 項，而且 ≤ 2^n − 1。

## 不用程式也能自己驗證

- 手算 15² = 225，換成二進位：225 = 128 + 64 + 32 + 1 = 11100001₂，4 個 1。
- 7² = 49 = 32 + 16 + 1 = 110001₂，3 個 1（n = 3，7 = 2³ − 1）。但 a(3) = 5：5² = 25 = 11001₂ 也是 3 個 1，而且 5 < 7。所以 2^n − 1 只是「一定找得到」的保證，不一定是最小的。
