# A231897 證明方法說明（高二版）

> 依據：紀錄 `records/DISC-0018/`、Lean 檔 `lean/Discovery/NeverEasy.lean`（定理 `a231897_exists`）、草稿 `a231897_oeis_edit_draft.md`。這個證明只有一行，所以沒有另外的英文證明頁。

## 一句話結論

A231897(n) 是「最小的 m，使 m² 寫成二進位後剛好有 n 個 1」；如果找不到就記 −1。Sloane（2013）猜「永遠不會是 −1」。我們證明它對：

> (2^n − 1)² 的二進位剛好有 n 個 1，所以每個 n 都找得到 m，而且 a(n) ≤ 2^n − 1。

這是習題程度的結果，不宣稱新。

## 第一步：定義和小例子

「二進位裡 1 的個數」記作 wt（weight）。例如 13 = 1101₂，wt(13) = 3。

a(4)：找最小的 m 使 m² 的二進位有 4 個 1。一個一個試：1² = 1、2² = 100₂、3² = 1001₂、…，一直試到 13² = 169 = 10101001₂，剛好 4 個 1，所以 a(4) = 13。

OEIS 前幾項：0, 1, 3, 5, 13, 11, 21, 39, …

## 第二步：證明

把 (2^n − 1)² 展開（乘法公式 (a − b)² = a² − 2ab + b²）：

> (2^n − 1)² = 2^(2n) − 2·2^n + 1 = 2^(2n) − 2^(n+1) + 1

看二進位長什麼樣子：

- 2^(2n) − 2^(n+1) = 2^(n+1) × (2^(n−1) − 1)。2^(n−1) − 1 的二進位是 n−1 個 1（例如 2³ − 1 = 7 = 111₂）；乘上 2^(n+1) 就是在後面補 n+1 個 0。
- 再加 1，最後一位從 0 變 1，不會進位。

所以二進位是「n−1 個 1、n 個 0、最後一個 1」，總共 n 個 1。

**例子：** n = 4，(2⁴ − 1)² = 15² = 225 = 11100001₂：3 個 1、4 個 0、1 個 1，共 4 個 1 ✓。

所以 m = 2^n − 1 一定滿足條件，最小的 m 不會超過它：a(n) ≤ 2^n − 1，永遠不是 −1。（n = 0 時 m = 0，0² = 0 有 0 個 1，也成立。）

這整個證明只用到乘法公式和二進位，完全在高中範圍。

## 編輯可能問、你可以這樣答

- **問：證明大意？** 答：(2^n−1)² = 2^(2n) − 2^(n+1) + 1，二進位是 n−1 個 1、n 個 0、一個 1，剛好 n 個 1。例：15² = 225 = 11100001₂。
- **問：n = 0 呢？** 答：0² = 0 有 0 個 1，a(0) = 0。草稿寫「for n ≥ 1」是因為 2^(n−1) 那個寫法在 n = 0 沒有意義。
