# A073631 程式說明（高二版）

## 這些程式在算什麼

| 檔案 | 語言 | 做什麼 |
|---|---|---|
| `code/chk073631.py` | Python | 用大整數重算：三個 Wieferich 質數真的是、兩個反例真的在序列裡且不是 529 的倍數 |
| `code/wieferich32.c` | C | 掃 2^32 以下每個質數，找 3/2 底 Wieferich 質數（約 30 秒，多核心） |

## 最重要的一支：chk073631.py（你自己一定可以跑）

只要 Python 3，不需要其他東西：

```
python -I results\A073631\code\chk073631.py
```

（`-I` 是「隔離模式」，讓 Python 不讀目前資料夾裡的其他檔案，比較安全。）應該印出：

```
counterexample 14766805716452908561 = 3842760169 ^2
counterexample 1761935642146136591689 = 41975417117 ^2
ok
```

**程式逐段說明：**

- `is_prime(n)`：Miller–Rabin 質數測試。先用小質數試除，再用 13 個底做測試；在 3.3 × 10^24 以下保證正確（這是已發表的數學結果），我們的數都在範圍內。
- `term(k)`：k 是不是 A073631 的成員：k > 1、不是質數、而且 `pow(3, k-1, k) == pow(2, k-1, k)`（3^(k−1) 和 2^(k−1) 除以 k 餘數相同）。
- 第一個迴圈：對 23、3842760169、41975417117，檢查是質數，而且 3^(q−1) 和 2^(q−1) 除以 q² 餘數相同（Wieferich 條件），但除以 q³ 不同。
- 第二個迴圈：k = q²，檢查 `term(k)` 成立而且 `k % 529 != 0`（不是 529 的倍數），印出反例。
- 最後檢查 23⁴ 不是成員（證明裡排除 23 的更高次方用到）。

`pow(a, b, m)` 是 Python 內建的快速冪，b 有 20 位數也能瞬間算完。

## wieferich32.c：找 Wieferich 質數

需要 C 編譯器（Windows 上較麻煩，可以只看說明）。

1. 用分段篩法列出範圍內所有質數 p。
2. 對每個 p，算 3^(p−1) 和 2^(p−1) 除以 p² 的餘數（自己寫的快速冪 `pw`，用 128 位元整數避免溢位），一樣就印出 `HIT p`。
3. `#pragma omp parallel for` 讓電腦用多個核心同時跑不同段。

指令：`gcc -O2 -fopenmp -o w wieferich32.c -lm` 然後 `./w 1 4294967295`。結果只印出 23 和 3842760169。

## a073631_scan.c：直接掃序列

1. 篩法標記合數（非質數），同時標記「有平方因數」的數（對每個 i，把 i² 的倍數都標起來）。
2. 對每個合數 k ≤ N，檢查 3^(k−1) 和 2^(k−1) 除以 k 餘數是否相同。
3. 是成員又有平方因數時，看是不是 529 的倍數；不是就印 `BAD k`。

掃到 10^9：60 個有平方因數的成員，全部是 529 的倍數，沒有 BAD。這說明為什麼原作者看前 50 項會以為猜想對：反例要到 1.4 × 10^19 才出現。

## 不用程式也能自己驗證（只要 Python）

```python
pow(3, 22, 529), pow(2, 22, 529)        # 兩個都是 392 → 23 是 Wieferich 質數
q = 3842760169
pow(3, q-1, q*q) == pow(2, q-1, q*q)    # True
k = q*q
pow(3, k-1, k) == pow(2, k-1, k)        # True → k 在序列裡
k % 529                                  # 不是 0 → 不是 529 的倍數
```
