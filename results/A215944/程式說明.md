# A215944 程式說明（高二版）

## 共用的工具：反例搜尋器 `discovery/cxsearch/`

這個結果是用專案自己寫的「反例搜尋器」找到 / 檢查的。它的做法：

1. **先建一份清單**：10^10 以下所有以 2 為底的偽質數（psp2），共 14884 個，存在 `data/cx/psp2_1e10.txt.gz`。這份清單是用 C 程式 `discovery/cxsearch/psp2.c` 產生的：先用篩法把質數劃掉，剩下的奇數 n 用快速冪檢查 2^(n−1) 除以 n 是否餘 1。
2. **檢查清單對不對**：`catalog.check` 用 Python 重新驗證每一個都是 psp2，並且和 OEIS 上的已知個數（A055550：10^3 以下 3 個、10^4 以下 22 個、……、10^10 以下 14884 個）逐一比對。
3. **每個猜想寫成一個檢查函數**（在 `discovery/cxsearch/conjectures.py`），對清單上每個數跑一次，列出不符合的。

`discovery/cxsearch/numth.py` 是共用的數論小工具：判斷質數（Miller–Rabin 測試，在 3.3 × 10^24 以下保證正確）、因數分解（Pollard rho 方法）等。

## 怎麼自己跑

1. 裝 Python 3（python.org，安裝時勾「Add Python to PATH」）。
2. 到 https://github.com/Bonnie9981/Project-Discovery 按「Code」→「Download ZIP」，解壓縮。
3. 在解壓縮的資料夾（看得到 `discovery`、`data` 這些資料夾的那一層）開終端機，輸入下面「指令」那一行。整個跑完大約幾秒到十幾秒。

**指令：**

```
python -m discovery.cxsearch scan A215944
```

我們跑的結果（開頭部分）：

```
{"key": "A215944", "domain": "psp2", "limit": 10000000000, "checked": 14884, "failures": 211,
 "first": [{"n": 3048841, "factors": {"61": 1, "151": 1, "331": 1}}, {"n": 4072729, ...}, ...]}
```

意思是：檢查了 14884 個 psp2，有 211 個違反猜想，最小的是 3048841 = 61 × 151 × 331。

## A215944 的檢查函數在做什麼（`conjectures.py`）

- **`in_a215944(n)`：n 是不是 A215944 的成員。** 先因數分解，要剛好三個質因數（重複的也算）；再看三個「兩兩相乘」a×b、a×c、b×c 裡，有沒有一個是比 n 小的 psp2。和條目的 b-file 對照過（798 個，個數和總和都一樣）。
- **`coman_form(n)`：能不能寫成 Coman 的形式。** 把所有可能的 p（n 的因數、p³ ≤ n）和 A × B = n/p 的拆法都試一遍，看 A、B 是否都 ≥ 2p − 1 且除以 p − 1 餘 1（這就是 A = (m+1)p − m、m ≥ 1 的意思）。找到就回傳那組 (p, A, B)。
- **`a215944(n)`：是不是反例。** 是成員、不能寫成 Coman 形式、也不是 5461 × (42k − 13)，三個條件都滿足就是反例。

## 最簡單的自己驗證（只要 Python，不用下載 repo）

打開 Python（在終端機打 `python` 進入），一行一行輸入：

```python
61 * 151 * 331                 # 應該是 3048841
pow(2, 3048840, 3048841)       # 2^(N-1) 除以 N 的餘數，應該是 1 → N 是 psp2
pow(2, 49980, 49981)           # 應該是 1 → 49981 = 151*331 也是 psp2
3048841 % 49981                # 應該是 0 → 49981 整除 N
151 % 60, 331 % 60             # 應該是 (31, 31) → 不是除以 60 餘 1
3048841 % 5461                 # 不是 0 → 不是 5461 的倍數
```

`pow(a, b, m)` 是 Python 內建的快速冪，算 a^b 除以 m 的餘數，即使 b 很大也一瞬間算完。
