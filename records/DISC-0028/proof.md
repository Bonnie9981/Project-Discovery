# DISC-0028 證明

## 定理對照

完整證明見 `paper/a308758-four-parts.md`（英文，OEIS 要連的頁面）。摘要：

1. (a,b,c,d) ↦ (a+1,b,c,d) 把 P(n−1) 單射到 P(n)，像是 a > b 的那些；b、c、d 不變，a 加 1。
2. 剩下的 E(n) = {(a,a,c,d)} 與 T(n−1) 一一對應：(a,a,c,d) ↦ (c, a, a+d−1)，反函數 (x,y,z) ↦ (y,y,x,z−y+1)。三角不等式 x+y>z 正好等價於 c ≥ d。
3. 對應下 c = x、a = y、d = z−y+1，得 H1–H4。
4. g.f.：參數化 d=y4、c=y4+y3、b=y4+y3+y2、a=全部，n=y1+2y2+3y3+4y4，Σy_i 的 g.f. 是 F·x^i/(1−x^i)（i≤3）和 F/(1−x^4)；是有理函數，與 Barker 的比較前 120 項即得相等（H5 的分拆那五條）；三角形三條由 H1–H3 與 A005044 的古典 g.f. 推出。

沒有 Lean（容器沒有 Lean 工具鏈；這需要 Finset 上的雙射求和，留作後續）。依研究規範第 1 節，沒有 Lean 不能標 PROVEN。

## 編譯結果

沒有 Lean 檔，所以沒有編譯。證明是紙上證明加精確有理函數比對（程式）。

## 敘述差異

- OEIS 用 offset 0（分拆那五條）和 1（三角形那三條），本證明的 n、n−1 都照 OEIS 的索引；n = 1、2、3 時兩邊都是 0。
- Barker 的遞迴式只在 g.f. 推得的範圍內成立（他寫的 for n > …），本紀錄只宣稱 g.f.。
