# DISC-0006 文獻與 OEIS 查證（M1.3）

查詢日期：2026-11-22。管道：使用者的 Chrome（OEIS 線上搜尋、OpenAlex API，無 API key）。這只是有限範圍的查詢，查不到不代表新。

## 問題

M1.3 的三條候選：

- **C01**（DISC-0004）：σ(σ_odd(n)) = σ_odd(σ(n)) ⇔ n 是奇平方數。
- **C02**（DISC-0004）：若 rad(σ(n)) = σ(rad(n))，則 n ∈ A065301，或 n = 2^a·p（p 是奇質數，a 是奇數且 ≥ 3）。
- **R2-C10**（DISC-0005）：規則 54、寬度 w 的環、單一種子出發，w ≥ 6 時暫態 T₅₄(w) 依 w mod 4 = 1、2、3、0 分別是 w−3、(w−6)/2、(w−7)/2、(w−4)/2，週期是 4。

## 已知成果

- **A065301**（k 和 σ(k) 都無平方因子）：
  - 有 Eldar（2025）的刻畫：k 無平方因子，k 的質因數都在 A049097 中，而且 {p+1 : p | k} 兩兩互質。
  - 條目沒有提到 rad(σ(n)) = σ(rad(n))。不過「A065301 ⊂ 解集」本身是一步推論：n 無平方因子時 rad(n) = n；σ(n) 無平方因子時 rad(σ(n)) = σ(n)。
- **C01：** 「σ(m) 是奇數 ⇔ m 是平方數或兩倍平方數」是教科書結果。C01 的「⇐」方向（n 是奇平方數時兩邊相等）可以由 n 奇數時 σ_odd(n) = σ(n)、而且 σ(n) 是奇數直接推出。真正的內容在「⇒」方向。
- **規則 54：**
  - 有關於滑翔機碰撞和邏輯閘的研究，例如 Martínez、McIntosh 等，"Phenomenology of glider collisions in cellular automaton Rule 54..."，Chaos Solitons Fractals 2005，doi:10.1016/j.chaos.2005.05.013。
  - 單一種子在環上的週期序列已收錄在 OEIS 的 A334496–A334515 系列（DISC-0005 的快照篩選）。
  - 沒有找到環上暫態的封閉公式。

## 研究空白

- 解集 {n : rad(σ(n)) = σ(rad(n))} 的完整序列（…, 409, **416**, 421, …）在 OEIS 線上搜尋**查無**。A065301 以外的解（416, 872, 1832, 3272, 5672, 5792, 6152, …）也**查無**。目前只能判定為 `NO_MATCH_IN_SCOPE`。
- 規則 54 的暫態序列（從 w = 6 起：0, 0, 2, 6, 2, 2, 4, 10, 4, 4, 6, 14, 6, 6, 8, 18, …）在 OEIS 線上搜尋**查無**，判定為 `NO_MATCH_IN_SCOPE`。
- C01 的「⇒」方向是一個集合等式，OEIS 只能比對集合本身（奇平方數 A016754），所以沒辦法比對這個刻畫。
