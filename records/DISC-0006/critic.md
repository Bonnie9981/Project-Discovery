## 攻擊項目

### C01：σ(σ_odd(n)) = σ_odd(σ(n)) ⇔ n 是奇平方數

1. **定義與邊界。** σ_odd 取 A000593（奇因數和），σ_odd(1) = 1。n = 1：兩邊都是 1，1 是奇平方數，一致。沒有 off-by-one。唯一的定義風險：有些文獻把「σ_odd」寫成 Σ_{d|n, n/d 奇} d（A002131），若誤用，敘述就不是同一條。報告要寫明「σ_odd = A000593」。
2. **奇數 n 是一步。** n 奇時 σ_odd(n) = σ(n) = m，等式變成 σ(m) = σ_odd(m)，也就是 m 是奇數；n 奇時 σ(n) 奇 ⇔ n 是平方數。所以「⇐」方向和奇數情形都是一步，C01 的全部內容在「n 偶數時等式不成立」。
3. **偶數情形的化約（我證明的引理）。** 設 n = 2^a·u（a ≥ 1，u 奇），σ(u) = 2^v·o（o 奇），M = 2^{a+1} − 1。則
   σ(σ_odd(n)) = σ(2^v o) = (2^{v+1} − 1)σ(o)，σ_odd(σ(n)) = σ_odd(M·2^v·o) = σ(Mo)。
   等式 ⇔ σ(Mo) = (2^{v+1} − 1)σ(o)。
   - 因為 M > 1，σ(Mo)/(Mo) > σ(o)/o，所以 σ(Mo) > M·σ(o)；又 σ(Mo) ≤ σ(M)σ(o)。
   - 於是 M < 2^{v+1} − 1 ≤ σ(M)。左邊推出 v ≥ a + 1，所以 2^{v+1} − 1 ≥ 2M + 1，得 **σ(M) > 2M：M = 2^{a+1} − 1 必須是過剩數**。
   - 程式列出 a + 1 ≤ 60 中 2^{a+1} − 1 過剩的只有 a + 1 ∈ {12, 24, 36, 40, 48, 60}。
   - a + 1 = 12：M = 4095 = 3²·5·7·13，σ(M) = 8736，唯一可能的目標是 2^13 − 1 = 8191。比值 Π σ(p^{e+f_p})/σ(p^{f_p}) 對每個 f_p 遞減。全部 f_p = 0 時比值是 8736 ≠ 8191；任何一個 f_p ≥ 1 時，相對比值最多是 1.444·1.2·1.1429·1.0055 ≈ 1.992 < 8191/4095 ≈ 2.0002，達不到目標。DFS 也確認這一支是窮舉（沒有被上限截斷的分支）。**所以 a = 11 完全排除。**
   - 結論：**C01 對所有 v₂(n) ≤ 22 的 n 都成立（已證）**。反例若存在，必須 v₂(n) + 1 ∈ {24, 36, 40, 48, 60, …}，而且 v₂(σ(u)) ≥ v₂(n) + 1 ≥ 24。
4. **對報告數值證據的攻擊（重要）。** 由上一點，偶數反例最小也要 n ≥ 2^23·u，且 2^24 | σ(u)。光是 a = 11 這一支，要 2^12 | σ(u) 的最小奇數 u 就是 2667（程式算出），對應 n ≥ 2^11·2667 ≈ 5.5×10⁶，已經超過 2×10⁶。所以 **10⁶、2×10⁶ 的數值檢查在偶數情形其實沒有碰到任何「有機會出錯」的 n**，它的證據力是零；真正的支持來自上面的引理和下面的代數搜尋。
5. **代數反例搜尋。** 對 a + 1 ≤ 36 窮舉 f_p ≤ 8，對 a + 1 ≤ 48 窮舉 f_p ≤ 6，對 a + 1 ≤ 60 窮舉 f_p ≤ 4，找 Π_{p|M} σ(p^{e_p+f_p})/σ(p^{f_p}) = 2^j − 1（j ≥ a + 2）：**0 個解**。這個搜尋比原命題更強，因為它不要求 o 真的是某個 σ(u) 的奇部分。但 a + 1 ≥ 24 時上限 f_p ≤ 6 有被截斷的分支（大質因數的 f_p 可以任意大，比值仍可能超過門檻），所以**不是證明**。
6. **奇偶性攻擊。** o 是平方數時，Mo ≡ 3 (mod 4) 不是平方數，σ(Mo) 偶、左邊奇，不成立。這只排除 o 平方的情形，和第 3 點獨立，可以一起用。

**判定：存活。** 不是一步推論（偶數部分需要上面的過剩數引理和有限窮舉），但比報告描述的更接近完整證明：v₂(n) ≤ 22 已證，剩下的是「2^m − 1 過剩（m ≥ 24）時的比值方程」。

### C02：rad(σ(n)) = σ(rad(n)) ⇒ n ∈ A065301 或 n = 2^a·p（a 奇且 ≥ 3）

1. **邊界。** n = 1：rad(1) = 1，σ(1) = 1，等式成立，1 ∈ A065301。n = 2：σ(2) = 3，rad 3 = 3 = σ(2)，2 ∈ A065301。沒有問題。
2. **「a ∈ {3,5,7}」是範圍造成的假象。** 報告 note 寫 671 個額外解「全部是 2³p、2⁵p、2⁷p」，敘述本身沒有宣稱 a 只有這三個值，這點正確。但我直接構造出更大的 a：
   - a = 9：n = 5935616 = 2⁹·11593（2¹⁰ − 1 = 3·11·31，11593 + 1 = 2·11·17·31）
   - a = 11：n = 20498432 = 2¹¹·10009
   - a = 13：n = 1699979264 = 2¹³·207517
   - a = 15：n = 41517350912 = 2¹⁵·1267009
   
   全部用試除法直接驗證等式成立。以後任何寫成「a ∈ {3,5,7}」的版本都是錯的。
3. **完整證明（初等，用 LTE，不需要 Zsigmondy）。** 這條其實可以證成一個完整刻畫：
   - (i) 等式右邊 σ(rad n) = Π_{q|n}(q + 1) 等於一個 radical，所以必須無平方因子。兩個奇質數 q₁、q₂ 會讓 4 | (q₁+1)(q₂+1)，所以 rad(n) ∈ {1, 2, p, 2p}（p 是奇質數），而且 p + 1 無平方因子（因此 p ≡ 1 mod 4）；rad n = 2p 時還要 3 ∤ p + 1。
   - (ii) n = 2^a：2^{a+1} − 1 必須是 3 的冪。由 LTE，v₃(2^m − 1) = 1 + v₃(m/2) ≤ log₃(3m/2)，所以只有 m = 2，也就是 n = 2。
   - (iii) n = p^b 或 2^a·p^b（b ≥ 1）：rad(σ(n)) 是偶數，所以 σ(p^b) 是偶數，b 是奇數。令 Q = σ(p^b)/(p+1) = (p^{b+1} − 1)/(p² − 1)。允許出現在 rad(σ(n)) 裡的質數是 2、3 和 p + 1 的質因數，它們都整除 p² − 1（p ≠ 3，因為 3 + 1 = 4 不是無平方因子）。對每個這樣的質數 q，LTE 給出 v_q(Q) = v_q((b+1)/2)（q = 2 時也成立：v₂(p^{b+1} − 1) = v₂(p−1) + v₂(p+1) + v₂(b+1) − 1）。所以 Q | (b+1)/2；但 Q = 1 + p² + … + p^{b−1}，b ≥ 3 時 Q > (b+1)/2。矛盾，所以 **b = 1**。
   - (iv) n = 2^a·p：σ(n) = (2^{a+1} − 1)(p + 1)，條件變成 rad((2^{a+1} − 1)(p+1)) = 3(p+1)。因為 3 ∤ p + 1，所以 3 | 2^{a+1} − 1，a 是奇數，而且 2^{a+1} − 1 的質因數都在 {3} ∪ (p+1 的質因數) 裡。a = 1 時 n = 2p 無平方因子，σ(n) = 3(p+1) 也無平方因子，n ∈ A065301；a ≥ 3 時 n 不是無平方因子，就是敘述中的第二類。
   - (v) n = p：n ∈ A065301。
   
   由此得到**完整刻畫**：解集合 = A065301 ∪ {2^a·p : a 奇且 ≥ 3，p + 1 無平方因子，3 ∤ p + 1，rad(2^{a+1} − 1) | 3(p+1)}。副產品是 A065301 = {1, 2} ∪ {p : p + 1 無平方因子} ∪ {2p : 3(p+1) 無平方因子}。這兩條我都數值驗證到 2×10⁶（見下節）。
4. **是否已知／平凡。** 上面的論證不是一步，但每一步都是標準工具（無平方因子 + LTE），大約一頁。A065301 本身的結構（{1,2} ∪ 特定質數 ∪ 2×特定質數）很可能已經寫在 OEIS 的 COMMENTS 裡；我這次連不到 oeis.org（proxy 回 403），離線快照只有名稱和數列，**沒辦法確認**。建議等級：「L1、已有紙上證明」，而且要把敘述升級成上面的完整刻畫。用 Lean 證明時可以用 Mathlib 的 LTE（`padicValNat.pow_sub_pow` 一類），不需要 Zsigmondy。

**判定：存活，而且已經有證明。** 原敘述是真的，但只是完整刻畫的弱版本，新穎性很可疑。

### R2-C10：規則 54，T₅₄(w) 依 w mod 4 的公式，P = 4

1. **範圍與邊界。** w = 1..5 的 (T,P) 分別是 (1,1)、(2,1)、(2,1)、(0,4)、(5,1)。w = 5 時軌道 1 → 10011 → 01100 → 10010 → 11111 → 00000，最後死掉（P = 1），公式給 2，**所以 w ≥ 6 這個下界必要，而且剛好卡在 w = 5**。w = 4 其實也符合公式（T = 0，P = 4），敘述可以寫成「w = 4 或 w ≥ 6」。「週期恆為 4」只在 w = 4 和 w ≥ 6 成立；w ≤ 3 和 w = 5 的週期是 1。報告寫「看起來恆為 4」，沒有寫明範圍，要補上。
2. **T 的定義。** T = 第一個落在循環上的時刻（S_T = S_{T+P}）。我的實作也是這個定義（dict 記第一次出現的時刻），和 repo 一致。
3. **時空圖結構（我證明的部分）。** 在無限直線上，從 x = 0 的單一種子出發，以 E_t 記 ether：
   - t 偶數：E_t(x) = 1 ⇔ x ≡ t (mod 4)
   - t 奇數：E_t(x) = 0 ⇔ x ≡ t + 1 (mod 4)
   
   也就是「#...」和「###.」交替，空間週期 4，時間週期 4（每 2 步平移 2 格）。**命題：S_t(x) = E_t(x)（|x| ≤ t），|x| > t 時為 0**，兩側前緣速度恰好是 1（光速）。用 F = c ⊕ (l ∨ r) 做歸納，內部和兩個邊界格各有 4 種情形，都是直接代值（我手算過，也用 `ca54b.py` 在環上 2t + 1 ≤ w 的範圍對 w ≤ 1200 全部比對，0 失敗）。
4. **由此推出 w ≢ 1 (mod 4) 的公式（證明草稿）。** 只要 2t + 1 ≤ w，環上的狀態就是上面那個錐形折到環上。在 t₀ = 2⌊(w − 4)/4⌋ 這個偶數時刻，錐外剩下的 0 串長度是 g = w − 2t₀ − 1：
   - w ≡ 0：g = 3，整圈剛好是完整的 ether「#...」，週期 4，T = (w − 4)/2。
   - w ≡ 2：g = 5，是 ether 加一個寬 6 的缺陷「#.....」。
   - w ≡ 3：g = 6，是 ether 加一個寬 7 的缺陷「#......」。
   
   這兩種缺陷是規則 54 的**靜止粒子**，4 步後回到原樣。證明方法是局部性：4 步的影響半徑是 4，離缺陷超過 4 的地方是純 ether，會自己回來；缺陷附近的局部圖樣和 w 無關（只要 w 夠大）。所以「每個剩餘類有一個足夠大的 w 成立」加上有限檢查，就推出全部 w；而我已經算到 w = 1200。
   
   下界：前一刻 S_{T−1} 是奇數列，錐外 0 串長度是 g + 2，循環裡最長的 0 串分別是 3、5、6（程式對 w < 400 確認）。所以 S_{T−1} 不在循環上。**R2-C10 在 w ≡ 0, 2, 3 (mod 4) 的部分，實質上就是「光錐 + ether 的接縫剛好是穩定缺陷」**，難度不高。
5. **w ≡ 1 (mod 4)（T = w − 3）才是實質內容。** 在 t = (w − 5)/2 時，錐外剩下長度 4 的 0 串（「#....#」），這個接縫不是穩定缺陷，會分裂成兩道相位牆，以速度 ±1 往種子方向移動。牆內是原來的 ether，牆外是相位差 2 的 ether。我量了 k = 2..39（w = 4k + 1）：t ≥ 2k + 1 時，和 E_t 一致的中心區域半徑恰好是 w − t − 1，**牆速恰好是 1**。兩道牆在種子附近相遇，留下一個靜止缺陷（在 w = 41 的圖上，t ≥ 40 時中心是「#####／.....」交替），所以 T ≈ (w − 5)/2 + (w − 1)/2 = w − 3。這個公式就是「接縫時間加上牆從對蹠點走回種子的時間」。要完整證明，還需要用局部性有限檢查兩件事：牆的平移週期性，以及兩牆碰撞的結果。在 w ≡ 1 的情形，前一刻和循環的最長 0 串都是 6，所以第 4 點的 0 串論證不夠用，需要別的論證。
6. **文獻。** 這和 Hanson–Crutchfield（Physica D 103, 1997）對 ECA 54 的「domain + 粒子」分析在結構上相符：ether 是規則 54 的 domain Λ，速度 ±1 的牆對應 γ± 粒子，靜止缺陷對應 α／β 類粒子。另外 Boccara–Nasser–Roger（1991）和 Martínez–Adamatzky–McIntosh 也研究過規則 54 的粒子。**這些引用是憑記憶，本次沒有查到原文**，粒子名稱和速度要再核對。單一種子在環上的暫態公式本身，我在離線 OEIS 快照裡搜「2,6,2,2,4,10,4,4,6,14,6,6,8,18」和 T + P 序列，都沒有吻合；A204714 是「所有初始狀態的最大週期」，不是同一個東西。

**判定：存活。** w ≡ 0, 2, 3 這三類幾乎是一步（光錐引理 + 局部性 + 有限檢查）；w ≡ 1 有實質內容，物理機制清楚（光速相位牆），可以證，但還沒寫完。
