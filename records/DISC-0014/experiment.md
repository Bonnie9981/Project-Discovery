# DISC-0014 實驗

## 方法

`research/r003/l07_a071052_even.py`，只用標準函式庫：
- 方法一：直接模擬規則 150（串列，位置 −n..n）。
- 方法二：(1+x+x²)^n 在 GF(2) 上的係數（整數位元、無進位乘法），0 的個數 = 2n+1 − 1 的個數。
- 0 ≤ n ≤ 2000 兩法一致；和條目 67 項 DATA 逐項一致；0 ≤ n ≤ 1000 逐格檢查 H1（第 2n 列偶數格 = 第 n 列、奇數格全 0）與 H3。
- 兩種算法在同一個檔案、共用手抄 DATA；critic 另寫第三套（Lucas 奇偶法，`research/r003/critic_c_a071052.py`）。

## 結果

全部 OK，約 0.5 秒。例：a(2) = 2 = a(1) + 2，a(8) = 14 = a(4) + 8 = 6 + 8。

## 重現方式

```
python research/r003/l07_a071052_even.py 2000
```
