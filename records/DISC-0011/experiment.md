# DISC-0011 實驗

## 方法

`research/r003/l04_rule54_mod23.py`，所有 6 ≤ w ≤ W、w ≡ 2, 3 (mod 4)：
- 方法一：`research/r002/impl_b.py` 的位元模擬加 Brent，算（暫態, 週期）。
- 方法二：自己寫的 list 模擬（不用 repo 的程式），字典找第一次重複。
- 兩者都要等於 (T, 4)。
- H1：對每個 t ≤ T 逐格比對對折光錐；H2：k = 0..8 逐格比對 ether 加中心缺陷。

## 結果

- W = 1200（598 個寬度）全部 OK，約 21 秒；W = 400 約 1 秒。
- 例：w = 6, 7 是 (0, 4)；w = 18, 19 是 (6, 4)，缺陷在 k = 1 時第 9 格（w = 18）或第 9、10 格（w = 19）。
- w ≤ 5 不在範圍內：(暫態, 週期) 是 w = 2, 3 → (2, 1)，w = 5 → (5, 1)（週期 1，全死或全活）。
