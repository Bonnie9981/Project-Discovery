## 攻擊項目

1. **定理 1 的代數，逐步核對。** (1−x)(1−x−…−x^(j−1)) = 1−2x+x^j，j = 1 時 N_1 = 1、1−2x+x = 1−x，成立。(1−x)K = (1−x)²/(1−2x) = (1−2x+x^j)N_j K = (1−2x)N_j K + x^j N_j K = (1−x)N_j + x^j N_j K，用到 (1−2x)K = 1−x，沒問題。所以 (1−x)(K−N_j) = x^j N_j K。常數項：K−N_j 在 x^0 是 1−1 = 0（空組合不算「最大 ≥ j」），B_j(0) = 0，兩邊在 n = 0 都是 0；乘 (1−x) 時自動用 A_j(−1) = 0，n = 1 用 A_j(0) = 0。結果：沒有錯。
2. **「有等於 j 的紀錄 ⇔ 第一個 ≥ j 的部分等於 j」。** ⇒：紀錄 j 前面的部分都 < j，所以它就是第一個 ≥ j 的部分。⇐：第一個 ≥ j 的部分等於 j，表示前面都 < j，所以是紀錄。紀錄的值嚴格遞增，所以每個值最多算一次，紀錄總數 = Σ_j [有紀錄 = j]。我的暴力程式直接用「j 在紀錄值裡」和「第一個 ≥ j 的是 j」兩種寫法分開算，n ≤ 16、所有 j 都和 A_j(n) − A_j(n−1) 一樣。結果：OK。
3. **offset。** A102712 的 offset 是 1，A336482 是 0（a(0) = 0），A119706 是 1。證明頁寫 n ≥ 1 並約定 A102712(0) = 0；草稿寫 n ≥ 2，不用到 A102712(0)，n = 1 時兩邊照約定也是 1 = 1 − 0。定理 2：n = 1 時 A119706(1) = 1 = A102712(2) − 2 = 3 − 2。結果：OK。
4. **定理 2 的雙射。** n 個位元 ↔ n+1 個 1 之間的 n 個空隙，2^n ↔ 2^((n+1)−1)，數目對。部分 ↔ 以 0 分隔的極大連續 1 段（可以是空段），長度 k ↔ 部分 k+1；全 0 字串 ↔ 1+…+1，最長 0 ↔ 最大 1。結果：正確。證明頁寫「a run of k consecutive 1's」，嚴格說應該是「maximal run」（見建議 1）。
5. **草稿的 g.f.** 自己用 Fraction 冪級數展開 (1−x)²/(1−2x)·Σ_{i≥1} x^i/(1−2x+x^i) 到 x^39，前 34 項和 A336482 存的 34 項完全一樣。gp 再算一次，前 20 項也一樣。結果：正確。
6. **草稿的 PARI 指令。** 本機有 gp，原樣跑：`vector(15,n,R(n+1)-L(n+1)+L(n))` 得到 15 個 0（就是驗 n = 2..16）；`vector(8,n,L(n))` = 1,3,8,19,43,94,202,428；`vector(8,n,R(n))` = 1,2,5,11,24,51,108,226，和 程式說明.md 寫的一樣。L 把 bit = 1 當「切」，R 也是，兩者一致。結果：指令算的就是宣稱的內容。
7. **專案程式本身。** `check_a336482.py 18` 重跑，輸出和 experiment.md 一樣（A102712:33、A336482:34、A119706:32；我數過，三條條目存的項數剛好是 33、34、32，所以「全部項都比過」屬實）。缺點有兩個：(a) 「實作二」`fast()` 直接用證明裡的分解式 B_j = Σ N_j(k)·C(n−k−j) 和 A_j = C − N_j 做遞推，所以它驗的是證明的算式，不是和證明無關的第二套算法；真正獨立的是拿去比 OEIS 資料（Heinz 的 Maple 遞推）。(b) `fast()` 和 n < 80 的檢查放在只接 `FileNotFoundError` 的 try 裡面；沒有離線 OEIS 時遞推照跑，但輸出寫「skipped」，看不出遞推到底有沒有跑。
8. **A102712 的兩個舊 g.f. 已經直接推出 Mathar 猜想。** 用 gp 驗：A102712 的 Deutsch g.f. F = Σ n(1−x)²x^n/((1−2x+x^n)(1−2x+x^(n+1)))，A119706 的 Balado g.f.（2025-10-20）B = Σ k x^k(1−x)²/((1−2x+x^(k+1))(1−2x+x^(k+2)))；F/x − B − 1/(1−2x) = O(x^29)。差的那一項是 Σ x^(n−1)(1−x)²/(D_n D_(n+1))，也就是「最大部分剛好是 n」的組合對 n 求和，等於全部組合 1/(1−2x)。所以 OEIS 裡已經有兩條公式，相減一步就得到這個猜想，只是沒有人寫出來。這不會讓證明出錯，但第 1c 節 L1 要求「不是已知公式一步就能推出」，定理 2 不符合；草稿也沒提到這件事。
