# DISC-0026 實驗

## 方法

**A372430（DFS 剪枝）**：k 的位數為 L 時，最高位（指標 L）一定是 1，所以 prime(L) | k。從最高位往下決定每一位：設為 1 就把該位的質數乘進必須整除的模數 M。在還沒決定的 r 個低位內，k 落在長 2^r 的區間；當 2^r / M < 8 時，直接列出區間內 M 的倍數逐一完整檢查。這是窮舉，不是抽樣：任何解都會在某條分支被列出。`a372430_dfs.c`，128 位元整數。

**獨立檢查**（`results/A372430/code/check372430.py`，Python 大整數，不同演算法）：k ≤ 10^6 暴力；所有至多 4 個 1 位元、k < 2^120 的數直接枚舉位置。

**A219433**：篩出質數，對每個 p 依序試 3-smooth 數 a（排序好的 2^i 3^j），用 12 底確定性 Miller–Rabin 判 p·a + 1（< 2^64 時確定；溢位前停）。`a219433_scan.c`。

## 結果

| 項目 | 範圍 | 結果 | 時間 |
|---|---|---|---|
| A372430 DFS | 所有 k < 2^120（L ≤ 120） | 只有 4100 和 **2^87 + 2^49 = 154742504911235484315811840**；67 億個節點 | 3 分 20 秒 |
| A372430 Python | k ≤ 10^6；≤ 4 個 1 位元、k < 2^120 | 只有 4100（暴力）；4100 和同一個反例（枚舉） | 數秒 |
| A219433 | n ≤ 10^8（p ≤ 2038074743） | 只有條目已知的 n = 522720 一個例外 | 約 10 分鐘 |

反例細節：k = 2^49·(2^38 + 1)，2^38 + 1 = 5 · 229 · 457 · 525313；二進位指標 {50, 88}，prime(50) = 229、prime(88) = 457。自我檢查：DFS 在 L ≤ 30 就重新找到 4100。

所以 2^87 + 2^49 是 4100 之後**最小**的數（2^120 以內只有這兩個）。
