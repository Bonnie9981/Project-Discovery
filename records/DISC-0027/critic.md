## 攻擊項目

1. **引理 1（LD ⇔ 空隙規則），兩個方向都檢查過。**
   - 支配部分：內部空隙 ≥ 3 時，中間那個 0 沒有鄰居在 S 裡；端點空隙 ≥ 2 時，最外面那個 0 沒有鄰居在 S 裡。反過來，條件 (a) 成立時每個 0 都碰得到 1。正確。
   - 區分部分：證明直接從「共同集合含某個 p」跳到 N(p−1)∩S = {p}，中間少寫一句「兩個不同點最多只有一個共同鄰居」。在 P_n 和 n ≥ 5 的 C_n 上這句話成立。在 C_4 上 1 和 3 有兩個共同鄰居 {2,4}，這才是 n = 4 例外真正的原因。論文把原因說成「p−2 = p+2」，兩種說法等價，但前者更直接。列為建議項。
   - 邊界情形：k = 1 時，g_0 和 g_1 都是端點空隙，兩個都長 ⇔ 字串是 010（n = 3），這組正確排除。n = 1 時字串 "1" 的兩個端點空隙都是 0，算進去，正確。p = 1 或 p = n 時不存在 p−1 或 p+1 這一對，證明不受影響。
2. **定理 1 的轉移權重**：逐項核對了 s = (1, x)、xT = [[x+x², x³],[x+x², 0]]、t = (1+x, 1)，以及前面那個 x（代表最後一個 1）。用 sympy 化簡 x·s(I−xT)^{-1}t，結果是 x(1+2x+2x³+x⁴)/(1−x−x²−x⁴−x⁵)，和論文一致。小 n 驗算：k = 1 給 x(1+2x)，k = 2 補上 n = 2 的 "11"，合計 a(2) = 3，正確。分子是 5 次，所以遞迴從 n ≥ 6 開始成立，論文寫法正確。
3. **定理 2 的鋪磚雙射**：
   - 一般情形：四種磚 1、10、1001、10010 對應的空隙依序是 (0)、(1)、(2,0)、(2,1)。每個 2 後面接的一定是 0 或 1，所以任何鋪法都滿足「沒有相鄰兩個 2」。反過來，0/1 字串決定了 1 的位置，也就唯一決定鋪法，兩邊互為單射。
   - 單一磚蓋住整個環（n = l）時，l 種轉法對應 l 個不同的字串，c(n) = Σ l·t(n−l) 在 n = l 時也成立。
   - 單一個 1 的情形：n ≥ 5 時唯一空隙長 n−1 ≥ 4，不支配，正確排除。
   - 公式 c(n) = Σ l·t(n−l) 其實對所有 n ≥ 1 都成立，例如 c(1) = 1、c(2) = 3。只有「鋪磚數 = LD 個數」這一步需要 n ≥ 5（或 n = 3）。
4. **引理 3（識別碼 ⇔ 字串規則）**：
   - 距離 1：N[i]ΔN[i+1] = {i−1, i+2}，i = 2..n−2 給出 j = i−1 ∈ [1, n−3]；i = 1 給 w_3 = 1，i = n−1 給 w_{n−2} = 1。
   - 距離 2：差集裡含 {i−1, i+2}，或在 i = 1 時含 3，所以已經被 (a)、(b) 蓋住。
   - 距離 ≥ 3：兩個閉鄰域不相交，又都非空，自然不同。
   - n = 3：(b) 變成 w_1 = w_3 = 1，識別碼只有 {1,3} 和 {1,2,3}，正確。沒有找到漏洞。
5. **定理 3 的 Cayley–Hamilton 起始 n**：特徵多項式 x·q(x) 是 8 次，從 M^{m+8} 到 M^{m+1}（m ≥ 0）推出遞迴在 n ≥ 11 成立，論文寫法正確。生成函數的分子是 7 次，所以遞迴從 n ≥ 8 開始；n = 8..10 由暴力值補上，論文也這樣處理。特徵多項式我用自己建的 8×8 矩陣、Faddeev–LeVerrier 方法、Fraction 精確運算重算，結果是 [1,−1,−1,1,−1,−1,0,1,0]，也就是 x(x⁷−x⁶−x⁵+x⁴−x³−x²+1)，和論文一致。
6. **漸近根**：1.81240361926804 和 1.58133345501955 用 sympy 的 nroots 重算，和草稿寫的一致。
