# DISC-0027 實驗

## 方法

- 程式：repo commit 8a69b45（加上本 PR），Python 3.13.18；`python results/A308758/code/check_a308758.py 200`，約 7 秒。
- 實作一（暴力）：直接枚舉 a≥b≥c≥d≥1 和 x≤y≤z、x+y>z，n ≤ 200 檢查 H1–H4，以及計數版。
- 實作二（雙射）：對每個 n ≤ 200 列出 E(n) = {(a,a,c,d)} 和 T(n−1)，驗 (c,a,a+d−1) 的像恰好等於 T(n−1)。
- 實作三（生成函數）：用 y1+2y2+3y3+4y4 參數化寫出精確有理 g.f.，與 Barker 的 g.f. 以分數運算比較前 120 個係數（兩邊分子分母次數和都小於 60，所以相等）；三角形的 g.f. 由 H1–H3 推出再比較；並與暴力值比對。
- 實作四（PARI/GP 2.15.4，給使用者自驗用）：forpart 寫法，n ≤ 40 的 H1 差全為 0。
- OEIS 資料：九條條目存的全部項（49～74 項）都和暴力值一致。
- 結果：全部通過。

挖掘器：`python -m discovery.relmine` 全庫約 25 分鐘，101,958 組 T(A)=k·B，其中 74,207 組沒互提；另一執行緒的仿射版 13,165 組、6,695 組沒互提。篩選（去 C-finite、兩跳已知、名稱類型、至少一邊沒有已證公式）後人工讀了約 20 對，本家族是第一個值得做的。

## 結果

H1–H4 在 n ≤ 200 全部成立；雙射逐元素成立；八個 g.f. 與推導出的有理函數相等；OEIS 存的項全部一致。

## 更正（2026-11-27，依 critic 第二輪與 review）

上面「實作三」寫的「比較前 120 個係數，次數和小於 60 所以相等」這個理由不成立（A308775 直接通分後交叉乘積次數 140）。現在的證明是 `check_gf_exact`：所有 g.f. 寫成 N/Q0²（Q0 = (1−x)(1−x²)(1−x³)(1−x⁴)），和 Barker 的分式做整數多項式交叉相乘，逐項相等；改一個係數會被抓到（已測）。前 120 項比較只留作額外檢查。
