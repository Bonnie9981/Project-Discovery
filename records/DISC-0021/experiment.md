## 方法

## 結果

### A134559（反例）

1. `results/A134559/code/a134559.c`：照「n mod u = k」定義累加 b_n(k)，P(n) mod n 取 gcd；每個 n 判斷 (*) 是否成立，和「n 在 A005383 且不是 3、5」比對。`./a134559 150000`（約 64 秒）。
2. `results/A134559/code/chk134559.py`：用因數和形式 T(n−k, k+1) 對 n = 4934, 6998, 11114 重算，找出讓 p 整除的 k。
3. `discovery/cxsearch/conjectures.py` 的 `a134559`（Python，第三套）：n ≤ 2000 沒有不一致（與條目一致），n = 4933 回報失敗（`tests/test_cxsearch.py`）。

結果：n ≤ 1.5·10^5 共 7 個不一致，全部是 A005383 的質數不滿足 (*)：4933、6997、11113、48673、50341、92941（gcd(P(p+1),p+1) = p+1），54217（gcd(P(p),p) = p，條目自己點名的失敗方式）。沒有任何不在 A005383 的 n 滿足 (*)。滿足 (*) 的 n 共 925 個。critic 用自己的程式（反對角線遞推）重算到 3·10^5，前述 7 個一致，另有 161221、172573、242533 三個失敗，仍沒有 A005383 以外的解。最小反例 4933：b_4934(134) = T(4800,135) = 14802 = 6·2467，三套程式一致。

### A322445（沒反例，範圍延伸）

`a322445.c`：a(n) = 最小 m 使 n | F(m)，F(m) = m^(m−1)·∏_{k<m} k^τ(m−k)（條目 A297707 的公式），逐質因數算 v_p。前 30 項與 DATA 一致。n ≤ 10^7：a(n)=a(n+1) 只有 n = 2400。
另外 a(n)=a(n+1)=m 時 n、n+1 都是 m-光滑數。`smooth.c 47 1e13` 列出 10^13 以下所有連續 47-光滑數對（1502 對，最大 1109496723125，與 Lehmer 1964 的表一致），`a322445_pairs.py` 算兩邊的 a：只有 2400。依 Lehmer 對 41-光滑（及文獻對 47）的完整列表，可說 a(n)=a(n+1) ≤ 47 的解只有 2400；其他解若存在，a ≥ 53 且 n > 10^7。完整性依賴文獻，不寫成定理。

### A306467（沒反例，範圍延伸）

`a306467.c`：對每個 k 和每個剩餘類 r，用中國剩餘定理數類中 p^i 的倍數，判斷 n 是否整除該類的乘積。前 34 項與 DATA 一致；Python 版（直接乘）到 n 約 3000 結果相同。`./a306467 20000`（11 分 35 秒）：n ≤ 20000 的 a(n)=a(n+1) 仍只有 1,2,3,4,9,27。a(n) 可大到約 0.38n，計算是 n² 級，沒再往上推。

### A309491、A008590（沒反例）

`gcd2.c`：a(n) = Σ_{d|n, d>1} φ(n/d)·d/lpf(d)、S2 = Σ φ(n/d)·lpf(d)，前 28 項與 A309491 DATA 一致。n ≤ 10^8：偶數解 a(n)=n 且 n/2 不是質數只有 8；「S1、S2 都偶數 ⇔ 8 | n」除 n = 1（條目限定 a(n) > 0，不算）外全部成立。

### A033235（沒反例）

`a033235.c`：b(n) mod n 用 4×4 矩陣快速冪。n ≤ 10^6 與條目完全一致（9748 個質數解、非質數解 1, 586, 2935, 17161, 429737）。n ≤ 10^8：質數解 719797 個，全部是 x²+55y² 型，反之亦然，0 個不一致；非質數解 12 個。
