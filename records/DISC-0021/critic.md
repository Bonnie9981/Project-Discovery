## 攻擊項目

1. **猜想的讀法。** 逐字原文：「Consecutive n satisfying two equations … are consecutive elements of A005383 (… save A005383(1) = 3 and A005383(2) = 5)」。紀錄讀成「解集合 S = A005383 去掉 3、5（記為 A'）」。我也測了較弱的字面讀法：「S 裡相鄰的兩項在 A' 裡也相鄰」。結果兩種讀法都被推翻。A' 在 4933 附近依序是 4621, 4933, 5077, 5101。我的程式算出 4621 和 5077 都在 S 裡，4933 不在，所以 S 裡相鄰的 (4621, 5077) 在 A' 裡不相鄰。第二句「The conjecture is false if … gcd(P(p),p) = p」只是作者舉的一種失敗方式（充分條件），沒有說是唯一的方式，所以不影響判定。
2. **指標範圍。** ⌈n/2⌉−1 對應到 `k < (n+1)/2`（自然數除法），奇數和偶數 n 都對。用來推翻的 k = 134 遠小於 ⌈4934/2⌉ = 2467，是合法指標。k = 0 時 b = σ(n)，也在範圍內。
3. **紙上證明（另一半）逐步檢查，沒找到漏洞。**
   - 引理：k = N−m < N/2，而 k 是整數，所以 k ≤ ⌈N/2⌉−1。「N mod u = k ⇔ u > k 且 u | m」成立。m 除了自己以外的因數都 ≤ m/2，而 m/2 ≤ N−m 等價於 m ≤ 2N/3，所以這些因數都不會被算進去。
   - 長度 N/6 的半開區間 (N/2, 2N/3] 一定含 d 的倍數，條件是 d ≤ N/6。成立，因為任何長度 ≥ d 的半開區間都含 d 的倍數。
   - 門檻 √n ≤ n/6 ⇔ n ≥ 36；√(N/2) ≤ N/6 ⇔ N ≥ 18；4 ≤ N/6 ⇔ N ≥ 24。在 n ≥ 36 時三個都成立。
   - 4|N 的情形：4 整除 gcd，所以 gcd ≠ 2，正確。M 合成時，奇質數 q 整除 gcd，所以 gcd ≠ 2，正確。
   - n < 36 的部分：我用字面定義暴力算，n ≤ 35 的解只有 13，而 13 在 A' 裡。
   - 數值佐證：我自己的掃描到 3·10^5 沒有任何 A' 以外的 n 滿足 (*)。
