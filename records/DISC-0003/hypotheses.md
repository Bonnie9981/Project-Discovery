# DISC-0003 hypotheses.md

作者：orchestrator（hypothesis 角色）

記號：apSum(D, a, k) = a + (a+D) + … + (a+(k−1)D)。R_D^{條件}(N) = #{(a, k) : a ≥ 1, k ≥ 1, 條件(k), apSum(D, a, k) = N}。R = R_1。d_odd(N) = N 的奇因數個數，τ(N) = 因數個數。所有 N 都是正整數。

## 猜想

| ID | 精確敘述 | 測試範圍 | 預期 | 角色 |
|---|---|---|---|---|
| H1 | ∀N ≥ 1：R(N) = d_odd(N) | N ≤ 100000；Lean 一般 N | 成立（已知） | M1.1 基準 |
| H2a | ∀N ≥ 1：R^{k≥2}(N) = d_odd(N) − 1 | N ≤ 100000；Lean | 成立（已知） | 基準推論 |
| H2b | ∀N ≥ 1：R^{k≥2}(N) = 0 ⇔ N = 2^m | N ≤ 100000；Lean | 成立（已知） | 基準推論 |
| H3 | ∀N ≥ 1：R^{k 奇}(N) = #{d 奇, d ∣ N, d² < 2N} 且 R^{k 偶}(N) = #{d 奇, d ∣ N, d² > 2N} | N ≤ 100000 | 成立 | 延伸（項數奇偶） |
| H4 | ∀N ≥ 1：R_2(N) = #{d ∣ N : d² ≤ N} = ⌈τ(N)/2⌉ | N ≤ 100000；Lean 前半 | 成立（已知 A038548） | 延伸（公差 2） |
| H5 | ∀N ≥ 1, 1 ≤ D ≤ 8：R_D(N) = #{k ∣ 2N : 2N/k − (k−1)D 為偶數且 ≥ 2} | N ≤ 10000 | 成立 | 延伸（一般公差） |
| H6 | ∀N ≥ 1：R_2(N) ≤ R_1(N) | N ≤ 100000 | **預期為假**（刻意放入的天真外推，用來確認反例搜尋會動） | 對照組 |

推導依據（給 critic 攻擊用）：2·apSum(D, a, k) = k(2a + (k−1)D)。D = 1 時 2N = k·m，m = 2a + k − 1 > k ≥ 1，k 與 m 奇偶相反，其中奇數那個是 N 的奇因數 d；k 奇 ⇔ k = d < m ⇔ d² < 2N（d² = 2N 不可能，因為左奇右偶）。這給出 H1 與 H3。H5 只是把 2N = k(2a + (k−1)D) 改寫，屬於定義層級的重述。

延伸序列 E1～E13（不是猜想，是送去新穎性層查的序列）列在 `research/r001/disc0003/run.py` 的 `EXTENSIONS`，結果在 `novelty_data.json`。

## 推翻條件

- H1～H5：兩個（或三個）獨立實作在測試範圍內都找到同一個不符的 N，判 `REFUTED`；實作之間不一致，判 `INCONCLUSIVE`。
- H6：只要有一個 N 讓 R_2(N) > R_1(N) 且兩個實作同意，就推翻。若沒找到反例，代表反例搜尋或實作有問題，要回頭檢查。
- Lean：若 `card_reps_one` 等定理無法在 CI 編譯，或公理檢查出現 `sorryAx` 等非標準公理，H1/H2/H4 不得升級為 `PROVEN_*`。
- 新穎性：任何序列在 OEIS 有完全吻合，就是 `MATCH_FOUND`，對應結果只能是 `*_KNOWN`。
