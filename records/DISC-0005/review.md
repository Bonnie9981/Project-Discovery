### C. 等級判定（1c：「不是已知公式一步就能推出」）

**核心問題：** 報告把「規則本身是非線性的」當作 L1 的理由（C01、C03、C04、C08 的說明欄）。但這個理由不成立。單一種子的軌道如果從頭到尾都不會出現某些鄰域，規則在這條軌道上就和線性規則完全相同。審查者對每條候選規則列出軌道上實際出現的鄰域（w = 3..24），並把 (T, P) 序列和全部 256 條規則、寬度平移 −2..+3 做比對，找到以下化約。

**引理 A（規則 90，Martin–Odlyzko–Wolfram 1984 的多項式方法）**

- 設偶數 w = 2^D·w′，其中 w′ 是奇數、D ≥ 1。在 F₂[x]/(x^w − 1) 中，規則 90 等於乘上 x⁻¹(1+x)²。
- x^w − 1 = (x^{w′} − 1)^{2^D}，其中因子 (1+x) 的重數剛好是 2^D。用中國剩餘定理拆開：單一種子 1 走 t 步之後，在 (1+x)^{2^D} 分量上是 x^{−t}(1+x)^{2t}，它等於 0 若且唯若 2t ≥ 2^D；其他分量都是可逆元。
- 所以 T₉₀(w) = 2^{D−1} = v₂pow(w/2)（w 為偶數）。w 為奇數時，像空間的權重都是偶數，所以 T₉₀(w) = 1。
- 這條序列就是 OEIS **A160467**。本批次自己的 OEIS 篩選也找到了它（`oeis_screen` 中 T₉₀ 的結果是 `A160467`, `MATCH_FOUND`）。

**引理 B（偶數寬度：四條規則和規則 90 完全相同）**

- 在偶數環上，規則 90 的單一種子軌道是棋盤格：時間 t 時只有 i + t 為偶數的格子可能是 1。所以 011、110、111 這三種鄰域永遠不會出現。
- 規則 18、146、26、218 在其餘 5 種鄰域（000、001、010、100、101）上的輸出都是 l ⊕ r，和規則 90 一樣。
- 所以 w 為偶數時，這四條規則的軌道**逐步等於**規則 90 的軌道（審查者列出鄰域確認過；(T, P) 到 w = 39 全部相等）。
- 由此 C01、C02、C04、C08 的偶數部分，以及 C11 的偶數部分（P₂₁₈ = P₁₈ = P₉₀），都可以由引理 A 直接得到。

**引理 C（奇數寬度的規則 18：刪去對蹠格）**

- 設 w = 2m − 1。看寬度 2m 的規則 90，種子放在 0。這個狀態對 i ↦ −i 對稱，所以對蹠格 m 每一步都滿足 z_m ← z_{m−1} ⊕ z_{m+1} = 0，也就是永遠是 0。
- 把格子 m 刪掉，得到 2m − 1 格的環。原本的 m−1 和 m+1 變成相鄰，而且兩格的值相同。
- 接縫格 m−1 在小環的鄰域是 (z_{m−2}, c, c)。規則 18 的輸出是 (1−c)(z_{m−2} ⊕ c)：
  - c = 0 時，輸出是 z_{m−2}；
  - c = 1 時，輸出是 0。由棋盤格性質，這時 z_{m−2} 也是 0。
  - 兩種情況都等於規則 90 在大環的更新值 z_{m−2} ⊕ z_m = z_{m−2}。
- 其他格子在棋盤格上本來就有「規則 18 = 規則 90」。
- 刪去格子 m 這個對應，在「z_m = 0 的組態」上是單射。所以 (T, P)₁₈(2m−1) = (T, P)₉₀(2m)。
- 審查者在 m ≤ 19 逐步比對了 3000 步，完全相同。規則 146 也一樣（m ≥ 2 時 111 不會出現）。
- **結論：** T₁₈(w) = T₉₀(2⌈w/2⌉) = v₂pow(⌈w/2⌉)。這就是 **C01 的完整敘述**，C02 也同時得到。

**引理 D（規則 126 = 規則 18 的「邊 OR」像）**

- 定義 Φ(u)_i = u_i ∨ u_{i+1}。窮舉 (u_{i−1}, u_i, u_{i+1}, u_{i+2}) 的 16 種情形，都有 F₁₂₆(Φ(u))_i = F₁₈(u)_i ∨ F₁₈(u)_{i+1}。也就是說，在任何環上 Φ∘F₁₈ = F₁₂₆∘Φ。
- 寬度 w+1 的單一種子在 Φ 之下變成相鄰的「11」，而且之後永遠對這條邊對稱，所以兩格的值永遠相同。
- 把這兩格合併：規則 126 是「三格不全相等」，對 (l, c, c) 和 (l, c, l) 的判斷相同，所以合併後就是寬度 w 的規則 126、單一種子。
- 審查者直接驗證：對 2 ≤ w ≤ 31，「寬度 w 的規則 126 軌道」逐步等於「寬度 w+1 的規則 18 軌道取 Φ、去掉跨越種子的那條邊」，檢查長度 T + 2P 步。(T, P)₁₂₆(w) = (T, P)₁₈(w+1) 到 w = 39 全部相等。
- 還沒寫完整的部分：Φ 在軌道上是單射（這樣 T、P 才完全相等，而不只是「整除」）。
  - 偶數環的情形：棋盤格組態除了兩個交錯態都映到全 1 之外，可以唯一還原；而交錯態下一步一定是全 0，所以軌道上最多出現一次。
  - 奇數環要再接上引理 C。
  - 這是例行細節，數值上已經確認。
- **結論：** T₁₂₆(w) = T₁₈(w+1) = v₂pow(⌈(w+1)/2⌉) = v₂pow(⌊w/2⌋+1)。這就是 **C03 的完整敘述**。本批次的 OEIS 篩選本身也顯示 P₁₂₆ 和 P₁₈ 吻合同一個條目 A334506，和這個化約一致。

**引理 E（奇數寬度的規則 218 會停在固定點：C11 的奇數部分）**

- **會出現「11」區塊：** 到 t = m − 1 為止，規則 218 和引理 C 的提升完全相同。這段時間內，接縫格只出現過 c = 0 的情形，而 218 在 (l, 0, 0) 上的輸出是 l。到 t = m − 1 時，提升中的 z_{m−1} 和 z_{m+1} 都是 1（光錐的邊緣，還沒繞回來），所以在 w 環上出現相鄰的「11」區塊。
- **區塊格只增不減：** 規則 218 對 011、110、111 都輸出 1。所以有 1 鄰居的 1 格（稱為區塊格）會永遠保持是區塊格，數量不會減少。因為數量有上限，從某個時刻 t₀ 起就不再變化。
- **t₀ 之後的結構：** 設 b 是某個區塊的右端（x_b = 1，x_{b+1} = 0）。
  - 如果某一刻 x_{b+2} = 0，那麼下一步 100 → 1 會產生新的區塊格，矛盾。所以 x_{b+2} 一直是 1。
  - 如果某一刻 x_{b+3} = 0，那麼下一步 010 → 0 會讓 x_{b+2} 變成 0，矛盾。所以 x_{b+2}、x_{b+3} 也是一個區塊。
  - 因此整個環是「長度 ≥ 2 的 1 區塊，中間隔單一個 0」，或者全是 1。這樣的組態是固定點：101 → 0，而區塊格保持是 1。
- 所以 P₂₁₈(w) = 1（w 為奇數；w = 1 時是 111 → 1，也成立）。再加上引理 B，**C11 整條都證完了**，總長大約十行，屬於初等論證。

**C04、C08、C07 的奇數部分，以及 C09、C10：沒有找到化約。**

- 規則 26 在奇數 w 時，軌道會出現 011、110，和任何仿射規則都不一致。它的 (T, P) 和規則 154 相同（因為 111 不會出現；154 = l ⊕ r ⊕ (l∧c)，是右置換型規則），但這還不是一步推導。
