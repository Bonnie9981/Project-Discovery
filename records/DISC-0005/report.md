# DISC-0005：初等細胞自動機的軌道大小批次探索（R-002）

- 研究線：R-002
- 目標：用 R-002 補足 M1.2 的 L1 候選數（DISC-0004 審查後只有 5 個）
- 程式：`research/r002/`（`impl_a.py`、`impl_b.py`、`impl_c.py`、`engine.py`、`candidates.py`、`run.py`）
- 重現：`python -m research.r002.run 22 40`（約 2 分鐘；OEIS 篩選需要 `data/oeis/raw` 的快照）
- 程式版本、套件與資料雜湊：`result.json` 的 `meta`

## 1. 設定與方法

研究對象是 256 條初等細胞自動機（Wolfram 編號 r）。系統是寬度 w 的環，初始狀態只有一個活細胞。T_r(w) 是進入循環之前的步數（暫態），P_r(w) 是循環的週期。

- **三套獨立實作：**
  - `impl_a` 逐格查表，用字典記住每個看過的狀態。
  - `impl_b` 把整個環放進一個整數做位元平行更新，用 Brent 演算法找循環。
  - `impl_c` 用字串做三格視窗改寫，用 Floyd 演算法找循環。
  - 三套對 256 條規則、w ≤ 12 的 (T, P) 完全一致。`discovery.independence` 檢查結果是 0 problems。
- **掃描：** 用 `impl_b` 算出所有規則在 w = 1..22 的 (T, P)。
- **對稱性自檢**（已知定理，失敗就代表程式有錯）：
  - 鏡像規則的軌道大小相同。
  - 互補規則從互補種子出發，軌道大小也相同。
  - 兩項都 0 個失敗。
- **OEIS 篩選：**
  - 每個鏡像類別各取一條非平凡的 P 或 T 序列，共 94 條。
  - 用離線快照比對，允許從前 0 到 3 項開始對齊，至少 16 項相同才算吻合。
  - 62 條吻合。週期序列大多已經收錄在 A334496–A334515。
  - 32 條沒有吻合（`NO_MATCH_IN_SCOPE`），幾乎全是暫態序列。
- **擾動擴散（依 ChatGPT 對 R-002 的建議）：**
  - 寬度 64，8 個隨機初始狀態，翻轉一格，64 步之後量兩條軌道的 Hamming 距離。
  - 結果：30 條規則讓擾動完全消失，154 條把擾動留在局部，72 條讓擾動擴散（比例 ≥ 0.05）。
  - 這一項只做描述，不產生猜想。
- **候選檢查：** 每個候選都由 `impl_b` 和 `impl_c` 兩套實作各算一次，檢查到 w = 40，兩套在每個寬度都必須一致。

## 2. 候選（逐條）

v₂pow(k) 是整除 k 的最大 2 的冪（A006519）。

**自我更正：** R2-C09 一開始寫成 2⌊(w+1)/4⌋，這是看 w ≤ 22 的資料時抄錯了。雙實作檢查在 w = 7 就推翻了它（實際值是 2，公式給 4），之後改成現在的版本。`tests/test_r002.py` 保留了這個推翻案例。

**Level 1：8 個**：R2-C01、C03、C04、C07、C08、C09、C10、C11。另有 3 個在 L0（C02、C05、C06）。

加上 DISC-0004 審查後的 5 個 L1（C01、C02、C03、C05、C06），**M1.2 合計 13 個 L1**。這要等 DISC-0005 的獨立審查確認。

## 3. 新穎性

- **全部是 `NOT_CHECKED`。** 快照裡沒有對應的暫態序列，只代表 `NO_MATCH_IN_SCOPE`，不代表新。
- 單一種子的週期早在 1984 年起就被系統研究過（Wolfram；Martin、Odlyzko、Wolfram），也有不少 OEIS 條目。暫態公式很可能散見在文獻或 OEIS 的 COMMENTS 裡。進入 M1.3 之前一定要做文獻查證。
- 8 個 L1 都列在 `novelty.open`。

## 4. 限制

- 寬度只檢查到 40，而且所有候選都是「對所有 w」的敘述，所以這只是數值證據。
- 只研究了單一種子。多初始條件的研究只做了擾動擴散的描述統計。
- L0 和 L1 的分界是作者自己的判斷，還要經過獨立審查。

## 5. 結論

**判定：`SUPPORTED_NOVELTY_UNCHECKED`**（取研究目標那一項的狀態）。8 個 L1 候選由兩套獨立實作檢查到 w = 40，都沒有反例。三套實作和兩項對稱性自檢都沒有失敗。沒有任何一條被證明，也沒有任何一條被宣稱是新的。

下一步：先做獨立審查。審查通過後，從兩條研究線的 L1 裡選 3 條進入 M1.3。R-002 方面初步建議 R2-C11 和 R2-C07。
