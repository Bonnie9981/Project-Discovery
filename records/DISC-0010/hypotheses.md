# DISC-0010 猜想

## 猜想

記號：w 格環，狀態 x_t，第 i 格（0 ≤ i < w），左鄰 i − 1、右鄰 i + 1（mod w），x₀ 只有第 0 格活。ether：E(t, i) 在 t 偶數時是「i ≡ t (mod 4)」，t 奇數時是「i ≢ t + 1 (mod 4)」。

- **H1（光錐）：** w ≡ 0 (mod 4)、2t + 4 ≤ w 時，第 i 格活 ⇔（i ≤ t 或 i + t ≥ w）且 E(t, i)。
- **H2（ether）：** T = (w − 4)/2 起，x_{T+k} 的第 i 格 = E(T + k, i)。
- **H3（R2-C10，w ≡ 0 段）：** w ≡ 0 (mod 4)、w ≥ 4：x_{μ+4} = x_μ ⇔ μ ≥ T；且 x_{T+p} ≠ x_T（p = 1, 2, 3）。也就是暫態 T = (w − 4)/2、週期恰好 4。

## 推翻條件

- 某個 w ≡ 0 (mod 4)：(暫態, 週期) ≠ ((w − 4)/2, 4)，或某個 t ≤ T 的狀態不等於 H1 的錐形，或某個 t ≥ T 的狀態不是 ether。
