## 攻擊項目

1. **Step 1（接觸 ⇔ 共用頂點）——找到一句敘述錯誤，結論沒錯。**
   論文寫「q_i、q_j 距離 1 ⇔ 第 i、j 步共用頂點」。這只對「一橫一直」的兩步成立。反例：W = 東、北、西、南、西（v0=(0,0)，v4=(0,0)，v5=(−1,0)）。第 1 步 (0,0)–(1,0) 和第 5 步 (0,0)–(−1,0) 共用 (0,0)，但兩倍中點相差 (2,0)，經 A 變成 (1,1)，距離 2，不是 1。
   結論「W 自避 ⇔ q 自避且無接觸」仍然成立，但要補一句理由：若 v_a = v_b（a < b），方格是二部圖，所以 b − a 是偶數（≥ 4，論文寫的 b ≥ a+3 太鬆）。而一直轉彎的路徑橫直交替，所以第 a+1 步和第 b 步一定一橫一直，才能套用「(±1,±1) ⇔ 共用頂點」。我手算確認過「同種的兩步相差的兩個座標都是偶數，經 A 後 L1 距離是 2·max(|a|,|b|)，一定不是 1」，以及「一橫一直相差 (±1,±1) ⇔ 共用頂點」這兩點都對。
2. **Step 2（q 的轉向）——手算驗證正確。** t_{i+1} ≠ t_i ⇒ e_{i+2} = e_i ⇒ q 直走。t_{i+1} = t_i = L 時，以 e_i=(1,0)、e_{i+1}=(0,1) 為例：p_{i+1}−p_i=(1,1)，p_{i+2}−p_{i+1}=(−1,1)，剛好是逆時針轉 90°。A 的行列式是 −1/2 < 0，會把方向反過來，所以 q 往右轉。從 t_1 到 t_i 共 i−1 次轉換，對應 q 在 q_2…q_i 的動作，其中改變的次數是 (i−1)−τ_i，所以 t_i = L ⇔ (i−1)−τ_i 為偶數 ⇔ q 在 q_{i+1} 右轉；也就是 q 左轉 ⇔ i+τ_i 為偶數。和論文一致。
3. **Step 3（Manhattan 轉向規則）——四種情況逐一手算都對**（向東 Y 偶：左轉=北 ⇔ X 偶；向西 Y 奇：左轉=南 ⇔ X 奇；向北 X 偶：左轉=西 ⇔ Y 奇；向南 X 奇：左轉=東 ⇔ Y 偶）。走 j 步後 X+Y ≡ j；第一步向東，所以當前方向是直的 ⇔ τ_j 為奇數。直走永遠允許。結論和 Step 2 的規則完全一樣。
4. **一一對應與鏡射。** 一一對應：t 字串 ↔「直走／轉彎」字串是雙射（s_i = [t_{i+1} = t_i]，t_1 固定），兩邊都是 2^(m−2) 個。(x,y)→(y,x)：第 Y 條橫線（Y 偶向東）變成第 Y 條直線（Y 偶向北），直線也一樣，所以 M 變回 M、原點不動。除了論文的論證，我還**直接比對集合**：m ≤ 13 時，正規化蛇的中點像集合 = 向東出發的無接觸 Manhattan 路徑集合（大小相等），而且鏡射把它剛好映成向北出發的集合（見「獨立重算」）。
5. **Manhattan 方向的約定。** 我把 4 種奇偶約定（第 y 列向東 ⇔ y+a 偶、第 x 行向北 ⇔ x+b 偶，a,b ∈ {0,1}）都跑了，n ≤ 14 時計數完全相同。所以計數不受約定影響。
6. **定義是否和 OEIS 一致。** A336662 的 C 行寫「Adjacencies are forbidden regardless of the direction」。程式用的是 Z² 距離 1、不管邊的方向，和定義一致；而且 Manhattan 格子上每對 Z² 鄰點之間都有一條有向邊，所以兩種讀法一樣。A189722 的「first turn left, otherwise doubled」：a(2)=1，表示第一步也固定。我用「所有方向出發、每步轉彎的自避路徑數 ÷ 8」重算，吻合。
7. **A337353 的說法——比紀錄寫的更強。** 在 terms.pkl 存的全部項（n ≤ 38）上，現有 F 行「a(n) = 4*A336662(n)」**沒有任何一個 n 成立**，連 n = 0 都不成立（1 ≠ 4）；不只是 n = 1 失敗。另外，4·A336662(n−1) 在 **n = 1 也成立**（4 = 4·1），所以 H2 的第二個等號可以寫成 n ≥ 1；論文和程式都只寫、只驗 n ≥ 2。8·A189722(n) 需要 n ≥ 2（A189722 從 2 開始），這部分沒錯。
8. **Offset。** sqlite 的 seq 表：A189722 offset 2、A336662 offset 0、A337353 offset 0；terms.pkl 也一樣。和 proof.md 一致。程式在比對已存項之間的關係時，offset 是**寫死**的（`k+1-2`、`n-1`），沒有用讀進來的 offset。目前資料剛好對得上，不是錯誤，只是比較脆弱。
9. **漏看的現成關係（A322419）。** OEIS 的 A322419（L-lattice）已經有「a(n) = 4*A189722(n) for n >= 2」。我在已存項上驗證：A336662(n) = A322419(n+1)/2（全部 n ≥ 0，含 n = 0），以及 A337353(n) = 2·A322419(n)（n ≥ 1）。literature.md 有提到 A322419，但論文和 OEIS 草稿的說法都沒用上它。換成 A322419 來寫，對應式不用拆成 k ≥ 1，也更直接呈現「L-lattice ↔ Manhattan」這個主題。
10. **程式的獨立性。** `midpoint_check` 和 `manhattan_nocontact` 共用同一個 `manhattan_ok`，所以 experiment.md 說的「彼此獨立的程式路徑」只有部分成立。我的獨立重算（不同的方向約定、用「全部 ÷ 8」數蛇、直接比對集合）補上了這一點，結果一致。
11. **新穎性。** Watson 1970 的覆蓋格子對應是已知的（S002 逐字讀過）。A189722 和 L-lattice 的關係在 A322419 已有。剩下的只有「覆蓋路徑剛好是 Manhattan 格子」這一步，物理文獻（L 和 Manhattan 格子的多邊形論文，J. Phys. A 18 (1985)）沒讀到。要標成 SUPPORTED_KNOWN，得有一份明確寫出這件事的來源，現在沒有。所以維持 SUPPORTED_NOVELTY_UNCHECKED／NO_MATCH_IN_SCOPE 是對的，不能宣稱新穎。
