# DISC-0032 證明

## 定理對照

完整證明見 `paper/a336662-manhattan.md`。
1. H1：一直轉彎路徑 W 的每一步取（兩倍）中點，轉 45° 縮放得到 q。(a) q 自避且無接觸 ⇔ W 自避（兩中點距離 (±1,±1) ⇔ 兩步共用頂點）。(b) W 相鄰兩個轉彎同向 ⇔ q 轉彎，異向 ⇔ q 直走；推出 q 在第 j 步後左轉 ⇔ j + τ_j 為偶數。(c) Manhattan 格子從原點向東出發的路徑，轉彎規則完全相同。所以是一一對應；向北出發由 (x,y)→(y,x) 對稱得到，乘 2。
2. H2：n ≥ 2 步的「不重複方向」自避路徑不能回頭，所以每步都轉；4 個起始方向 × 2 個第一個轉彎，等於 8·A189722(n)，再代 H1。

## 編譯結果

沒有 Lean 檔。紙上證明加程式驗算；依研究規範第 1 節不能標 PROVEN。

## 敘述差異

- A189722 offset 2（m = 邊數），A336662 offset 0（k = 步數），A337353 offset 0。k = 0 時 A336662(0) = 1，不在 H1 範圍。

## 更正（critic 後補記）

- Step 1 原寫「q_i、q_j 距離 1 ⇔ 第 i、j 步共用頂點」，只對一橫一直的兩步成立（反例：東北西南西的第 1、5 步共用 (0,0)，q 距離 2）。已改：W 走回舊點 v_a = v_b 時 b − a 是偶數（方格是二部圖）且 ≥ 4，第 a+1 步和第 b 步一橫一直，所以 q 有接觸。上面「b ≥ a+3」應為「b ≥ a+4」。
- H2 的範圍：4·A336662(n−1) 在 n = 1 也成立，改成 n ≥ 1；A337353 現有公式在條目存的每一項都不成立，不只 n = 1。程式改成從 n = 1 檢查，比對 OEIS 項時改用讀進來的 offset。
