# DISC-0024 證明

## 引理（偶數位回文被 11 整除）

N 的十進位數字 d_0（個位）…d_{L−1}。因為 10 ≡ −1 (mod 11)，N ≡ Σ (−1)^i d_i。回文時 d_i = d_{L−1−i}，L 偶數時 i 和 L−1−i 奇偶相反，兩兩抵銷，交錯和為 0，所以 11 | N。
Lean：`PalDigits.pal_even_dvd11`（`alt_reverse`：反轉後交錯和乘上 (−1)^(L−1)）。

## 位數

p 有 a 位且每位 ≥ 4，則 4·10^(a−1) ≤ p < 10^a（Lean `val_ge`、`val_lt`）。q 同樣 b 位。於是
16·10^(a+b−2) ≤ pq < 10^(a+b)，所以 pq 恰好 a+b 位（不寫前導零）。Lean `main` 裡的 `lo`、`hi`、`hlen`。

## H2（A084352）

a = b，pq 有 2a 位，是偶數位回文，11 | pq。11 是質數，所以 p = 11 或 q = 11，但 11 的數字是 1，不是 ≥ 4（Lean `val_ne_11`：一位數 < 10，兩位以上 ≥ 40）。矛盾。所以每個回文 brilliant 數的兩個因數至少有一個數字 ≤ 3，即 a(n) ≤ 3。Lean `a084352`。

## H1（A084189）

p 是回文質數且數字 ≥ 4：若位數偶數，p 被 11 整除，p = 11，矛盾（`palprime_odd`）。所以 a、b 都是奇數，a+b 偶數，同上矛盾。Lean `a084189`。

**不是空泛**：A084189、A084352 的值 a(n) = 3 確實出現（例如 9 = 3·3），猜想是「≤ 3」不是「≤ 2」。

Lean 的陳述用「小端數字串」表示 p、q、pq，pq 的最高位 ≥ 1（標準寫法）。質數用一般定義（2 ≤ p 且因數只有 1 和 p）。只用 core。

## H3（A225004）

n·m 的每個質因數 p 記 (a, x) = (v_p(n), v_p(m))（新質數 a = 0）。d(n) = ∏(a+1)，d(nm) = ∏(a+x+1)。若某個 x ≥ a+1，該因子 ≥ 2(a+1)，其餘因子 a+x+1 ≥ a+1，所以 d(nm) ≥ 2d(n)。故 d(nm) < 2d(n) 時每個 x ≤ a，即 m | n、nm | n²；同時看出新質數不能出現，a(n) = n·max{m | n : d(nm) < 2d(n)}。
Lean `DivisorExp.two_P_le_Q`、`exponents_le`（只形式化乘積不等式；d 的乘積公式是古典事實，沒形式化）。

## H4（A340896）

n = ∏ p_i^{a_i}，k 個不同質因數。d(n²)/d(n) = ∏ (2a_i+1)/(a_i+1)。k = 0（n = 1）時 1 < 2；k = 1 時 (2a+1)/(a+1) < 2；k ≥ 2 時每個因子 ≥ 3/2，乘積 ≥ 9/4 > 2。所以 n² 在第 n 列（d(n²) < 2d(n)）若且唯若 n 是質數冪。紙上證明，數值檢查到 n ≤ 150（與 A225004 同一支程式的副產品，見 experiment.md）。

## H6 反方向（A058383）

x = 1 + 2^a·3^b 是質數（a, b > 0）：φ(x) = x−1，φ(x−1) = (x−1)/3，和 = 4(x−1)/3；3 | x−1 所以 ⌊(4x−3)/3⌋ = (4x−4)/3。相等。正方向沒有證明。

## A276674（Ordowski 2016）：x − λ(x) = 2m > 0 ⇒ x ≤ 4m

只要證 λ(x) ≤ x/2。x − λ(x) 是正偶數排除了：x = 1（差 0）、x = 2（差 1）、奇質數冪 p^k（λ = p^(k−1)(p−1)，差 p^(k−1) 是奇數）。剩下：
- x 偶數：λ(x) ≤ φ(x) ≤ x/2。
- x 奇數且至少兩個不同質因數：λ(x) 是各 λ(p^e) 的最小公倍數，每個都是偶數，所以 λ(x) ≤ ∏λ(p^e)/2 = φ(x)/2 < x/2。

所以 x ≤ 2(x − λ(x)) = 4m。紙上證明，數值檢查 x ≤ 10^6（`results/A276674/code/check276674.py`，順便對 A276674 DATA 前 20 項）。
