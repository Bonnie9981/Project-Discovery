# DISC-0024 假設

## 猜想

- **H1（A084189）**：若 p、q 是回文質數、所有數字 ≥ 4，p·q 不會是回文。理由：數字 ≥ 4 的回文質數位數是奇數（偶數位回文是 11 的倍數）；首位 ≥ 4 讓 p·q 恰好 a+b 位（偶數），所以 p·q 是偶數位回文、被 11 整除，矛盾。
- **H2（A084352）**：若 p、q 是質數、位數相同、所有數字 ≥ 4，p·q 不會是回文。同一論證，a = b。
- **H3（A225004）**：d(nm) < 2d(n) 推得 m | n，所以 a(n) | n²。
- **H4（A340896）**：d(n²) < 2d(n) 若且唯若 n 是質數冪（含 1）。
- **H4b（A276674）**：x − λ(x) 是正偶數時 λ(x) ≤ x/2。
- **H5（A015126）**：n 奇數時 φ(k) = φ(n) 的最小 k 是奇數。只能數值檢查。
- **H6（A058383）**：φ(x) + φ(x−1) = ⌊(4x−3)/3⌋、x ≥ 7 的解恰好是 Pierpont 質數 1 + 2^a·3^b（a, b > 0）。反方向（這些質數都是解）一行可證；正方向只能數值檢查。

## 推翻條件

- H1/H2：找到 p、q 數字全 ≥ 4 且 p·q 是回文（對應條件下）。
- H3：某個 n 的 a(n) 不整除 n²。H4：兩個以上質因數的 n 有 d(n²) < 2d(n)，或質數冪反之。H4b：x − λ(x) = 2m > 0 但 x > 4m。
- H5：奇數 n 的 φ(n) 最小原像是偶數。H6：非 Pierpont 質數的解。
