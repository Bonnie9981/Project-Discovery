# DISC-0020 猜想

## 猜想

- H1（A362070，Ratajczak）：對所有 n ≥ 1，a(n) ≠ a(n+1)。
- H2（A362070 另問）：a(n) = n 的解只有 1、16 和 T(p) = p(p+1)/2（p 為奇質數）。
- H3（A332786，Ordowski）：49 是唯一的合數 m 使 m | a(m)；沒有偽質數 m 使 m^2 | a(m)。

## 推翻條件

- H1：找到 n 使 a(n) = a(n+1)，並用照定義逐字寫的程式、條目自己的 Maxima 程式、Lean kernel 計算確認。
- H2：找到不在清單裡的 n 使 a(n) = n。
- H3：找到 49 以外的合數 m 使 m | a(m)（用 q 進賦值精確判斷，並以分數精確計算對小範圍校對）。
