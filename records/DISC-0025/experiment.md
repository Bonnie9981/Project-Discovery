# DISC-0025 實驗

## 方法

- 程式：`discovery/tuzasat/`（search.py、check.py），規格 `docs/TUZASAT.md`；commit 見 PR。
- Python 3.13.18、PySAT 1.9.dev24（CaDiCaL 1.9.5 `Cadical195`）、雲端容器單核。
- 指令：`python -m discovery.tuzasat.search N [K] --out DIR`，`python -m discovery.tuzasat.check DIR N K...`。每個 (n, k) 的搜尋和檢查分開跑，各自 `timeout 600`。
- 摘要（含 CNF、DRAT 的 SHA-256）：`data/tuzasat/summary.json`。CNF／DRAT 本身不進 git（可重跑產生，CaDiCaL 是決定性的）。

## 實作（第二實作只到 7 點）

- **A（SAT＋證書）：** 雙層 CEGAR，見 `docs/TUZASAT.md`。
- **B（暴力）：** `check.nu_tau` 直接列舉三角形打包和邊覆蓋，對 networkx 圖譜裡所有 3～7 點的圖確認 τ ≤ 2ν（`tests/test_tuzasat.py::test_bruteforce_atlas`）。B 只到 7 點；8、9 點只有 A。

## 結論

- n ≤ 9：所有 k 的證書都在 600 秒、50 MB 上限內驗過，**9 點以內沒有 τ > 2ν 的圖**。
- n = 10：k = 1～3 有證書；k ≥ 4 的證書檢查超過 600 秒（DRAT 38～116 MB，也超過 50 MB），只有求解器結果，**不算數、不主張 10 點**。
- 擋子句數每多一點約乘 8～15 倍，n = 11 不在這套 Python 工具的能力內。

## 重現方式

```
python -m discovery.tuzasat.search 9 --out OUT
python -m discovery.tuzasat.check OUT 9 1 2 3 4 5 6 7 8
```

重跑得到的 CNF、DRAT 雜湊應和 `data/tuzasat/summary.json` 相同。
