# DISC-0015 猜想

## 猜想

記號：R_t = 規則 54 從位置 0 單一 ON 細胞走 t 步；a118109(n) = R_n 在 −n..n 讀成十進位數；ones(n) = R_n 的 ON 數；a265225(n) = ones(0)+…+ones(n)。

- **H1（列的封閉形）：** R_t(x) = 1 ⇔ |x| ≤ t 且（t 偶：x ≡ t mod 4；t 奇：x ≢ t+1 mod 4）。
- **H2（A118109，Barker）：** a(n) = 10001a(n−2) − 10000a(n−4)（n > 3）；g.f. (1+111x)/((1−x)(1+x)(1−100x)(1+100x))。
- **H3（A118109，Keller）：** a(n) = ⌊(10000+1100(n mod 2))·100^n/9999⌋。
- **H4（A265225，Barker）：** 4a(n) = (n+1)(2n − (−1)^n + 5)；5 階遞迴；g.f. (1+3x)/((1−x)^3(1+x)^2)。
- **H5（A265225，Hurt、Veselovac）：** a(n) = n+1+(n+1)⌊(n+1)/2⌋ = A093353(n)+n+1。
- **H6（A265225，Ianakiev 註解）：** 從 1..2n 選 n 個不同數、和被 n 整除的最小和 = a(n)。預期：索引差一，應是 a(n−1)。

## 推翻條件

任何 n 讓模擬和封閉形不同，或任何公式在某個 n 不成立，或和條目 DATA 不一致。
