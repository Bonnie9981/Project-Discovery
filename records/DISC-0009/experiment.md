# DISC-0009 實驗

## 方法

`research/r003/l02_check.py`，n = 1..40（w = 2n+2 = 4..82）：
- 方法一：`research/r002/impl_b.py` 的位元模擬加 Brent，算規則 26 環的（暫態, 週期）。
- 方法二：自己寫的 tuple 零邊界規則 90，字典找第一次重複，算（暫態, 週期）。不 import repo 的程式。
- 兩者比較：週期相同、環的暫態 = 導線暫態 + 1；導線週期和 OEIS A268754 前 54 項中的前 40 項逐項相同。
- n ≤ 20 逐步檢查結構（第 0、m 格死、左半 = 導線、右半 = 鏡像），到暫態 + 2 倍週期。

## 結果

- n = 1..40 全部 OK（約 2 秒）。最大週期 174762（n = 36，w = 74）。
- 例：w = 10 是（1, 6），w = 16 是（8, 1）。
