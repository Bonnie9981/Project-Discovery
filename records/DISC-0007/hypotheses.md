# DISC-0007 猜想（M1.4）

## 猜想

- **H1（C02 完整刻畫，主線）：** 對所有 n ≥ 1，rad(σ(n)) = σ(rad(n)) ⇔ n 和 σ(n) 都無平方因子（A065301），或 n = 2^a·p，其中 p 是奇質數，a 是奇數且 ≥ 3，p+1 無平方因子，3 ∤ p+1，而且 rad(2^{a+1}−1) | 3(p+1)。這是 DISC-0006 的 H2′，本輪目標是在 Lean 裡證完兩個方向。
- **H2（C01 延伸，副線）：** 對所有 n ≥ 1 且 2^23 ∤ n，σ(σ_odd(n)) = σ_odd(σ(n)) ⇔ n 是奇平方數。DISC-0006 在 Lean 裡只做到 2^11 ∤ n；本輪要補上 v₂(n) = 11（2^12 − 1 = 4095 是過剩數，要另外論證）和 12 ≤ v₂(n) ≤ 22。
- **H3（R-003 試點，探索性）：** 初等細胞自動機單一種子在環上的暫態或週期，除了已知的規則 90 家族之外，還有一些可以寫成 a·G(h(w)) + b 的算術公式（G 取 2 的冪次部分、奇部分、2 的乘法階等）。這是「找不找得到」的試探，不是定理。

## 推翻條件

- **H1：** 找到一個 n，兩邊不一致；或 Lean 證明在 CI 上編譯失敗、用到 `sorry` 或額外公理。
- **H2：** 在 v₂(n) ∈ {11, …, 22} 找到一個偶數解；或 a = 11 的比值論證有錯（例如某個 f ≥ 1 的組合比值 ≥ 8191）。
- **H3：** 試點如果找到的非平凡公式全部能化約到已知結果（規則 90、仿射規則、已記錄的 R2 候選），H3 就是負面結果：這個公式庫在 w ≤ 22 的資料上找不到新東西。
