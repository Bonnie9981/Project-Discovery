# DISC-0013 猜想

## 猜想

記號：y_t^(n) = 零邊界規則 90、n 格、左端種子走 t 步（位元 i = 第 i+1 格），a(n) = 最小正最終週期（A268754）。

- **H1（間隔展開）：** n ≥ 1，把 y 的第 i 位搬到第 2i+1 位（偶數位補 0）記作 S(y)。則 y_{2t+1}^(2n+1) = S(y_t^(n))，對所有 t。
- **H2（死亡條件）：** n ≥ 1：導線會走到全空 ⇔ n + 1 是 2 的次方。
- **H3（A268754 FORMULA）：** n ≥ 1、n + 1 不是 2 的次方：a(2n+1) = 2a(n)；n + 1 = 2^k：a(n) = a(2n+1) = 1。

## 推翻條件

- 某個 n：H1 的某一步不相等，或死亡與否和 n+1 是否 2 的次方不一致，或 a(2n+1) ≠ 2a(n)（非例外）／≠ 1（例外）。
