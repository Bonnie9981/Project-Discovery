# DISC-0013 文獻

## 問題

OEIS A268754（零邊界規則 90、n 格、左端單一種子的最終週期，offset 1）FORMULA 欄：「奇數項 a(2n+1) = 2a(n)，除非 n = 2^k − 1，這時 a(n) = 1」。條目沒有附證明或出處（S001，2026-11-22 重讀全文）。COMMENTS 另寫「n = 2^k − 1 時所有格子會死，週期 1」，也沒有證明。

量詞與索引核對：
- 例外句的「a(n) = 1」應讀成 a(n) = a(2n+1) = 1（n = 2^k − 1 時 2n+1 = 2^(k+1) − 1 也是同型）。草稿建議改寫成這樣。
- 公式適用 n ≥ 1（offset 1）；n = 0 不在範圍。

## 已知成果

| 結果 | 出處 | 和我們的關係 |

| 規則 90 在 N 格環上的最大週期 Π_N：N 偶數時 Π_N = 2Π_{N/2} | Martin–Odlyzko–Wolfram 1984（本紀錄沒有重讀，見 DISC-0009 的筆記） | 同一個「位置加倍」想法（2n+1 格導線對應 4n+4 格環，正是 2n+2 格環的兩倍，critic 指出），但 MOW 講的是所有初始狀態的最大週期，不是這條特定軌道；本紀錄的證明是針對左端種子這條軌道自己寫的 |
| 零邊界 n 格 = 2n+2 格環上的對稱狀態 | DISC-0009 證明第二步（反射技巧，出處待查） | 本紀錄沒有用到，直接在導線上做「間隔展開」 |

## 研究空白

- 條目只給公式，沒有證明。論證很短（間隔展開 + 奇偶 + 偶數寬度可逆），用的都是已知技巧，很可能有人知道；新穎性不宣稱。
- 沒有查 arXiv、MathSciNet、Math Fun 郵件列表、Stack Exchange 聊天室（條目 LINKS 的兩個聊天記錄沒點開）。
