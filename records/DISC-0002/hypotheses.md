# DISC-0002 hypotheses.md

作者：orchestrator（主執行緒扮演 hypothesis 角色）

## 猜想

| 編號 | 類型 | 精確敘述 |
|---|---|---|
| H1 | universal | 對所有自然數 p ≥ 2：(p−1)² + (p−1) + p = p²，因此不是質數。（所以 Q_p 的範圍 n ≤ p−2 已是最長） |
| H2 | finite | 對所有整數 0 ≤ n ≤ 39：n² + n + 41 是質數。 |
| H3 | finite | 40² + 40 + 41 不是質數。（Q_41 不能延伸到 n = 40） |
| H4 | finite（範圍內） | 對所有質數 p ≤ 100000：Q_p 成立 ⇔ p ∈ {2, 3, 5, 11, 17, 41}。 |
| H5 | finite（範圍內） | 對所有質數 p ≤ 100000：Q_p 成立 ⇔ n² + n + p 對所有 0 ≤ n ≤ ⌊√(p/3)⌋ 都是質數。 |

H4、H5 在有限範圍內檢查，即使全部通過也只是證據。它們的一般情形分別是文獻第 4、5 條，本次不嘗試形式化（需要類數理論）。

## 推翻條件

- H1：任一 p ≥ 2 使等式不成立（代數上不可能，交給 Lean 證明）。
- H2：任一 n ∈ [0, 39] 使 n² + n + 41 是合數。
- H3：40² + 40 + 41 = 1681 是質數。
- H4：存在質數 p ≤ 100000，p 不在清單中但 Q_p 成立，或在清單中但不成立。
- H5：存在質數 p ≤ 100000，短檢查與完整檢查的結果不同。
