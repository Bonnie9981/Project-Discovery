# DISC-0002 literature.md

作者：orchestrator（主執行緒扮演 literature 角色）

## 問題

對質數 p，Q_p 表示「n² + n + p 對所有 0 ≤ n ≤ p−2 都是質數」。DISC-0001 在 p ≤ 2000 找到 Q_p 成立的 p 是 2, 3, 5, 11, 17, 41。本次要問：這個範圍為什麼停在 p−2？更大的 p 還有沒有？有沒有比檢查全部 n 更快的判準？

## 已知成果

1. **Euler (1772)**：n² + n + 41 對 n = 0..39 都是質數。廣為引用的經典例子。
2. **OEIS A014556**（Euler 的 lucky numbers）：2, 3, 5, 11, 17, 41，正是 Q_p 成立的 p。**OEIS A005846**：形如 n² + n + 41 的質數。
3. **Rabinowitsch (1913)**，J. reine angew. Math. 142, 153–164：Q_p 成立 ⇔ 判別式 **1−4p 本身**是類數 1 的虛二次判別式（即 4p−1 是 Heegner 數 3, 7, 11, 19, 43, 67, 163 之一）。
   - 修正紀錄：初稿寫成「ℚ(√(1−4p)) 的類數為 1」，被 critic 以 p = 7 推翻（4·7−1 = 27 = 3²·3，ℚ(√−27) = ℚ(√−3) 類數為 1，但 1+1+7 = 9 不是質數；p ≤ 2000 內有 30 個此類反例）。差別在於要的是判別式而不是體。
4. **類數 1 問題**（Heegner 1952、Baker 1966、Stark 1967）：類數為 1 的虛二次體只有 9 個。代入 4p − 1 ∈ {3, 7, 11, 19, 43, 67, 163} 得 p ∈ {1, 2, 3, 5, 11, 17, 41}，去掉非質數的 1，**清單已完整**，沒有更大的 p。
5. **只需檢查到 √(p/3)**：若 n² + n + p 對 0 ≤ n ≤ √(p/3) 都是質數，則對 0 ≤ n ≤ p−2 都是質數。此結果見於 Ribenboim 討論 Euler 多項式的著作（具體版次與頁碼**未查證**）。
6. 在 n = p−1 時，(p−1)² + (p−1) + p = p²，必為合數。這是一行代數，屬常識。

## 研究空白

就數學內容而言，第 1～4 條涵蓋的問題（Q_p 何時成立、清單是否完整）在 1967 年以前就已解決。第 5 條的出處與年代本次未查證，不納入這個判斷。本次演練的目的不是新發現，而是讓六個角色完整跑一次流程。

可能的小空白：Mathlib 裡有沒有 Euler 多項式的形式化證明，本次**未查**。
