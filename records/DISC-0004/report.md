# DISC-0004：算術函數批次探索（M1.2）

- 研究線：R-001
- 目標：M1.2，至少 10 個 Level 1 候選猜想
- 程式：`research/r001/batch/`（`engine.py`、`impl_a.py`、`impl_b.py`、`impl_c.py`、`candidates.py`、`run.py`）
- 重現：`python -m research.r001.batch.run 10000 1000000`（約 1 分鐘；需要 `data/oeis/raw` 的 OEIS 快照，沒有快照時 OEIS 篩選會記為無來源）
- OEIS 快照：見 `result.json` 的 `oeis_snapshot`
- 程式版本、套件與資料雜湊：`result.json` 的 `meta`

## 1. 方法

1. **函數庫**：27 個算術函數，定義寫在 `library.py`（d、d_odd、σ、σ₂、σ_odd、φ、ψ、J₂、ω、Ω、μ、λ（Liouville）、rad、core、Carmichael λ、sopf、sopfr、gpf、lpf、σ*（么正因數和）、2^ω、平方因數個數、r₂、r₃、r₄ 等）。
2. **兩套獨立實作**：`impl_a` 逐一用試除法分解每個數；`impl_b` 對整個範圍做篩法（因數和篩、Eratosthenes、r₂/r₄ 用 Jacobi 公式、r₃ 用 r₂ 摺積）。27 個函數算到 5×10⁴，兩套**完全一致**（`base_mismatch_a_vs_b` 是空的）。
3. **衍生物件**：210 條合成序列 f(g(n))（12 個內層函數 × 外層函數），每一個值都分別用兩套實作的表格算出來，不一致就丟掉（本次 0 條不一致；42 條因數值超出表格範圍而丟掉）。
4. **偵測器**（N = 10⁴）：乘性、交換子 f(g(n)) 和 g(f(n)) 的大小關係與相等集合、和 n 比較（含有限例外）、不動點集合、模 m 規律（含有限例外）。共產生 150 條線索（Level 0）。
5. **OEIS 篩選**：每條序列和集合都拿最多 200 項去離線快照比對。如果比到的 OEIS 條目名稱用的是同樣的函數，判為「定義相同」（已知）；如果是不同的定義，判為「交叉吻合」（可能是一個刻畫）。
6. **第三套實作**：`impl_c` 用線性篩求最小質因數，**不 import** A、B。所有候選都推到 N = 10⁶ 檢查。

## 3. 新穎性

- **全部是 `NOT_CHECKED`。** OEIS 快照只能比對序列和集合，沒辦法比對「性質」或「刻畫」。上表的 OEIS 欄只說明集合本身有沒有被收錄，**不代表**這條敘述是新的。
- 依照第 1b 節，任何候選進入 M1.3 之前都要做文獻查證：OEIS 頁面的 FORMULA 和 COMMENTS 段、論文資料庫、瀏覽器存證。所有 L1 都列在 `novelty.open`。
- 預期很多條是已知結果或練習題等級，特別是 C05、C06。`novelty.open` 只列 5 個 L1。

## 4. 線索的品質（自我批評）

- 60 條「模 m 規律」線索大多很平凡，例如 m ≥ 3 時 2 | φ(m)。偵測器還沒有過濾「外層函數本身就有這個性質」的情況。這是下一版要修的。
- 「不動點等於質數」那一類（例如 gpf(rad(n)) = n）全部都很平凡，評分時已經因為只吻合常見序列而扣分。
- 乘性偵測一開始把 Liouville(g(n)) 當成發現。它對任何乘性函數 g 都會成立，現在已經排除。

## 5. 結論

**判定：`SUPPORTED_NOVELTY_UNCHECKED`**（取研究目標那一項的狀態）。5 個 L1 候選全部經過三套獨立實作，檢查到 10⁶ 都沒有反例；**M1.2 的數量條件在這份紀錄裡沒有滿足**（5/10）。這些都只是數值證據，沒有任何一條被證明，也沒有任何一條被宣稱是新的。
