### C. 等級判定（1c：「不是已知公式一步就能推出」）

**C07、C08、C09、C11 第二部分：都可以從同一個古典上界一步推出，應該降為 L0。**

古典結果：n > 1260 時 d(n) < √n（等價的說法是 d(n)² < n；審查者也檢查到 10⁶：d(n)² ≥ n 的 n 共 54 個，最大是 1260）。另外，對每個 m ≥ 1，
σ(m) ≤ m·d(m) ≤ m²，ψ(m) ≤ σ(m)，σ*(m) ≤ σ(m)，J₂(m) ≤ m²。
所以 n > 1260 時，
σ(d(n))、ψ(d(n))、σ*(d(n))、J₂(d(n)) 都 ≤ d(n)² < n。
剩下的只是有限檢查到 1260。這就是「一個已知上界 + 有限檢查」，正是 L0 的情況。C07 的 `triviality` 欄自己也寫了「should follow from explicit bounds on d(n) plus a finite check」，但還是被算進 L1，這和 1c 的標準自相矛盾。

- C11 第二部分 {n : ψ(d(n)) = n}：上面的不等式在 n > 1260 時是嚴格的，所以解都 ≤ 1260，有限檢查就結束了。
- C11 第一部分 {n : d(ψ(n)) = n}：n = d(ψ(n)) ≤ √(3ψ(n))，而 ψ(n) ≤ σ(n) ≤ n(1 + ln n)，所以 n ≤ 3(1 + ln n)，也就是 n ≤ 13，再做有限檢查。這用了兩個教科書上界，同樣是例行推導。報告說「確切名單需要明確的上界」，但這個上界本來就是已知的。**C11 整條應該降為 L0。**

**C12：應該降為 L0。** 設 P = gpf(n)。如果 P ≥ 5，φ(P) = P − 1 是大於 2 的偶數，不是質數；但 gpf(φ(n)) 一定是質數或 1，所以等式不成立。如果 P = 2，需要 gpf(φ(n)) = 1，也就是 φ(n) = 1，得到 n = 2。如果 P = 3，n = 2^a·3^b；b ≥ 2 時 3 | φ(n)，所以要 b = 1。整個證明只靠「P − 1 是偶數」這一點，兩三行就完成。候選的 `triviality` 欄自己也寫「elementary (phi(p) = p − 1 …)」。

**保留為 L1：C01、C02、C03、C05、C06。**

- C01：n 是奇數時，σ_odd(n) = σ(n)，所以等式成立若且唯若 σ(n) 是奇數，也就是 n 是平方數。這個方向是一步。n 是偶數時，設 n = 2^a·m，σ(m) = 2^v·o（o 是奇數），等式會化成 (2^{v+1} − 1)·σ(o) = σ((2^{a+1} − 1)·o)。o 是平方數時可以用奇偶性排除，但 o 不是平方數時沒有一步就能排除的論證。審查者對 a < 40、o 在 2^{a+1} − 1 各質因數上的次方 < 5 做了代數搜尋，沒有任何組合能讓兩邊的比值等於 2^{v+1} − 1。這支持猜想，但不是證明。保留 L1。
- C02：先要 σ(rad n) 無平方因子，可以推得 rad(n) ∈ {1, 2, p, 2p}。再來要排除 p^b（b ≥ 2）的情形，這看起來需要 Zsigmondy 類型的論證。不是一步，保留 L1。另外要注意：這只是必要條件，a ∈ {3,5,7} 只是觀察到的現象，沒有被宣稱。
- C03：敘述比較弱（只限制 v₂(n)），但不是一步可推出。保留 L1。
- C05、C06：沒有找到一步的推導，保留 L1。不過這兩條很可能是已知結果或練習題（報告第 3 節也這樣說），文獻查證應該先查這兩條。

**結果：L1 從 10 個變成 5 個（C01、C02、C03、C05、C06）。M1.2「至少 10 個 L1」沒有達成。** 報告第 2 節表格最後一段和第 5 節「M1.2 的數量條件已滿足」屬於過度宣稱。commit `ef80317` 的訊息「M1.2 達成」也一樣（不能強制推送改歷史，所以應該在 PR 描述或後續 commit 更正）。

## 給 CEO 的摘要

- DISC-0004 的程式品質不錯：三套實作互不 import，方法也不同；審查者在乾淨的 commit 上重跑，結果和提交的完全一致；審查者另外寫了兩支獨立程式，分別檢查到 10⁵ 和 10⁶，報告中的所有數字（包括 C10 被推翻、反例 10711）都對。

- 新穎性全部誠實標成 NOT_CHECKED，沒有宣稱任何新發現。C05、C06 很可能是已知的練習題。最值得往 M1.3 推進的是 C02、C01、C03（和作者的建議一樣）。
- 建議：先修正等級並在乾淨的工作目錄重新產生 result.json，修正後同意合併；然後再跑一批補足 L1，並在偵測器加入「d(n) 上界」過濾。
