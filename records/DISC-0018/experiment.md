# DISC-0018 實驗

## 方法

腳本 `results/A231897/code/verify.py`：

- A231897：檢查 a = 0..3000 時 wt((2^a − 1)^2) = a；逐一搜尋重算前 25 項。
- A215461、A215462 兩套獨立實作：(1) 篩法 + 條目 FORMULA 的卷積；(2) 直接列出所有奇數拆法，試除判質數。
- 零點掃描：n < 200000，找到一種拆法就停。
- Lean 證明用的具體拆法（9 / 35 / 25 配 2n mod 6；3 / 7 / 5 配 2n mod 3）逐一數值檢查。

## 結果

- A231897：a ≤ 3000 全部成立；前 25 項和 DATA 一致，且都 ≤ 2^n − 1。
- A215461、A215462：n < 600 兩套實作完全一致，也和條目 DATA（各 74、80 項）一致。
- 零點：n < 200000 內，A215461 只有 n = 0, 1, 5 是 0；A215462 只有 n = 0, 2, 3, 4, 6, 7, 10, 16, 19 是 0。
- 具體拆法對 n < 500000 都成立。
