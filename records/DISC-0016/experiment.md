# DISC-0016 實驗

## 方法

`results/A085588/code/l08_a085588_period.py`，只用標準函式庫：
- 方法 A：用 F^(2^j) = 左移 2^j + 自己 + 右移 2^j 快速算 F^k；a(n) = P 的最小因數 d 使 F^(2^D+d)e = F^(2^D)e（P 用自寫的 Miller–Rabin + Pollard rho 分解）。
- 方法 B：直接一步一步模擬，用字典記住看過的狀態，找到重複就得週期（不用任何理論；週期 ≤ 20 萬步時才跑）。
- 檢查：n ≤ 400 每個 n 三個隨機狀態驗 H1；n ≤ 120 驗快速冪 = 逐步模擬；3 ≤ n ≤ 200 驗 H2，方法 B 能跑的 121 個 n 和方法 A 一致；對照條目 64 項 DATA（n = 3..66）。
- 另外在瀏覽器裡用 BigInt 檢查整個 b-file（n = 3..1000，S003），程式 `results/A085588/code/bfile_check.js`。
- critic 另寫第三套（F2[x]/(x^n−1) 一般平方乘法，`results/A085588/code/critic_c_a085588.py`），n ≤ 200 一致。

## 結果

- H1：n ≤ 400 全部成立。
- H2：n ≤ 200 自算全部成立；b-file 998 項全部成立。
- H3：不成立。n ≤ 200 有 36 個 n 失敗，b-file 有 174 個，最小的是 n = 4（a = 2，P = 4）和 n = 13（a = 21，P = 63）。失敗的 n 正好是條目列的「a(n) ≠ P」的 n（2 的次方、6·2^k、13·2^k……）。
- H4：n ≤ 1000 中 a(n) = n 的 31 個 n 全是 2^i(2^j − 1)、j ≥ 3 的形式。
