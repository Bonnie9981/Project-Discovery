# DISC-0016 猜想

## 猜想

記號：F = 規則 150 在 n 格環上一步（新(i) = 舊(i−1) xor 舊(i) xor 舊(i+1)）；n = 2^D·m，m 奇數；s = A309786(n)（最小 s ≥ 1 使 m | 2^s − 1 或 m | 2^s + 1）；P = 2^D(2^s − 1)；a(n) = A085588(n)。

- **H1（算子恆等式）：** 對每個環上狀態，F^(2^D + P) = F^(2^D)。所以任何軌道走 2^D 步內就進入週期，週期整除 P。
- **H2（條目第 1 條的正確方向）：** 對所有 n ≥ 3，a(n) | 2^D(2^s − 1)。
- **H3（條目第 1 條原句）：** 2^D(2^s − 1) | a(n)。預期**不成立**（a(4) = 2、a(13) = 21）。
- **H4（條目第 2 條）：** a(n) = n 推出 n ∈ A115770。只做數值與部分結果，不期望證完。

## 推翻條件

- H1：某個 n 和某個隨機狀態 F^(2^D+P)x ≠ F^(2^D)x。
- H2：某個 n 的 a(n) 不整除 P（自己算或 b-file）。
- H3：找到一個 n 使 P ∤ a(n) 即推翻。
