# DISC-0016 文獻

## 問題

OEIS A085588（offset 3）：規則 150 在 n 格的環上，從一個 ON 細胞出發的最終週期。2024-08-17 Roman Khrabrov 在 COMMENTS 寫了兩條「It appears / Conjecture」（S001，2026-11-23 讀全文）：

1. 「It appears that 2^A007814(n) * (2^A309786(n) - 1) divides a(n)」，說規則 90 時由 Martin–Odlyzko–Wolfram（MOW）Lemma 3.5、Theorem 3.5 推出，規則 150 驗到 n ≤ 1000。下一句說 a(n) 不等於 2^A007814(n)(2^A309786(n) − 1) 的 n 是 2 的次方和 6·2^k、13·2^k、37·2^k、61·2^k、67·2^k、95·2^k……
2. 「Conjecture: a(n) = n only if n belongs to A115770」，反方向第一個例外是 445。**更正：** 445 不在 A115770（11 ⊗ 445 ≠ 7·445）；在 A115770 裡、但 a(n) ≠ n 的最小 n 是 455（a(455) = 4095）。條目原文確實寫 445（S001 抄自條目），應是條目筆誤。

記號：A007814(n) = D（n 的 2 進位尾 0 個數），n = 2^D·m，m 奇數；A309786(n) = s = 最小的 s ≥ 1 使 2^s ≡ ±1 (mod m)（A309786 FORMULA：a(2n) = a(n)，a(2n−1) = A003558(n−1)，S002）。

## 研究空白

條目第 1 條寫的整除方向和數據相反：a(13) = 21，但 2^0·(2^6 − 1) = 63 不整除 21；a(4) = 2，但 4 不整除 2。真正成立（條目轉述的 MOW 規則 90 結果也是這個方向）的是 **a(n) 整除 2^D(2^s − 1)**。下一句「不等於……的 n」的列表和原句失敗的 n 吻合（n ≤ 1000 共 174 個，S003）；這不是巧合：因為 a(n) | P，「a(n) ≠ P」和「P ∤ a(n)」是同一件事。作者本意無法確定。空白：規則 150 這個方向沒有寫下的證明；條目原句需要更正。
