# DISC-0030 猜想

## 猜想

- **H1**：OLD(C_n) = A001609(n)（n 奇數 ≥ 3）、A001609(n/2)²（n 偶數 ≥ 6），OLD(C_4) = 0。
- **H2**：OLD(P_2k) = A000930(k)²（k ≥ 1）、OLD(P_{2k+1}) = A000930(k+3)·A000930(k−2)（k ≥ 2）。
- **H3**：梯子圖定位支配集個數的生成函數（13 階，paper 定理 3）。
- **H4**：梯子圖識別碼個數的生成函數（10 階，paper 定理 4）。
- 附帶線索（L0）：梯子圖的開定位支配集個數全是平方數（1, 0, 4, 9, 49, 64, …），應該也是奇偶拆開；稜柱圖需要環狀轉移矩陣的跡驗證，留待下一批。

## 推翻條件

任一 n 的暴力計數與公式不同即推翻。
